# 小加工厂财务教程：从录入凭证到出报表

> 这份教程带你**完整走一遍 2026 年 11 月**：一家做氧化外发加工的小厂，9 笔业务、10 张凭证，
> 月末结转，最后出四张报表。
>
> 全文所有数字都是软件真实算出来的（不是手算示例），你可以照着录一遍，最后逐项核对。
> 建账和期初怎么做请看《[日常记账手册](日常记账手册.md)》第一、二章；这份教程只讲
> **日常怎么记 → 月末怎么做 → 报表怎么读**。

里边的厂叫「恒亮氧化加工厂」：收客户的料做氧化加工，收加工费；自己没有在产品盘存，
房租水电直接记制造费用。

## 〇、先认路：三个入口在哪儿

| 要干的事 | 桌面版（左侧菜单） | 网页版（顶部菜单） |
|---------|------------------|------------------|
| 录一张凭证 | 填制凭证 | 凭证 → 记账凭证 |
| 看某笔账的来龙去脉 | 账簿查询 | 账簿报表 → 明细账 |
| 看某科目余额 | 科目余额表 | 报表中心 → 科目余额表 |
| 结转损益 / 结账 | 期末处理 | 凭证 → 期末处理 |
| 出三张主表 | 会计报表 | 账簿报表 → 资产负债表 / 利润表 / 现金流量表 |
| 看客户欠我多少 | 往来核销 | 往来 → 账龄分析 |
| 看这个月赚多少 | 首页 | 开始 → 工作台 |

桌面版默认是精简菜单（只有 17 项日常用的）。网页版菜单更全，功能一样。

## 一、一张凭证到底怎么填

录凭证的界面从上到下就五样东西：

```
日期  2026-11-05    凭证字  记    号  1        ← 日期改错了后面全错
─────────────────────────────────────────
摘要            会计科目          借方        贷方
采购辅助材料     140302 辅助材料   10,000.00
付材料款         100201 工行基本户              10,000.00
─────────────────────────────────────────
合计                             10,000.00   10,000.00
```

填的顺序建议是：**先想「借什么、贷什么」，再动手**。会计科目点一下能搜索，直接打
`1002` 或「银行」都行。

### 四个必填项，不填不让存

这四个是新手最常卡住的地方，报错长得像这样：`第 1 行科目 100201 核算银行账户，必须填写银行账户`。

| 科目类型 | 必须补什么 | 在哪个格子填 |
|---------|-----------|-------------|
| `1001/1002` 现金、银行存款 | 银行账户 | 科目右边的「银行账户」下拉（如 工行基本户） |
| `1122` 应收账款 | 客户 | 「客户」下拉 |
| `2202` 应付账款 | 供应商 | 「供应商」下拉 |
| `1403/1405` 存货类 | 存货档案 **+ 数量** | 「存货」下拉 + 「数量」输入框 |

填了这些，后面「钱在哪」「库存」「按客户看欠款」才出得来。省这一步的代价是：报表上看
得到总数，但拆不开是谁的。

### 金额永远填「不含税」的？不，按票面填

- **有增值税专用发票**：金额拆成「不含税金额 + 税额」两行（下面第 1、6 张凭证就是）。
- **没有票 / 普通发票**：一笔全额记进去，不拆税。
- 税率每个客户可以不一样：客户档案里能设「税点%」，录凭证时点工具栏「按客商税点算税」，
  填含税金额它帮你拆。

## 二、11 月的 10 张凭证，一张一张来

### 期初（只做一次，在建账时录）

| 科目 | 期初 |
|------|------|
| 100201 工行基本户（银行账户 B01） | 借 200,000.00 |
| 160101 房屋及建筑物 | 借 40,000.00 |
| 4001 实收资本 | 贷 240,000.00 |

> 期初只能录在**末级科目**上（`100201` 不是 `1002`，`160101` 不是 `1601`）。
> 系统会拦，报「必须录在末级科目上」。

### 第 1 张 · 11-05 采购辅助材料（有专票，13%）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 采购辅助材料 100kg | 140302 辅助材料 | 10,000.00 | |
| 进项税额 | 22210101 进项税额 | 1,300.00 | |
| 付材料款 | 100201 工行基本户 | | 11,300.00 |

**要点**：140302 是存货科目，记得填「存货」＝氧化辅料、「数量」＝100。
系统还会提示单价 100.00 元/kg —— 这个提示不用管，只是核对用。

> 为什么不是 140301「原料及主要材料」？客户给料加工，自己只买辅料，用 140302 更贴。
> 两个科目用法一样，选一个固定下来就行。

### 第 2 张 · 11-08 付厂租房租 15,000（没票）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 厂租房租 | 510105 制造费用-其他 | 15,000.00 | |
| 付厂租房租 | 100201 工行基本户 | | 15,000.00 |

**要点**：房租记「制造费用」而不是「管理费用」——这是**车间**的房租，最终要进产品成本。
没票也一样记，只是这笔进项不能抵扣（也不拆税）。别因为没票就不记，那样利润是假的。

### 第 3 张 · 11-10 水电费 8,000（没票）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 生产水电费 | 510103 制造费用-水电费 | 8,000.00 | |
| 付水电费 | 100201 工行基本户 | | 8,000.00 |

### 第 4 张 · 11-15 领用辅料投入生产

| 摘要 | 科目 | 借方 | 贷方 | 数量 |
|------|------|------|------|------|
| 领用辅助材料 | 500101 生产成本-直接材料 | 10,000.00 | | 100 |
| 领用辅助材料 | 140302 辅助材料 | | 10,000.00 | 100 |

**要点**：这是「材料 → 生产成本」那一步。两边都要填数量，否则库存数量对不上。
月底 140302 的数量余额应该是 0（买 100、用 100）。

### 第 5 张 · 11-20 外发加工费 12,000（宏源，没票，先挂账）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 外发加工费-宏源 | 510105 制造费用-其他 | 12,000.00 | |
| 外发加工费-宏源 | 220201 应付货款（供应商：宏源氧化） | | 12,000.00 |

**要点**：收到发票/对账单但还没付钱 → 贷「应付账款」，别贷银行存款。
这样「我欠别人多少」才准。宏源既是外发厂又是客户的情况，系统按名称识别，会在
「钱在哪」里合并显示净额。

### 第 6 张 · 11-25 完工交货，开票收加工费（含税 113,000，13%）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 华达五金加工费 | 112201 应收货款（客户：华达五金） | 113,000.00 | |
| 氧化加工费 | 600102 服务收入 | | 100,000.00 |
| 销项税额 | 22210102 销项税额 | | 13,000.00 |

**要点**：收入按**不含税** 100,000 记，税金单独挂「销项税额」。这是收加工费，
所以用「服务收入」；如果是卖自产货物，用 600101 产品销售收入。

> 「完工交货」不看开没开票：只要货交了/活干完了，就该确认收入。有票没票都一样记。

### 第 7 张 · 11-26 收到华达货款 113,000

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 收到华达货款 | 100201 工行基本户 | 113,000.00 | |
| 收到华达货款 | 112201 应收货款（客户：华达五金） | | 113,000.00 |

**要点**：收到钱是「冲应收」，**不是**再记一次收入。新手最常犯的错就是这个：一收钱就
贷记收入，收入翻倍。

### 第 8 张 · 11-28 付宏源外发加工费 12,000

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 付宏源加工费 | 220201 应付货款（供应商：宏源氧化） | 12,000.00 | |
| 付宏源加工费 | 100201 工行基本户 | | 12,000.00 |

### 第 9 张 · 11-30 计提 11 月工资（生产 15,000 + 管理 5,000）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 生产工人工资 | 510101 制造费用-工资 | 15,000.00 | |
| 管理人员工资 | 660201 管理费用-工资 | 5,000.00 | |
| 计提 11 月工资 | 221101 应付职工薪酬-工资 | | 20,000.00 |

**要点**：**计提**和**发放**是两张凭证。计提是「这个月该付的工资」，发放时再
借 221101、贷 100201。小厂常用「当月计提当月发」，那就两张都做。

### 第 10 张 · 11-30 计提折旧（生产 3,000 + 管理 1,000）

| 摘要 | 科目 | 借方 | 贷方 |
|------|------|------|------|
| 生产设备折旧 | 510102 制造费用-折旧费 | 3,000.00 | |
| 管理折旧 | 660205 管理费用-折旧费 | 1,000.00 | |
| 计提折旧 | 1602 累计折旧 | | 4,000.00 |

**要点**：折旧记「累计折旧」这个**备抵科目**，不直接冲固定资产原值。
所以报表上「固定资产」＝ 原值 − 累计折旧。

### 录完自查（1 分钟）

去「科目余额表」，看最下面一行的合计数：

```
期初  借 240,000.00   贷 240,000.00   ✅ 平
本期  借 318,300.00   贷 318,300.00   ✅ 平
```

两个数不相等就说明有凭证录错了，回「凭证查询」逐张看——不平衡的凭证系统本来就存不进去，
所以这里不平通常是**期初**或**漏了一个科目**。

## 三、月末 20 分钟：结转 → 出表

### 第 1 步：查漏（3 分钟）

首页会直接告诉你：`⚠ N 张凭证还没记账，未计入下面的数字`。有提示就先去「凭证查询」
批量记账（未记账的凭证不进任何报表）。

### 第 2 步：结转损益（2 分钟）

去「期末处理」→「结转损益」，系统自动生成一张结转凭证。**这张凭证是它算的，不要手写。**

11 月实际生成的就是这 9 行：

| 科目 | 摘要 | 借 | 贷 |
|------|------|----|----|
| 500101 生产成本-直接材料 | 结转本期损益 | | 10,000.00 |
| 510101 制造费用-工资 | 结转本期损益 | | 15,000.00 |
| 510102 制造费用-折旧费 | 结转本期损益 | | 3,000.00 |
| 510103 制造费用-水电费 | 结转本期损益 | | 8,000.00 |
| 510105 制造费用-其他 | 结转本期损益 | | 27,000.00 |
| 600102 服务收入 | 结转本期损益 | 100,000.00 | |
| 660201 管理费用-工资 | 结转本期损益 | | 5,000.00 |
| 660205 管理费用-折旧费 | 结转本期损益 | | 1,000.00 |
| 4103 本年利润 | 结转本期损益 | | 31,000.00 |

**读这张凭证的方法**：把所有收入和成本费用「清零」，差额进「本年利润」。
贷方的 31,000 就是这个月的净利润（赚的记贷方，亏的会记借方）。

> **成本类科目（5001/5101）也会被结转**，所以结转完制造费用余额是 0。
> 这些支出从来不走 6401 主营业务成本——这是小加工厂的正常做法，不用再做「成本结转凭证」。

### 第 3 步：结账（1 分钟）

「期末处理」→「结账」。结账之后这个月就锁了，想改要先「反结账」。
**顺序不能反：先结转损益，再结账。**

### 第 4 步：出表（10 分钟）

「会计报表」里四张表都点一遍。下面是这次 11 月的真实结果。

#### ① 利润表（2026-11）

| 项目 | 金额 |
|------|------|
| 一、营业收入 | 100,000.00 |
| 减：营业成本 | 63,000.00 |
| 　　管理费用 | 6,000.00 |
| 二、营业利润 | 31,000.00 |
| 三、利润总额 | 31,000.00 |
| 四、净利润 | **31,000.00** |

营业成本 63,000 是这么来的：直接材料 10,000 ＋ 制造费用 53,000（房租 15,000、水电 8,000、
外发加工 12,000、生产工资 15,000、生产折旧 3,000）。

**这张表的净利润必须和首页那个大字一模一样**（都是 31,000）。如果不一样，说明有版本问题，
去 `报表 → 利润表` 和首页对一下，报给我们。

#### ② 资产负债表（2026-11 期末）

| 项目 | 期末余额 |
|------|---------|
| 货币资金 | 266,700.00 |
| 流动资产合计 | 266,700.00 |
| 固定资产 | 36,000.00 |
| 资 产 总 计 | **302,700.00** |
| 应付职工薪酬 | 20,000.00 |
| 应交税费 | 11,700.00 |
| 负 债 合 计 | 31,700.00 |
| 实收资本 | 240,000.00 |
| 未分配利润 | 31,000.00 |
| 所有者权益合计 | 271,000.00 |
| 负债和所有者权益总计 | **302,700.00** |

三个自查点：

1. **资产总计 = 负债 + 权益**（302,700 = 31,700 + 271,000）——不平就是记错了。
2. **未分配利润 = 利润表净利润**（31,000）——这是三张表之间最有用的一条勾稽。
3. **应交税费 11,700 = 销项 13,000 − 进项 1,300**——这就是这个月该交的增值税（还没算附加税）。

#### ③ 现金流量表

这张表只有**做了现金流量项目标注的凭证**才进得来。这个月现金流是：收 113,000、付 46,300
（材料 11,300 + 房租 15,000 + 水电 8,000 + 加工费 12,000），净流入 66,700。

所以正确的读法是：

1. 先看表底有没有一行提示「未标注现金流量项目 X 元」。**有提示就说明这张表不完整**；
2. 去凭证里给银行/现金那几行补「现金流量项目」（销售商品收到的现金、购买商品支付的现金、
   支付职工薪酬……）；
3. 补完再看三段（经营/投资/筹资）的净额。

三个数可以互相对一下：`期末现金 = 期初现金 + 三段净额`，且 `期末现金` 应当等于资产负债表
的「货币资金」（本月份是 266,700）。

#### ④ 往来账龄（要不要催钱）

「往来核销 → 账龄分析」：这个月华达已经结清，所以应收是 0。真实月份里，这里按客户列出
「欠多少、欠了几天」，超过 90 天的会标红——那是该打电话的名单。

## 四、最容易踩的 7 个坑

| # | 现象 | 原因 | 怎么办 |
|---|------|------|--------|
| 1 | 存不进去：`必须填写银行账户/客户/供应商/存货` | 凭证行没补辅助核算 | 按第一节那张表补 |
| 2 | 存不进去：`科目 140301 核算数量，必须填写数量` | 存货科目只填了金额 | 补数量；单价自动算 |
| 3 | 报表看不到这个月的数 | 凭证还是「未记账」 | 首页警告 → 批量记账 |
| 4 | 期初录不进去：`必须录在末级科目上` | 录在了 `1002` 这种一级科目 | 换成 `100201` 这种末级 |
| 5 | 利润表净利润 ≠ 首页净利润 | 老版本（≤v1.8.44）的 bug | 升到 v1.8.45 以上 |
| 6 | 结账后又想改 | 期间已锁 | 「期末处理 → 反结账」→ 改 → **重新结转** → 再结账 |
| 7 | 客户欠款金额不对 | 收款时又记了一遍收入 | 收款是「借银行、贷应收」，不再进收入 |

## 五、每月固定动作清单（打印贴墙上）

```
每月 1—25 日（来一笔记一笔）
□ 收付款：借银行/贷应收（应收），借应付/贷银行（付款）
□ 采购有票：材料不含税 + 进项税额 + 银行
□ 卖货/加工费：应收含税 → 收入不含税 + 销项税额
□ 费用：车间进 5101 制造费用，办公室进 6602 管理费用
□ 工资：计提一张、发放一张
□ 随手看一眼首页「钱在哪」，超 90 天的客户当天打电话

每月最后一天
□ 查漏：首页有没有「N 张凭证还没记账」
□ 计提折旧、计提工资（如果还没做）
□ 结转损益（系统生成，别手写）
□ 结账
□ 出四张表：利润表 / 资产负债表 / 现金流量表 / 账龄
□ 三个自查：资产=负债+权益；未分配利润=净利润；应交税费=销项-进项
□ 备份（桌面版「备份到…」；网页版自己导出 .fbk）
```

## 附：这些数字怎么复现

教程里的每个数都能重跑一遍（需要装 Rust 环境，仅开发者用）：

```bash
cargo run --release --example tutorial_nov -p findb
```

它会新建一个临时账套、录完这 10 张凭证、生成结转凭证，然后把试算平衡、利润表、
资产负债表、首页口径一起打印出来。改数字再跑，就知道某笔业务会怎样影响报表。
