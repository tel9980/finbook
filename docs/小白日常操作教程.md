# 小白日常操作教程：一个月只要点这几个地方

> 给第一次用电脑记账的人看。**不用懂会计**，照着点就行。
>
> 这一份只讲「日常怎么点」。想弄清一张凭证为什么这么写 → [小加工厂财务教程](小加工厂财务教程.md)；
> 规则、口径、各种坑 → [记账共通附录](记账共通附录.md)；某个功能到底能干什么 → [功能参考](功能参考.md)。

---

## 〇、先记住三句话

1. **你的账就是一个文件**（`.fbk`）。备份 = 把这个文件复制一份到 U 盘。
   软件不联网、不上传、不收费。
2. **来一笔钱的事，记一张凭证；月底点四五个按钮收尾。** 就这两件事。
3. **看不懂的菜单不用管。** 左侧最多显示十几个常用项——
   要用的不在里面，就在顶上搜索框打名字（比如打「利润」），搜到直接点。

三个词听懂了就够：

| 词 | 大白话 |
|---|---|
| 科目 | 这笔钱「算什么」——房租、电费、工资、加工费收入 |
| 凭证 | 一张记账单：**借**谁、**贷**谁、多少钱。一张单上借方合计必须等于贷方合计 |
| 结转 | 月底把「收入/成本/费用」倒进「本年利润」，算出这个月挣了多少 |

## 一、每天（一笔业务 3 分钟）

### 1.1 打开

双击 `finbook.exe` →「打开已有账套」→ 选中你的 `.fbk` 文件 → 登录。
第一次是 `admin` / `admin123`，打开后系统会让你改密码，**改成自己好记的**。

打开后默认在 **「首页」**（左侧最上面那个）。

### 1.2 记一张凭证：点左侧「填制凭证」

一张凭证就是一行行抄下来：

```
摘要：付 11 月房租
借：510106 厂房租金      15,000
贷：100201 银行存款      15,000
```

填完点 **「保存」**，再点 **「记账」**——**这一步最容易漏**：
存下来的凭证只是草稿，报表只认「已记账」的。

### 1.2·补、「借」和「贷」到底怎么分（30 秒看懂）

这两个字是记账方向的名称，不是「借钱」「贷款」。一句话：

> **借方 = 钱花到哪去了**（买了什么、变成了什么、该谁欠你）
> **贷方 = 钱从哪来的**（哪个卡付的、欠了谁、挣的什么钱）

一笔业务拆成两行，写在同一张凭证里，**两边的钱数必须一样**，这就是「借贷平衡」。
下面的「差额」变成 **0.00** 才能保存。

还是拿不准？不用背——照 **1.4 那张表**抄，把金额和名字换掉就行。

**软件里也写了这句话**：打开「填制凭证」，分录表格下面有一行灰字，
就是上面这两句；科目是下拉选的，按业务里的词找（电费、房租、收款、原材料、工资）。
看报表时同理：「科目余额表」上面有一行灰字告诉你**只看「期末」这一列**就是月底还剩多少。

### 1.3 四种东西没填，存不进去（系统会提示「必须填写…」）

| 分录里出现这个科目 | 必须补 |
|---|---|
| 银行存款（1002 开头） | 哪张卡/哪个户（下拉选） |
| 应收账款（1122 开头） | 哪个客户 |
| 应付账款（2202 开头） | 哪个供应商 |
| 存货（1403 开头） | 哪个料 + 数量 |

看不到要选的那个客户/供应商？点它旁边的 **「＋新建」**，只填名字就能先用。

> 科目只认**末级**：用 `100201`，不要用 `1002`。填上级科目会提示「必须录在末级科目上」。

### 1.4 五种最常见的事，照这个抄（把金额和名字换掉）

| 事情 | 借 | 贷 |
|---|---|---|
| 付房租、水电、煤气 | 5101 制造费用下的明细（如 510106 厂房租金） | 100201 银行存款 |
| 买化工料（有专票） | 140302 原材料（不含税）+ 22210101 进项税额 | 220201 应付账款（含税） |
| 开票收加工费（13%） | 112201 应收账款（含税） | 600101 加工费收入（不含税）+ 22210102 销项税额 |
| 客户打钱过来了 | 100201 银行存款 | 112201 应收账款 |
| 付供应商货款 | 220201 应付账款 | 100201 银行存款 |

> ⚠️ **收到钱不再记一次收入**，只是「应收」变少。把收款也记成收入，是最常见的错账。
> 没票、收据、微信转账：金额**含税全额**进成本，不拆税。

### 1.5 记错了怎么办（没结账之前）

「凭证查询」→ 找到那张 → **作废** → 重新记一张。
每月都一样的那几张（房租、折旧）→ 左侧搜「凭证模板」，存一次，以后一键生成。

## 二、打开软件第一眼：看那一句话（10 秒）

点左侧 **「首页」**。**不用看懂所有数字**，从上往下只需要看三处。

> 网页版和桌面版（窗口版）都是这三处，判断是同一份 ——
> 不会出现「网页说先催款、窗口说先记账」这种情况。

### 2.1 第一处：那行带 ⚠ 的话

首页中间有一行字，说的就是**接下来该先办哪件事**。它一次只提醒一件，
按这个顺序挑最要紧的说：

| 你看到的话 | 意思 | 怎么办 |
|---|---|---|
| ⚠ 还有 N 张凭证没记账… | 记完没点「记账」，这些不算进利润 | 去「凭证查询」勾选 → 批量记账 |
| ⚠ 账面这个月赚了，但 N 家客户的钱超过 90 天没收回 | 钱压在客户手里了 | 先催这几笔，别的都放后面 |
| 净欠外面 X（欠供应商多于别人欠你） | 该付的钱比该收的多 | 留意付款节奏，看手头现金够不够 |
| 本月还没有收入凭证 | 可能还没开张记第一笔 | 去「填制凭证」记第一笔加工费 |
| 收支正常，暂无卡住的事 | 没有要急着处理的 | 该干嘛干嘛 |

**为什么先提「没记账」**：没记账的凭证不算进利润，这时候显示的赚了多少
**一定是偏小的**。拿着偏小的数去报价、去发工资就会出错 —— 所以它排第一。

### 2.2 第二处：赚了多少 + 钱在哪

那行字上面是**收入、成本、净利润**，下面一块是**钱在哪**：

| 看什么 | 怎么理解 |
|---|---|
| 净利润 | 这个月赚了多少（已经扣掉所有成本） |
| 客户欠我 | 已经干了活、钱还没收回来 |
| 我欠谁 | 料钱、加工费还没付给人家的 |
| 手头现金 | 现在账上能动的钱 |
| 净头寸 | 「客户欠我 − 我欠谁 + 手头现金」，正数说明家底在增厚 |

**小厂最容易出事的地方不是不赚钱，而是赚的钱全压在客户手里、同时房租工资还得按月付。**
所以「客户欠我」和「手头现金」这两个数，比净利润更值得每周看一眼。

### 2.3 第三处：「账有没有记错」

首页靠下有一块 **「账有没有记错」**：

- 显示 **「✔ 账是平的，没有记错的凭证」** → 放心，可以出报表；
- 显示 **「✖ 账不平，有凭证记错了」（并告诉你差多少）** → 去「凭证查询」逐张看，
  通常是某张凭证只填了借方没填贷方。

想看到具体数字（期初、本期、期末各借多少贷多少），点开下面的
**「逐项数字（借方 / 贷方）」** 就展开 —— 平时不用管，会计来对账时才需要。

### 2.4 最下面那个折叠的「账目概况」

点一下会展开：这个月**几张凭证、多少钱进出、余额多少、账套共几个科目**。
也全是自检用的，平时收着就行。

## 二·补、首页那些「看不懂的词」

首页原来有些会计术语，这一版改成了大白话：

| 原来的词 | 现在的说法 | 意思 |
|---|---|---|
| 试算平衡 | 账有没有记错 | 借方合计 = 贷方合计，说明没记错 |
| 本期发生额 | 本期借方合计 | 这个月一共有多少钱记了账 |
| 期末余额 | 期末借方合计 | 月底账上的数 |
| 借贷不平衡 | 账不平，有凭证记错了 | 每笔凭证的借方和贷方必须一样多 |

记不住也没关系：**只要那一行不是 ⚠、那块显示 ✔，就不用管别的。**

## 三、月底：五个动作，顺序不能乱（15 分钟）

都在左侧 **「期末处理」** 里。

| 第几步 | 点什么 | 会看到什么 / 出问题怎么办 |
|---|---|---|
| ① 查漏 | 看「凭证查询」里有没有**草稿** | 有就全选 → 记账。漏一张，这个月的报表就是错的 |
| ② 记账 | 期末处理 →「批量记账本期已审核凭证」 | 一键把本月草稿都记上 |
| ③ 结转损益 | 期末处理 →「生成结转损益凭证」→ 保存 → 记账 | 生成一张把收入/成本/费用转进「本年利润」的凭证。**制造费用会自动转**，不用你自己做 |
| ④ 结账 | 期末处理 →「期末结账」 | 结完这个月就锁了，不能再改。有没记账的凭证会拦住你 |
| ⑤ 出表 + 备份 | 「会计报表」看一眼 + 「备份恢复」备份 | 见下面第四、五节 |

### 结错了 / 老板说这张要改

「期末处理」→ **「反结账当前期间」** → 改凭证 → **重新做一遍 ③ 结转**（重要：反结账后旧的那张结转凭证要作废，重新生成，否则利润会重复）。

三条系统会拦你的规矩：上一期没结不能结下一期；结转凭证不能手工删；反结账要管理员权限。

### 12 月多做一件事

结账前先做 **「年末结转」**（本年利润 → 利润分配）。顺序：结转损益 → 年末结转 → 结账。

## 四、老板最该看的一张表：利润分析表

这张表**不是**会计口径的利润表，而是照厂里那张写了很多年的纸做的：
收入一行，下面厂租、电费、水费、化工、染料、工资、包装、货车、外发加工、税金、社保、业务费、办公、维修、挂具，最后一行净利润。

点左侧 **「利润分析表」**（精简模式下看不到就在搜索框打「利润」）。

### 4.1 第一次用：让它自己认科目（只做一次）

表上这些名字，账里的科目未必叫这个（厂里叫「厂租」，账上是「厂房租金」）。两个按钮：

| 按钮 | 干什么 | 什么时候点 |
|---|---|---|
| **「自动挂科目」** | 按**现有科目的名字**对一遍，先给你看「哪行挂哪个科目」，你看过再点「应用这 N 行」 | 账已经记了一阵子（**推荐先用这个**） |
| **「按这张表生成科目」** | 账里实在没有对得上的，才在「5101 制造费用」下新建一个同名科目 | 新账套、什么都没挂上时 |

两个按钮都是**先认已有的、认不出才新建**，不会给你造出第二套重复科目。
点完表格里每行右边应该有科目名了，没有的会标黄「未挂科目」——那几行要么手工挂，要么那笔钱本来就记在别的科目上（见 4.3）。

### 4.2 每月看一眼（结账后来）

表下面的合计就是三行数：

- **收入**：本月加工费收入
- **支出**：表上 15 行的合计
- **净利润**：收入 − 支出

比看利润表快，因为每一行就是老板嘴里的那个词。

### 4.3 表下面那行黄字是什么意思（很关键）

如果出现类似：

> 还有 8,730.00 元费用没落到表上任何一行（510102 折旧费 6,000.00、660303 手续费 100.00…）

意思是：**账上还花了这些钱，但这张表的 16 行里没有它的位置**，所以「支出」这一栏少了它。

两个选择，都对：

1. **让它看得见**：点「编辑」加一行（比如「折旧」），把这几个科目挂上去；
2. **不管它**：心里清楚「净利润 25,849.18 + 表外 8,730.00 = 账上真实净利 17,119.18」。

规矩只有一条：**表上支出 + 表外体检 = 账上真实支出**。等式成立，这张表就能拿去给老板看。

### 4.4 产量为什么是空的

第一行「收入：月总产量」要读生产工单里的完工数量。
**没录生产工单就留空**——空着是「还没录」，不是「产量 0」，别当成软件坏了。
要用产量：先在「制造管理」里录生产工单/完工，再回来看这张表。

## 五、备份：每月一次，比记账重要

左侧 **「备份恢复」**：

| 按钮 | 说明 |
|---|---|
| **「备份到…」** | 挑个位置存一份（U 盘、D 盘都行）——**最常用** |
| 「备份到同目录」 | 存到账套旁边，名字带日期 |
| **「自动备份（保留 N 份）」** | 设一次，以后每次打开自动备，省心 |
| 「从备份文件恢复…」 | 换电脑、文件坏了，用这个 |

三条铁律：

1. **备份完要打开确认**：提示损坏、打不开、只有 0 字节——这三种都不算备份成功。
2. **不要放在网络共享盘上让两台电脑同时打开**，会把账套弄坏。
3. 换电脑 = 把 `.fbk` 复制过去，用「打开已有账套」打开，就这些。

## 六、网页版多出来的两样（手机/别的电脑也能用）

桌面版没有、网页版才有的两个常用页：

| 在哪 | 干什么 |
|---|---|
| 资金管理 → **电费台账** | 加工厂电费是先充卡、按用量扣：① 充值（只动预付卡，不算费用）② 月底抄表（只登记用量）③ 一键结转（这时才进电费，并自动拆进项税） |
| 往来核销 → **收款认领** | 客户打来一笔钱、说不清是哪几张单：在这里把这笔钱认给一个或多个客户/单据，账上不用你手写分录 |

## 七、和客户、供应商对账（每月一次，20 分钟）

月底把账记完，还有一件事：**和客户、供应商核一遍，看数对不对**。
对账不改账——对完你才决定要不要调。

### 7.1 对账在哪儿

左侧「期末」组里的 **应收应付对账**（桌面版和网页版都有，界面一样）。

### 7.2 三步走

1. **选一边、选月份，点「新建这次对账」**
   名单会自动按账面列出来：欠你钱的客户（或你欠的供应商）一个个都摆好了，
   金额先等于账面上的数。
2. **把对方报来的数改上去**
   客户发来对账单说"我欠你 12,000"，你就把那一行的金额改成 12,000。
   **差额自己就冒出来了**：差 0 显示「对上了」，不为 0 显示「差多少」。
   对方发来的是 Excel/截图？点下面的「粘贴导入」，一行一户：`客户编码,金额`。
3. **对好了点「确认这一批」**

### 7.3 点确认会发生什么

- 全部对上了 → 只标「已确认」，**账上什么都不动**。
- 有差额 → 差额汇总成**一张草稿凭证**（比如差 200，就做一张 200 的调整凭证）。
  它只是草稿：去「凭证查询」看一眼，审核、记账，账才真的变。
  不想记账就删掉，账上等于没发生。

### 7.4 三个常见情况

| 情况 | 怎么办 |
|---|---|
| 对方说欠 12,000，我账上 12,500 | 差 500 先问清是**我们漏记了收款**还是**对方少算了**；说不清就点「标争议」先放着，不影响其他户确认 |
| 页面说「账面还有 3 户没录进来」 | 这三户账上有余额但对账单上没有。点「加进来」按账面补，或打个电话问 |
| 确认后发现有户填错了 | 点「打回重对」。草稿凭证还在就自动删掉；已经记账了就先反记账再来 |

一句话记住：**对账期间账上一分钱不动，所以可以放心大胆地试。**

## 七·补、报加工费单价（按只、按米、按平方都能算）

同一个工件，车间报给你的是「**300 只**」，客户要的报价单是「**7.02 ㎡ × 12 元**」。
以前这个换算得你自己在纸上算，算错了单子照样出。现在让软件记一次，以后自动算。

位置：左侧「**销售**」组 → **加工费规则**（桌面版和网页版都有）。

### 第一次：只做两件事

1. **告诉软件「1 只折合多少」**
   点「录折算系数」，一行一个口径：

   | 物料 | 口径 | 1 个折合 |
   |---|---|---|
   | MB01 | ㎡ | 0.0234 |
   | MB01 | kg | 0.0012 |

   意思是「1 只 = 0.0234 ㎡」。一个物料想按几种算法卖，就录几行。
2. **在矩阵里填价**
   表里一行一个工件、一列一种算法。哪一格有价就填哪一格，填完立刻生效。
   没定价的格子空着就行 —— **别填 0**，填 0 等于白送。

### 开单的时候

填「数量 300」、口径选「㎡」，软件自己算给你看：

```
300 只 × 0.0234 = 7.02 ㎡
7.02 ㎡ × 12.00 = 84.24
```

起步价、加急费照旧自动加。

### 调价

- **改现在的价**：格子里直接把数字改掉，改完就生效。
- **提前录下一版价**（客户说 3 月 1 日起调价）：点格子旁的「调」，
  填新价 + 生效日写 `2026-03-01`。到那天自动换过来，**旧单仍按旧价**，
  不用你月底回来改一趟。

### 价目表整张导进来（客户发来一张 Excel 的时候）

1. 点工具栏的**批量导入**，导入什么选「单价」。
2. 打开客户发来的表，**连着表头一起**全选复制，粘到框里（也可以直接选那个 `.xlsx` 文件）。
3. 点**开始导入**，结果会写清楚：`新增 12 条、覆盖 3 条、跳过 2 行`。

   三句话的意思：
   - **新增**：新的价，加进去了；
   - **覆盖**：这一格原来就有价，这次被改成了表上的数（同一格不会变成两条）；
   - **跳过**：那一行有问题，下面会写「第 7 行：单价「abc」不是数字」，
     照着行号回 Excel 改一行，再导一次就行 —— **不用整张重来**。

列的顺序（第一行照这个写，或者点「下载模板」）：

```
物料编码,客户编码,计价口径,单价,起步价,加急固定费,加急率%,生效日期,名称,备注
MB01,,㎡,12.00,30.00,,,,,
MB02,C01,只,0.45,,,,,,
```

- 「客户编码」空着 = 所有客户都这个价；填了 = 只给这个客户。
- 后面的列可以整列删掉，只留前四列也能导。
- 折算系数也能这样导（导入什么选「折算系数」，四列：物料编码、计价口径、系数、保留位数）。
- 想提前录下一版价：加一列生效日期，写 `2026-03-01`。同一格不同生效日算两版价，互不覆盖。

### 三个常见情况

| 看到什么 | 怎么办 |
|---|---|
| 格子下面写「未设系数 · 点这里录」 | 价能填、但还没告诉软件「1 只折合多少 ㎡」，点那行小字去录 |
| 报价说「这一格还没定价」 | 那个口径没填价。**不会**拿别的口径的价凑给你 |
| 报价说「X 月 X 日才生效」 | 你提前录了下一版价，现在报的是未来的价 —— 想按现在的价卖，就再录一条今天的价 |

### 按规格算：客户说「2.5 元一米」「80 元一个平方」

客户报价常这么说，工件给的却是规格，比如 `1200*80`、`1250*250*3`（毫米）。
你不用再拿计算器按一遍，直接让软件算：

1. 工具栏下面「按规格算单价」那一块，填**单价**（`2.5`），口径选**米**。
2. 把规格整列粘进大文本框（从 Excel 直接复制，一行一个）：

```
1200*80
920*60
1250*250*3
```

3. 点**算单价**，出来一张表：

| 规格（毫米） | 1 件折合 | 单件价 |
|---|---|---|
| 1200×80 | 1.2000 | 3.00 |
| 920×60 | 0.9200 | 2.30 |
| 1250×250×3 | 0.3125 | 25.00（按 80 元/㎡ 时） |

- 按**平方**算：口径选「㎡」，只要写两维（`1250*250`），厚度不影响面积。
- 按**重量**算：口径选「kg」，必须写三维 + 密度（钢 7.85、铝 2.70、铜 8.90，那一格能改）。
- 写**一维**（只写 `1200`）会被拒：「看不懂这个规格」。软件不猜 —— 猜错一个数，
  报价单上看着正常，实际差几十倍。

**这张表只是算给你看的，不落库。** 算完想用，就把「单件价」填进矩阵对应那一格
（或者在矩阵里录一次折算系数，以后开单自动算）。

**已经在矩阵里录过系数了怎么办？** 以你录的为准。人工核对过的实测值比规格算出来的
近似值可靠，软件不会反过来说「我按规格重算了一遍」。

### 同一个件两种氧化（普通 / 硬质），价不一样怎么办

同一个工件，客户可能同时要「普通氧化 12 元/㎡」和「硬质氧化 18 元/㎡」。
这两个价属于同一个物料、同一个客户、同一种口径，只差一道表面处理 —— 用**工艺档**分开：

1. 矩阵工具栏「工艺」那一格**留空**，正常录普通氧化的价（12）。
2. 再在「工艺」里填 `硬质氧化`，录 18。两档各存一条，互不覆盖。
3. 开单/试算时，试算框的「工艺」填什么就按哪一档报；**不填就按不分档的价算**。

几条要记住的：

- **没填工艺，绝不会拿到档位价。** 这是故意的：报了硬质氧化的价，客户拿普通氧化的
  单子来对账，一句「系统算的」反而说不清。
- 某一档没单独定价时，矩阵那格会标「**用通用价**」，说明它沿用的是不分档那条。
  这个标记要当真 —— 别以为定过价了。
- 批量导入时模板最后一列是「工艺档」，客户把价目表做得再乱也能导：**有表头就按列名
  对齐**，列的顺序随你排，表里没有的列当没填。

## 八、常见问题

| 问 | 答 |
|---|---|
| 双击打不开 / 闪退 | 确认下载完整；Windows 提示「已保护你的电脑」→「更多信息」→「仍要运行」 |
| 忘记密码 | 新账套就重建一个；已有的找装软件的人重置（`reset_pwd`） |
| 左侧菜单怎么只有十几个 | 顶上搜索框打名字就能找到；想显示全部，把搜索框下面的「精简模式」勾掉 |
| 存凭证说借贷不平 | 右上角有差额，对着找。借方合计必须等于贷方 |
| 报表里没有我刚记的凭证 | 那张还是草稿，点「记账」 |
| 净利润和银行卡余额对不上 | 正常。净利润是「挣了多少」，银行卡余额是「手里还有多少钱」，中间有欠款、有存货、有固定资产 |
| 利润分析表「支出」比账上花的少 | 看表下面那行黄字（4.3），差额就在那儿写着 |
| 能装到公司电脑给会计用吗 | 可以，复制 `.fbk` 过去就行；但**不要多人同时打开同一份** |
| 数据会上传吗 | 不会，完全离线 |
| 我要的功能找不到 | 顶上搜索框打名字；真没有就去 GitHub 提 issue |

## 九、打印版速查卡（贴墙上）

```
每天：一笔业务 → 填制凭证 → 保存 → 记账
月中：首页看三处 —— 那一行 ⚠ 说了什么？赚了多少？账是不是 ✔ 平的？

月底（顺序不能乱）：
  ① 查漏：凭证查询里还有草稿吗
  ② 记账：期末处理 → 批量记账
  ③ 结转：期末处理 → 生成结转损益凭证 → 记账
  ④ 结账：期末处理 → 期末结账
  ⑤ 出表：会计报表 + 利润分析表
  ⑥ 对账：期末 → 应收应付对账 → 新建 → 改对方的数 → 确认（只造草稿）
  ⑦ 备份：备份恢复 → 备份到… → 打开确认能打开

五条不能忘：
  · 收到钱不是收入（贷应收）
  · 没票按含税全额进成本
  · 表上支出 + 表外黄字 = 真实支出
  · 对账过程不动账，确认只造草稿凭证
  · 备份完要打开试一下
```
