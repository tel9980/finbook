## 一、一张凭证的四样「必填」

存不进去、提示「必须填写…」，十次有九次是这四样没补：

| 分录行里出现这个科目 | 必须补什么 | 补在哪 |
|---|---|---|
| 100201 / 100202 银行存款 | **银行账户** | 分录行的「银行账户」格子，下拉选 |
| 1001 库存现金 | 不用补（默认就是现金） | —— |
| 112201 应收账款 | **客户** | 分录行的「客户」格子 |
| 220201 应付账款 | **供应商** | 分录行的「供应商」格子 |
| 140301 / 140302 等存货科目 | **存货** + **数量** | 「存货」下拉 + 「数量」填数字 |
| 112101 银行承兑汇票（应收票据） | **客户** | 同应收 |

三条经验：

- **系统只认末级科目**。`1002` 是一级，下面有 `100201/100202`，所以期初和凭证里都只能用 `100201`。期初录在 `1002` 上会报「必须录在末级科目上」。
- **一个户还是一笔一选**：按实际走哪条路收款就选哪个，同一个客户这次打对公、下次打结算户，各记各的。月底对着银行流水能逐笔对上，这是整套账最值钱的地方 —— **对不上的那几笔，就是有问题的那几笔**。
- **数量科目只提醒不拦**：数量 × 单价 与金额差几分钱（取整、抹零）只提醒，照存。

## 二、金额口径：按票面填，税额单独拆

一张采购发票到手，**问的第一句永远是「什么票、几个点」**，因为它决定金额怎么拆：

| 拿到的票 | 入账金额 | 进项税 | 说明 |
|---|---|---|---|
| 增值税**专用**发票（13% / 9% / 3%） | 不含税金额 | 单独进 `22210101 进项税额` | 必须**已认证**才能抵 |
| 增值税**普通**发票 | 含税全额 | 不拆 | 普票不能抵进项 |
| 收据 / 白条 / 微信截图 / 没票 | 含税全额 | 不拆 | 所得税上也未必认，能要票就要票 |

含税 10,300 的三个例子（一般纳税人）：

| 情况 | 借 | 贷 |
|---|---|---|
| 13% 专票 | 材料 9,115.04 + 进项税 1,184.96 | 应付 10,300 |
| 3% 专票（小规模供应商开的） | 材料 10,000.00 + 进项税 300.00 | 应付 10,300 |
| 无票 | 材料 10,300.00 | 应付/现金 10,300 |

小规模纳税人的账套**没有进项抵扣**：所有票一律全额进成本，税只算销项（3% 或 1%）+ 附加。

**销售开票同理**：开出去的专票，不含税金额进收入（`600101`），税额进 `22210102 销项税额`。收款时是「借银行、贷应收」，**不再进一次收入** —— 把收款也记成收入，是最常见的一类错账。

## 三、操作常识

| 情况 | 怎么做 |
|---|---|
| 借贷不平 | 系统会拦住你，右上角显示差额，对着找 |
| 金额差几毛 | 系统只提醒不拦，继续保存就行 |
| 忘了记账 | 凭证存下来先是**草稿**，点「记账」才算数（报表只认已记账的） |
| 记错了（未结账） | 凭证查询 → 找到那张 → 作废 → 重新记一张 |
| 每月都一样的（房租、折旧） | 导航「凭证模板」，存一次，以后一键生成 |
| 老板垫钱买的 | 借：费用科目 / 贷：其他应付款 `2241`（别记成现金，现金没动） |
| 科目已被用过又想改辅助核算 | 系统会拦。用「停用」代替删除，另建新科目 |
| 想删客户/供应商档案 | 已有凭证引用就删不掉。改成「停用」 |

## 四、月末固定动作

### 通用五步（每个月都要走）

```
① 查漏：首页/凭证列表看有没有「未记账」的凭证 → 全部勾选 → 记账
② 结转损益：期末处理 → 结转损益 → 生成凭证 → 记账
③ 结账：期末处理 → 结账
④ 出表：会计报表 → 利润表 / 资产负债表 / 现金流量表
⑤ 备份：备份恢复 → 一键备份
```

顺序不能颠倒：**没结转损益就结账，系统会报「损益类尚未结转」**。

> 每一步点哪个菜单、看哪个提示，见 [日常记账手册](日常记账手册.md) 第四节的逐步说明（含截图式点法）。

### 12 月多两步（年末结转）

```
① 12 月正常结转损益（月结）
② 期末处理 → 结转损益页 → 年末结转 → 生成凭证 → 记账
③ 检查 4103 本年利润是否归零（归零才对，说明利润已转入 4104 利润分配）
④ 结账 → 备份，文件名标「2026年决算」
```

本月亏损时 4103 是借方余额，年末结转方向反过来即可，系统会自动判断。

### 结错了怎么改：反结账

结账后账就锁了，改要按这个顺序：

```
期末处理 → 反结账 → 改凭证（改完要重新记账）→ 重新结转损益 → 重新结账
```

三条会被系统拦住的规矩：

1. **只能从最后结账的期间开始反**。12 月已结账，想改 11 月，先反 12 月。
2. **反结账后必须重新结转损益**。补的凭证里有收入/费用，不重新结转，4103 和利润表都对不上。
3. **反结账不清空已生成的报表**，但报表要重新生成才反映改动。

## 五、每月固定动作清单（打印贴墙上）

```
每月 1—25 日（来一笔记一笔）：
  □ 收付款当天就记，别攒（攒到月底必然对不上银行流水）
  □ 采购/销售的票到手就录，专票顺手点「认证」
  □ 每周五看一眼首页「钱在哪」

每月月底（约 15 分钟）：
  □ 上月的凭证全部记完，勾选全部 → 记账
  □ 期末处理 → 结转损益 → 记账
  □ 期末处理 → 结账
  □ 会计报表 → 看利润表、资产负债表是否合理
  □ 备份恢复 → 一键备份

每年 12 月结账时（多两步）：
  □ 12 月正常结转损益
  □ 期末处理 → 结转损益页 → 年末结转 → 记账
  □ 检查 4103 本年利润是否归零
  □ 结账 → 备份，标「2026年决算」

每季度：
  □ 打一份客户对账单寄出去（应收账龄超 90 天的先打）
  □ 看「科目余额表」，5101 制造费用有没有异常余额（月末应为 0）
```

## 六、出问题了怎么办

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 试算不平 | 期初有错 | 期初建账页找差额 |
| 结转提示「净发生额为 0」 | 已经结过了 | 正常，直接去结账 |
| 首页净利润跟利润表不一致 | 有凭证没记账 | 首页黄字会提示，批量记账 |
| 报表看不到这个月的数 | 凭证还是「未记账」 | 同上 |
| 存不进去：`必须填写银行账户/客户/供应商/存货` | 分录行没补辅助核算 | 见本附录第一节那张表 |
| 存不进去：`科目 140302 核算数量，必须填写数量` | 存货科目只填了金额 | 补数量，单价自动算 |
| 期初录不进去：`必须录在末级科目上` | 录在了 `1002` 这种一级科目 | 换成 `100201` 这种末级 |
| 客户欠款金额不对 | 收款时又记了一遍收入 | 收款是「借银行、贷应收」，不再进收入 |
| 客户名改了首页没变 | —— | 系统是实时的，刷新一下 |
| 结账后发现记错 | 账已锁定 | 反结账 → 改 → **重新结转** → 重新结账 |
| 反结账报「只能从最后结账的期间开始」 | 后面月份已结账 | 先按月倒着反，从最后一个月开始 |
| 补账后结账提示「损益类尚未结转」 | 补的凭证有费用/收入 | 再点一次结转损益即可 |

## 七、十二个新手规矩

前六条**任何账套都适用**，后六条分纳税人身份。

**通用六条**

1. **客户的料不是你的货**：来料只在摘要写清（哪家、什么货、大概数），**不进库存、不做凭证**。你只对「加工费」和你自己买的材料记账。
2. **收付不用对发票**：一律按实际发生记，余额轧差就是欠/剩。客户多付了（`112201` 借方负数）就是预收，不用另立科目。
3. **只有实际收到的钱才算收款**，承兑汇票收到时记 `112101 银行承兑汇票`，它到期前是「你手里的钱」，报表上单独一行，但**账户里没有现金**。
4. **费用按「谁受益」分**：车间发生的进 `5101 制造费用`（月底转成本），办公室发生的进 `6602 管理费用`。混在一起，成本算不准、利润也看不出问题在哪。
5. **每笔记清摘要**：`11-08 收宏远汽配 10 月加工费` 比 `收款` 有用一百倍 —— 三个月后你自己也要靠摘要回忆。
6. **月末必做的两件事**：结转损益 + 备份。备份是唯一能救「误删账套」的动作。

**小规模纳税人（3%/1%）额外注意**

7. **没有进项抵扣**：买料的票只留着备查（所得税上还有用），税只算销项 + 附加。
8. **月销售额 10 万以下免增值税**（小规模优惠，政策会变，按当年口径）：所以小规模的账**重点不在税，在把成本记全**。

**一般纳税人（13%/9%/6%）额外注意**

9. **只有专票能抵进项，而且要「已认证」**：普票、收据、白条、微信转账截图都不能抵。采购前先问「能开专票吗、几个点」，比事后算账便宜得多。
10. **每一个月都要算「应交增值税 = 销项 − 进项」**，月末转出未交增值税、计提附加税（城建 7% + 教育 3% + 地方教育 2%），三步一张不少。
11. **充值卡、预付款不是费用**：电卡充值时只是「钱换了个地方待着」（`112301 预付电费`），抄表才进成本。同理，预付供应商的货款是 `1123 预付账款`。
12. **税负高低主要看「有票支出占收入多少」**，不是看税率：人工占比高的加工厂，进项天然少，税负 10% 左右是常态（见一般纳税人手册第四节的实测构成）。

## 八、这个系统不管的事

找功能之前先看一眼，这些**故意不做**，别浪费时间找：

- **生产线设备折旧**（固定资产模块只做最简单的直线折旧录入，不做卡片/变动管理）
- **MRP / 工艺路线 / 工序报工 / 计件产量统计**——只做财务，不做生产
- **多维度利润分析、预算管理、合并报表**——小厂用不上
- **自动报税**（不上传税局）：申报表可以取数、可导出，最后仍要到电子税务局手工申报

导航栏默认是「精简模式」，只显示日常要用的菜单。想全看，去「账套参数」取消勾选。
