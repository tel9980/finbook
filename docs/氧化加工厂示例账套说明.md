## 二、日常业务 → 分录对照（8 类，照抄格式换金额）

### 1. 完工开票（转字）：加工费 + 3% 税=含税应收

```
借：112201 应收货款—客户        含税总额
　贷：600101 氧化加工费收入      不含税
　贷：222102 未交增值税          税额（小规模挂这里，下月缴）
```
对照：转1（A厂 92700=90000+2700）、转2（B厂 57680）、转8（C厂 39140）。

### 2. 收加工费（收字）：收多少记多少，不用跟发票一一对应

```
借：100201 / 1001               实收金额
　贷：112201—客户               实收金额
```
对照：收1（收回10月 68000）、收2（微信收 A 50000，欠 92700 只收一半）、
收5（A 再收 40000，还剩 2700 尾款）。
**B 厂收 30000（收3）时账上已结清，这 30000 就是预收**——不用另设科目，
112201 出现负数（−30000）就是预收，下批开票自动冲掉。

### 3. 买化工料（转字）：进 140302，数量单价必填

```
借：140302 辅助材料—品名        金额（数量×单价，品名挂存货档案）
　贷：220201—供应商 / 银行       金额
```
对照：转3（三酸8吨挂账）、转4（片碱+色粉 N银行付现、无票）、
转10（除油剂+亚钠挂账）。**一种料一行**，单价照进货单写。

### 4. 付供应商（付字）：付多少记多少，欠多少账上自然剩多少

```
借：220201—供应商               实付金额
　贷：100201 / 1001             实付金额
```
对照：付1（恒信欠 53800 付 30000，剩 23800）、付6（微信付大发 20000，
欠 40200 剩 20200）。**不用指明还的是哪一笔**，余额就是真相。

### 5. 委外加工（转字付字）：直接进费用，不走库存不走生产模块

```
挂账：借：510108 委外加工费      贷：220201—外发厂
现付：借：510108 委外加工费      贷：银行/现金
```
对照：转5（喷砂挂账 18000）、付4（抛光现付 9600）、转11（拉丝挂账 7200）。

### 6. 房租水电化工领用（付字/转字）

### 7. 工资两步（转字 + 付字）

## 四、四个新手必懂的规矩

1. **客户的料不是你的货**：来料只在摘要写清（哪家、什么货、大概数），**不进库存、不做凭证**。你只对"加工费"和"你买的化工料"记账。
2. **收付不用对发票**：一律按实际发生记，余额轧差就是欠/剩。客户多付了（112201 负数）就是预收，不用另立科目。
3. **票据只有两句**：收到票"应收账款→应收票据"，兑付/背书"票据→银行/应付"。到期前它是你手里的钱，报表上单独一行。
4. **小规模没有进项抵扣**：买料的票只留着备查，税只算销项 3% + 附加。哪天转一般纳税人了再启用进销项两栏。

日常节奏：有业务就填凭证（收/付/转）→ 月底做"月末三步"→ 期末处理结账 → 备份恢复点一键备份。
