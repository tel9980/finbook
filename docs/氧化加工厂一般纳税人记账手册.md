## 〇、先记住一句话：一般纳税人 = 每一笔都要问"票呢？"

小规模：收入 × 3%，买料不要票也没关系。
一般纳税人：**销项（收到的税）− 进项（付出去的税）= 要交的税**。
所以这本账里，**每一张采购/费用凭证都多一行 22210101 进项税额**——
这一步不是会计爱麻烦，是钱：要票就少交税，不要票就自己掏。

## 二、日常业务 → 分录对照（10 类，照抄格式换金额）

### 1. 完工开票（转字）：加工费 + 13% 销项

```
借：112201 应收货款—客户          含税总额
　贷：600101 氧化加工费收入        不含税
　贷：22210102 销项税额            13%
```
对照：转-1（宏远 226,000 = 200,000 + 26,000）、转-4（精密 169,500 = 150,000 + 19,500）、
转-7（灯具 113,000 = 100,000 + 13,000）。本月不含税收入 **450,000**、销项 **58,500**。
**税是价外税**：谈价时说的 226,000 是"含税价"，账上收入只有 200,000，那 26,000 是替国家收的。

### 2. 买化工料（转字）：进 140302，数量单价必填，票上有多少税就抵多少

```
借：140302 辅助材料—品名          不含税金额（数量×单价，品名挂存货档案）
借：22210101 进项税额             13%（或 3%）
　贷：220201—供应商 / 银行        含税总额
```
对照：转-2 硫酸 8 吨×1,200 含税（不含税 8,495.58 + 税 1,104.42）、转-3 磷酸、转-5 硝酸、
转-6 片碱、转-8 亚钠、转-9 染料 200 公斤（以上 S01，13%）；
转-10 除油剂 20 桶、转-11 封闭剂 15 桶（S03，**3% 征收率**，只能抵 3%）。
**一种料一行**，单价照进货单填；3% 的票和 13% 的票分录长得一样，只是税少。

### 3. 领用化工料（转字）：数量单价必填，这是"成本"真正发生的地方

```
借：510107 化工材料               不含税金额
　贷：140302 辅助材料—品名        同上（数量照领料单）
```
对照：转-18 一张凭证 8 行，期初 15,320 + 本月购入 53,730.99 = **69,050.99 全部投产**，
期末库存 0（小厂月底基本吃干净，这也是一种对账手段：库存表该是 0）。
单价用**加权平均**：例如硫酸（2,000 + 8,495.58）/（2 + 8）吨 = 1,049.56。

### 4. 电费充值 + 月底抄表（付字 + 转字）：本账最特别的一条

```
充卡： 借：112301 预付电费        20,000
       　贷：100202 N银行结算户     20,000      ← 付-1，此时没成本

抄表： 借：510103 水电费（车间）   15,929.20    ← 记-1（台账结转出来的）
       借：22210101 进项税额       2,070.80
       　贷：112301 预付电费        18,000
```
电卡余额 6,000 挂在 112301（期初 4,000 + 充 20,000 − 用 18,000），下月接着用。
**千万不要充值时直接记水电费**——那样 12 月没充值的月份，成本就凭空变少了。

这张抄表凭证**不用手写**：打开「资金管理 → 电费台账」，登记一行（抄表日 11-30、
表号 E-01、用量 15,000 度、含税单价 1.20、税率 13%），再点「结转本期」，
系统就把「借 510103 15,929.20 + 借 22210101 2,070.80 / 贷 112301 18,000」开出来并记账。
台账上那一行会显示凭证号，点开就是这张凭证——量、价、税、账四处对得上。

### 5. 收加工费（收字）：收多少记多少，不用跟发票一一对应

```
借：100201 / 100202 / 1001        实收金额
　贷：112201—客户                实收金额
```
对照：收-1（宏远 100,000 进对公户）、收-2（微信收宏远 40,000）、收-4（灯具 97,950）。
**客户多付了就是预收**，112201 出现负数，不用另设科目。

收-5（微信收宏远 20,000）**故意没做核销**：钱到了、但还没落到哪张单上，
所以它躺在「往来核销 → 收款认领」的待认列表里，账龄里也看得到（宏远总额里有它）。
这正是现实里最常见的起点——月底收到一笔钱，你还不知道该清哪张单。

### 6. 付供应商（付字）：按实际付的记，余额自动是欠款

```
借：220201—供应商                实付（含抹零前的欠款额）
　贷：100201 / 1001              实付金额
```
对照：付-8 付恒信 60,000、付-10 付大发 30,000。
抹零另说（见第 9 条）：付-14 欠 800 实付 780，**借 220201 800 / 贷 1001 780 + 贷 660305 20**。

### 7. 委外加工（转字/付字）：三种票三种写法

| 情况 | 分录 | 对照 |
|------|------|------|
| 开 13% 专票、挂账 | 借 510108 10,619.47 + 借 22210101 1,380.53 / 贷 220201 12,000 | 转-12 喷砂 |
| 开 3% 票、挂账 | 借 510108 6,000 + 借 22210101 180 / 贷 220201 6,180 | 转-13 拉丝 |
| **不给票、现付** | 借 510108 3,500 / 贷 100202 3,500（**没有进项**） | 付-4 抛光 |

无票的那 3,500 一分税都抵不了，等于白多交 402 元税（3,500÷1.13×13%）。
**这就是"要票"最直观的账**：同样付 3,500，给票的比不给票的便宜 400 块。

按一万元算，三种票进成本的差距是 1,150 元：

| 票种 | 进成本（不含税） | 能抵的进项 |
|------|------------------|------------|
| 13% 专用发票 | 8,849.56 | 1,150.44 |
| 3% 征收率发票 | 9,708.74 | 291.26 |
| 无票 | 10,000.00 | 0 |

在系统里确认加工费时会先让你选**票种**，再填**价税合计**，旁边就把这张对比表算给你看
（`/api/outsource/compare`）——不用回头问老板，老板也不用回头问会计。

### 8. 工资不是一步，是五步（转字 + 付字，70 人一个都不能漏）

```
① 计提工资（转-15）
   借：510101 工资（车间 62 人）      198,400
   借：660201 工资（办公室 8 人）      44,000
   　贷：221101 应付职工薪酬—工资      242,400

② 计提单位社保（转-16）
   借：510110 社会保险费（车间）       32,000
   借：660207 社会保险费（管理）        7,800
   　贷：221103 应付职工薪酬—社保        39,800

③ 发放工资（付-12）
   借：221101                        242,400
   　贷：100202 实发                  229,300
   　贷：221103 代扣个人社保            11,800
   　贷：222107 应交个人所得税           1,300

④ 缴纳社保（付-13）：单位 39,800 + 代扣 11,800 = 51,600
   借：221103                         51,600
   　贷：100201 G银行                   51,600

⑤ 下月缴个税：借 222107 1,300 / 贷 100201（本月没缴，余额挂在贷方）
```
**顺序不能反**：先计提后发放，221101 才会在发完工资后归零；
代扣的社保和个税是"你替员工保管的钱"，不是你的费用，所以贷 221103 / 222107 而不是冲费用。
车间社保进 510110（算成本），办公室社保进 660207（算管理费用）——**同一个社保两个去处**，
按人头分，这是本账里最容易漏的一处。

### 9. 收付不一一对应的三招（这是真实生意里最值钱的三招）

**① 代收代付（收-3 + 记-1）**：精密电子打来 45,000，其中 15,000 是替美丽灯具付的。

```
收钱时全额记一个客户：借 100202 45,000 / 贷 112201—精密电子 45,000
系统自动出过渡凭证：借 112201—精密电子 15,000 / 贷 112201—美丽灯具 15,000
```
对照：收-3、记-1（往来互抵）。**不这么做，精密电子的账会莫名多付 15,000、
美丽灯具永远挂着 15,000 欠款，两个客户都被记错。**

**② 三方抵账（记-2）**：精密电子欠我 20,000，我欠恒信化工 20,000，三家说好互顶。

```
往来核销 → 往来对冲单 → 客户"精密电子" ↔ 供应商"恒信化工" 20,000 → 审核
系统出：借 220201—恒信化工 20,000 / 贷 112201—精密电子 20,000
```
对照：记-2（三方抵账），审核时两端同时自动核销。
**这笔钱一分都没进银行**，但三方账全平了——现金为王的小厂，这就是省下来的现金流。

**③ 收款抹零 / 付款抹零（收-4 + 记-3、付-14）**：美丽灯具欠 98,000，实收 97,950，那 50 不要了。

```
收款 97,950：借 100201 97,950 / 贷 112201—灯具 97,950
差异核销 50：借 660305 50   / 贷 112201—灯具 50      ← 系统自动出（记-3）
```
对照：收-4 + 记-3（核销差异）。贷方合计 98,000，发票全额结清，50 块落到财务费用里。
反过来付供应商抹零（付-14）：欠 800 实付 780，**借 220201 800 / 贷 1001 780 + 贷 660305 20**（抹零收益）。
**50 块、20 块的差额千万别挂在往来上**，挂一年你就会被"永远差几十块"的账逼疯。

| 销项税额 | 58,500.00 | 收入 450,000 × 13% |
| 进项税额 | 9,740.34 | 见下表，只有收入的 2.2% |
| **应交增值税** | **48,759.66** | **税负 10.84%（占不含税收入）** |
| 附加税 | 5,851.16 | 增值税 × 12% |
| 增值税+附加合计 | 54,610.82 | 占收入 12.1% |

进项只有这么点，钱都花在哪了：

| 有票的支出 | 进项税 | 无票/没有进项的支出 |
|------------|--------|---------------------|
| 化料（13% 部分 49,800 含税） | 5,729.21 | 工资 242,400（**不产生进项**） |
| 化料（3% 部分 9,950 含税） | 289.80 | 单位社保 39,800 |
| 电费 18,000 | 2,070.80 | 厂房房租 20,000（无票） |
| 水费 1,090 | 90.00 | 宿舍租金 6,000（无票） |
| 喷砂 12,000 | 1,380.53 | 抛光 3,500（无票） |
| 拉丝 6,180 | 180.00 | 劳保 2,600 / 办公 1,200 / 招待 2,800（无票） |
| **合计** | **9,740.34** | **合计 ≈ 32 万，一分抵不了** |

> 演示账里已经替你录好了发票：**销项 3 张 + 进项 12 张（全部已认证）**。
> 房租、宿舍、抛光、劳保、办公、招待这六样没票，**一张都没录**——
> 这就是进项只有 9,740.34 的原因，也是申报表上"进项税额"一栏的真实来历。
> 进项票在税务模块里必须是「已认证」状态才算数，待认证的票填进去也不抵扣。

**结论（老板必须听懂的一句）**：本厂成本的大头是**人工和房租**，这两样天生没有进项。
所以哪怕全部采购都要到专票，税负也降不到 5% 以下。这不是会计没做好，是行业结构决定的。
**能做的事只有两件**：① 该要的票一张别丢（13% 专票 10,000 元 = 少交 1,150 元）；
② 房租、宿舍这种大额无票支出，尽量让房东去代开（有票就能抵，也能进成本凭证链）。

> 顺带算一笔：同一笔生意，如果还是小规模（3% 征收率），450,000 收入只交 13,500 左右；
> 一般纳税人要交 48,759.66。**客户要求 13% 专票，你就没得选**——这也是为什么
> "小规模更划算"只在客户都是个人/小门店时成立。

## 五、对应表在哪：收付不用一一对应，系统替你记三层

不用建表去"指认"每一笔钱还的是哪张单。对应关系分三层：

| 层 | 是什么 | 在哪看 |
|----|--------|--------|
| 往来期初明细 | 启用前欠的逐单台账（10 月：宏远 60,000 / 精密 30,000 / 恒信 46,000 / 大发 18,000） | 期末 → 往来核销 → 期初明细 |
| 凭证 | 启用后每笔发生（48 张） | 凭证查询 |
| 核销配对 | 系统自动配上的 + 你手动做的（代收代付 1 笔、抵账 1 笔、抹零 1 笔） | 期末 → 往来核销 |

日常只看**余额**（第三节表）。要催款/对账时看**账龄分析**：

- 宏远：账龄"合计 126,000、预收 0" → 一分不差，就是欠款。
- 精密：账龄"合计 34,500" → 与余额一致。
- 灯具：**账龄里连一行都没有**（全额收清），这比"显示 0"更让人放心。
- 恒信：账龄"合计 46,000、预收栏 46,000" → 净额 0（期初单据配不上是正常的，它没有凭证分录）。
- 大发：合计 18,000、预收栏 11,820 → 净 6,180，与余额一致。

## 七、你自己厂开工的固定节奏

**建账那天**：建账 → 导入科目 → 改 3 个科目名 + 加 6 个明细 → 建客户/供应商/银行/存货档案 →
录期初（含 112301 电卡余额、140302 各料数量单价）→ 录往来期初明细。

**每个月**：
1. 有业务就填凭证（收 / 付 / 转三类，收付按实际金额记，不对发票）；
2. 月底：领料（数量单价）→ 抄表结电费 → 计提折旧 → 结转制造费用 → 转出未交增值税 →
   计提附加税 → 结转损益（**顺序不能乱**）；
3. 期末处理 → 全部记账 → 期末结账；
4. 次月 15 日前：报增值税（销项 58,500 − 进项 9,740.34 = 48,759.66）+ 附加税 5,851.16。
   Web 端「税务申报 · 增值税一般纳税人」里点一下，申报表自动取数（进项只认已认证的发票，
   桌面端在「发票」里把进项票逐张认证掉，否则进项 9,740.34 会取成 0）；
5. 备份恢复点一键备份，账套文件 `xxx.fbk` 随手存一份到 U 盘。

> 想先看效果：打开 `恒亮氧化加工厂一般纳税人演示账.fbk`，按上面每条"对照：转-x / 付-x / 收-x"
> 翻对应的凭证，格式一模一样，把金额和摘要换成你自己家的就能用。

## 八、这本演示账里，四个新功能各点一遍

账套不光要"借贷平"，还要能让会计照着做。下面四件事在
`恒亮氧化加工厂一般纳税人演示账.fbk` 里都有真数据（不是空页面），打开就能看。

### 1. 电费台账 —— 资金管理 → 电费台账

- 月份选 2026-11，类别选"电"，能看到一行：抄表日 11-30、表号 E-01、用量 15,000 度、
  含税单价 1.20、金额 18,000、不含税 15,929.20、进项 2,070.80、状态 **已结转**。
- 上面四张卡：**已充 20,000 / 已用 18,000 / 卡里剩 6,000 / 还有 0 元没结转**。
- 点那一行的凭证号，看到的就是记-1：借 510103 + 借 22210101 / 贷 112301。
- 想自己试：把月份切到下个月，登记一行抄表再点"结转本期"——系统会当场开凭证并记账。

### 2. 收款认领 —— 往来核销 → 收款认领

- **故意留了一笔没认领**：11-27 微信收宏远 20,000（收-5）。
- 待认列表里就这一笔；下面"待清单据"列出宏远还挂着的发票；
  点「按建议勾选」，它会先挑同一客户的单（这是钱最可能的归属），把 20,000 填好。
- 点「认领」就清掉了；不点也行，账龄里会一直显示"钱到了、还没落到哪张单上"。
- 一笔钱认给多个客户时（A 付 B 的款），系统会自动出一张过渡凭证——
  这本账里 11-17 那笔 45,000 就是这么认的：30,000 归精密、15,000 是替灯具付的（记-2）。

### 3. 委外加工三票 —— 委外订单 → 确认加工费

- 弹窗里先选**票种**（13% 专用发票 / 3% 征收率发票 / 无票），再填**价税合计**；
  下面是三票对比小表，填 10,000 就能看到进成本 8,849.56 / 9,708.74 / 10,000.00。
- 这本账里有一一对应的三张凭证可以对照：转-12（喷砂 13% 专票）、转-13（拉丝 3%）、
  付-4（抛光无票，一分进项都没有）。

### 4. 申报前体检 —— 税务申报页最上面

- 打开「税务申报 · 增值税一般纳税人」，四张数字卡上方就是体检结果：
  **0 个错误、1 个待确认、0 个提醒 → 可以申报**。
- 那 1 个"待确认"是申报表自己带的取数提示，点开能看到说明。
- 体检**只举手不动手**：它不会替你改账、不会替你认证票。报税前反复点几次都行。
- 想看不干净的样子：把某张进项票的"已认证"取消，再回来刷新，
  它会立刻点名"有一张 X 元的进项票还没认证"——这就是它存在的意义。
