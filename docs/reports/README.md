# 过程报告归档

本目录存放**开发过程中的阶段性报告**：某个时间点的功能对比、差距分析、安全加固与完成情况汇总。
它们是**历史记录，不是使用文档**——日常使用看仓库根目录的 `README.md`，生产部署看 `DEPLOY.md`。

这些文件原先散落在仓库根目录，与主文档混杂；2026-09-26 统一归档到此处，
**根目录只保留** `README.md`（使用说明）、`DEPLOY.md`（部署说明）、`index.html`（源码包展示页）。

> ⚠ 报告内容具有时效性，**可能与当前代码不一致**。判断系统当前行为请以代码和 `README.md` 为准。
