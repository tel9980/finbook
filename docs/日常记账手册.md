# 小工厂日常记账手册

> 给老板娘 / 兼职会计看的。不讲会计原理，只讲「点哪里、填什么」。
> 从 2026 年 11 月开始用系统记账，按这份走就行。
>
> **这份手册配的是你自己的账套**：`小工厂账套.fbk`，已建好 212 个科目、
> 59 个客户（C001–C059）、25 个供应商（S001–S025）、4 类存货、3 个资金账户。
> 你不用再建档案，打开就能记账。

---

## 〇、先记住三句话

1. **只记真实发生的业务**。有没有发票都照记，发票不是记账的前提。
2. **每月 15 分钟收尾**：把凭证记完 → 记账 → 结转 → 结账 → 备份。
3. **拿不准就记一笔「借：管理费用 贷：现金」，先记录再分类**。记了随时能改，不记就永远是个窟窿。

## 一、第一天：建账（只做一次，约 30 分钟）

### 1.1 新建账套

打开软件 → 「新建账套」，填四个格子：

| 格子 | 填什么 | 例子 |
|---|---|---|
| 文件路径 | 账存哪儿。建议放 D 盘专门的文件夹 | `D:\财务\2026.fbk` |
| 企业名称 | 工厂全名 | 恒亮氧化加工厂 |
| 纳税识别号 | 营业执照上的号（选填） | 91330... |
| **启用期间** | **填 `2026-11`** | 你从哪个月开始记账 |

文件路径这一栏：整个厂的账就是这一个 `.fbk` 文件。丢了这个文件，账就没了。

底下有个「预置常用档案（推荐）」的勾，**保持勾上**。它会先把「部门」和「银行账户」建好，不然你录第一张凭证就会被拦住问「必须填写银行账户」，而你不知道去哪填。

### 1.2 录期初余额

建账后进「**期初建账**」页。这里填的是**10 月 31 日晚上关账时的家底**。

**不用一行行敲。** 工具栏有个「**批量粘贴**」按钮，从你现有的 Excel 余额表（或者别人给的）复制两列——科目编码、金额——粘进去就行。

实在要手填，规则只有一条：

> 年初余额填**正数**，然后选方向（借/贷）。
> 「累计借方 / 累计贷方」填**启用期之前**已经发生的金额。
> 系统自己算：启用期期初 = 年初余额 + 累计借方 − 累计贷方。

**必须做的检查：** 页面下方有个试算平衡，借贷两边要相等。不等就说明有数填错了，回头找。

#### 期初该录到哪个科目（最容易踩的坑）

有一件事必须先说清楚：**期初只能录在末级科目上**。

什么叫末级？就是**下面不再挂着子户的科目**。我们这套科目表是分级编码（4-2-2 位），比如：

```
1002  银行存款          ← 上级，下面挂着 7 个银行户
  └ 100201  工行基本户   ← 末级，录这个
  └ 100202  建行一般户   ← 末级，录这个
```

为什么非得这样：试算平衡表和资产负债表都是**按末级科目**汇总的。要是你把 125,000 录在 `1002` 上，试算平衡表压根不会统计这笔钱，然后告诉你「借贷不平」——可你翻遍每一行都对，因为那笔钱不在任何一行里。**这种错最难查**，所以系统现在直接拒收，不让你录进去。

下面这张表照着抄就行（左边这些**别用**，用右边的）：

| 你要填的家底 | ❌ 常见误区 | ✅ 该录的科目 |
|---|---|---|
| 现金 | — | `1001` 库存现金 |
| 银行存款 | ~~1002~~ | `100201` 工行基本户<br>`100202` 建行一般户<br>`100207` 其他银行存款 |
| 客户还欠我的钱 | ~~1122~~ | `112201` 应收货款 |
| 库存材料 | ~~1403~~ | `140301` 原料及主要材料<br>`140302` 辅助材料<br>`140306` 燃料 |
| 库存产品 | ~~1405~~ | `140501` 产成品 |
| 固定资产 | ~~1601~~ | `160101` 房屋及建筑物<br>`160102` 机器设备<br>`160103` 运输设备 |
| 我欠供应商的钱 | ~~2202~~ | `220201` 应付货款 |
| 欠工人的工资 | ~~2211~~ | `221101` 工资 |
| 欠税务局的钱 | ~~2221~~ | `222102` 未交增值税<br>`222106` 应交企业所得税 |
| 老板投的钱 | — | `4001` 实收资本 |
| 之前赚的没分 | — | `410401` 未分配利润 |

> 💡 **怎么自己判断一个科目是不是末级**：在「会计科目」页看它**有没有缩进的子行**。有子行就是上级，点开往下找带子户的。实在拿不准，就把编码里**至少 6 位**的挑出来，7 位的肯定是末级。
>
> 💡 **银行有好几个户怎么办**：每个户单独一行录。工行 8 万、建行 4.5 万，就录 `100201` 8 万 + `100202` 4.5 万两行，不要合并成 `1002` 12.5 万。

**批量粘贴也会拦。** 从 Excel 粘进来的时候，万一粘的是 `1002` 这种上级科目，预览里那行会直接标成：

> 跳过：这不是末级科目，期初要录到子户上（可录 100201、100202、100207）

**不用去别处查，它把能录的子户列给你了。** 那一行也不会计进试算，所以看到「跳过」就先把编码改对再导。


### 1.3 客户和供应商档案：已经建好了

导航「基础资料」→「客户档案」/「供应商档案」，**59 个客户、25 个供应商都已经在了**，你不用建。

| 类型 | 数量 | 编码 |
|---|---|---|
| 客户 | 59 家 | C001 – C059 |
| 供应商 | 25 家 | S001 – S025 |
| 资金账户 | 3 个 | B01 G银行对公户 / B02 N银行结算户 / B03 微信钱包 |
| 存货 | 19 个 | HG化工 / RL染料 / GJ挂具 / BZ包装 |

**你唯一要做的是：给每家填税点。** 现在全部空着。

税务档案里打开一个客户 → 「税点 %」填数字（13、9、6、3 都行），「开票情况」选一下（正常开票 / 部分开票 / 不开票）。填过一次，以后录凭证点「按客商税点算税」就自动拆税，不用你按计算器。

> 空着也能记账，只是不会自动拆税，你得自己填税额。**常用的十几家先填上，剩下的慢慢补。**

#### 三家「既是客户又是供应商」的厂

| 客户 | 供应商 | 说明 |
|---|---|---|
| C019 宏源加工 | S013 宏源加工 | 既给你外发加工，又拿你的货 |
| C020 勇唐加工厂 | S016 勇唐加工厂 | 同上 |
| C016 东蓬二厂 | S024 东蓬二厂 | 同上 |

这三家**两边名字一字不差**（这是系统认双向身份的唯一依据，以后改名要两边一起改）。首页「钱在哪」会把它们合成一行按净额显示，不用你自己心算。

**记账时还是要分开记**：他给你外发加工 → 记应付；他拿你的货 → 记应收。不要图省事轧一笔。

### 1.4 备份

导航 → 「备份恢复」→ 「一键备份」。

**现在就把第一次备份做了。** 以后每月结完账做一次。

## 二、日常：每来一笔业务就记一张凭证

导航 → 「**填制凭证**」。

### 2.1 最常见五种业务，照抄分录

#### ① 卖货收钱

```
借：银行存款 100201       10300
  贷：主营业务收入 600101      9115.04
  贷：应交税费—销项税额 22210102   1184.96
```

嫌算税麻烦：填好含税金额，点工具栏「**按客商税点算税**」，自动拆。

#### ② 卖货没收到钱（挂应收）

```
借：应收账款 112201  （必须选客户！）   10300
  贷：主营业务收入 600101                 9115.04
  贷：应交税费—销项税额 22210102              1184.96
```

> 「应收账款」这个科目挂了辅助核算，**必须选客户**。不选系统不让存——这是故意的，不选就不知道谁欠你钱。

#### ③ 客户还钱了

```
借：银行存款 100201    10300
  贷：应收账款 112201  （选同一个客户）  10300
```

#### ④ 付供应商货款

```
借：应付账款 220201  （选供应商）  5000
  贷：银行存款 100201              5000
```

#### ⑤ 付房租、水电、煤气

```
借：制造费用—水电费 510103    1500
  贷：库存现金 1001            1500
```

> **这些记在「制造费用」里没问题。** 月底点结转时，它会自动一起转进成本，不用你另外做分录。

### 2.2 有四个「必填」，不填不让存

新手最容易卡这里。**不是系统找茬，是这几处必须知道钱是谁的：**

| 行里有这个科目 | 必须补 | 在哪补 |
|---|---|---|
| 100201 / 100202 银行存款 | **银行账户**（B01 对公户 / B02 结算户） | 分录行的「银行账户」格子，下拉选 |
| 112201 应收账款 | **客户** | 分录行的「客户」格子 |
| 220201 应付账款 | **供应商** | 分录行的「供应商」格子 |
| 140302 辅助材料等存货科目 | **存货** + **数量** | 「存货」下拉 + 「数量」填数字 |

你的账套里这三个资金账户**已经建好**：`B01 G银行对公户`、`B02 N银行结算户`、`B03 微信钱包`。银行存款只能选 B01/B02，微信收款选 B03。

#### 一个户还是一笔一选？

**按实际走哪条路收款就选哪个。** 同一个客户这次打对公、下次打结算户，各记各的。月底对着银行流水能逐笔对上，这是这套账最值钱的地方——**对不上的那几笔，就是有问题的那几笔**。

### 2.3 几个实际操作技巧

| 情况 | 怎么做 |
|---|---|
| 借贷不平 | 系统会拦住你，右上角显示差额，对着找 |
| 金额差几毛 | 系统只提醒不拦，继续保存就行 |
| 忘了记账 | 凭证存下来先是**草稿**，点「记账」才算数 |
| 记错了 | 凭证查询 → 找到那张 → 作废 → 重新记一张 |
| 每月都一样的（房租） | 导航「凭证模板」，存一次，以后一键生成 |
| 老板垫钱买的 | 借：费用科目 / 贷：其他应付款 2241（别记成现金，现金没动） |

### 2.4 没发票的怎么办

**照记。** 系统不管发票。

- 有发票、有专票已认证的，进项税单独拆出来
- 没票的，**全额进成本**，不拆进项税

举同一个例子，含税 10300：

| 情况 | 分录 |
|---|---|
| 有专票（已认证） | 借 原材料 140301 9115.04 + 借 进项税额 22210101  1184.96 / 贷 银行 10300 |
| 没票 或 普票 | 借 原材料 140301 10300 / 贷 银行 10300 |

### 2.5 外发加工怎么记

你这个厂有 6 家外发厂（鸿川、宏源加工、义商、勇唐加工厂、联胜、东蓬二厂、传奇罗老板），**发出去加工**和**收回来的加工费**是两件事，分开记。

**① 把料发出去加工**（料到外发厂，所有权还是你的）

不用记账。料只是换了个地方放，还是你的存货。**但要在备查簿上记一笔**：哪天、多少 kg、发给谁、加工什么工序。

> 为什么不用记账：账上的存货数量没变（还在你名下），记了反而会重复。
> 为什么还要备查：**外发厂的料丢了、损耗超标，只有备查簿能追。**

**② 收到外发加工费发票 / 结算单**

```
借：制造费用—外发加工费 510111   （选外发厂）  2000
  贷：应付账款 220201                          2000
```

**③ 付加工费**

```
借：应付账款 220201  （选外发厂）  2000
  贷：银行存款 100201              2000
```

**④ 加工完的货收回入库**

如果收回来的半成品要入库挂账（比如你要看还剩多少在制品），记：

```
借：库存商品 140501  （选存货 + 填数量）  XXXX
  贷：生产成本 5001                      XXXX
```

> 小厂不盘点、不做成本核算的话，**第 ④ 步可以先不做**。加工费当月就进成本，简单直接，利润也是准的。

**⚠ 宏源加工、勇唐加工厂、东蓬二厂这三家既是外发厂又是客户。**
他给你加工 → 走 220201 应付；他拿你的货 → 走 112201 应收。**两笔分开记，别轧一笔**。轧了以后对账就说不清了。

### 2.6 客户几个月才确认对账单，怎么办

**不影响记账。** 你照常记应收，账上的应收余额一直是准的——因为你记的是「发出去多少货、收回来多少钱」，跟客户认不认没关系。

要处理的是「**这笔账客户到底认不认**」，用「**对账单**」功能：

1. 导航「往来核销」→「对账单」标签页
2. 选「应收」、选客户、起止期间，点「生成」
3. 打印或导出，发给客户
4. 客户确认了，在系统里点「发出」→「回签」

**状态是 draft（草稿）→ sent（已发出）→ confirmed（已回签）**，回签后不能作废。

> 几家大客户一年都对不上一次，是常有的事。**你不用等他确认才开始记下一笔**，
> 对账单只是拿来做「依据」的——真打官司、真吵架的时候，有个他自己签过字的东西。

## 三、月中：看一眼首页

导航 → 「首页」。三块内容，30 秒看完。

### 3.1 本期经营结果

最大那个数字是**净利润**（绿赚红亏）。

- 下面一行小字是利润率
- 有「▲ 较上月」就是环比
- 营业成本下面摊着成本构成前三名——能一眼看出钱主要花在哪

**看到黄色警告「N 张凭证还没记账」，说明上面的数没算全**，先回去记账。

### 3.2 钱在哪

四列数字：

| 列 | 意思 |
|---|---|
| 别人欠我 | 应收账款总额 |
| 我欠别人 | 应付账款总额 |
| 手头现金 | 现金 + 银行 |
| 净头寸 | 别人欠我 − 我欠别人 + 预付 − 预收 |

下面两列明细：**欠我最多的客户**、**我欠最多的供应商**，后面跟着账龄（多少天了）。

- 数字后面标黄 = 超过 60 天
- 标红 = 超过 90 天

红色那条下面会出现一行提示：「⚠ N 家客户的钱超过 90 天没收回，共 X，该催了」

### 3.3 待办事项

有「本期损益尚未结转」「凭证断号」这类提示，照着做就行。

## 四、月底：15 分钟收尾

按这个顺序，别跳步。

### 第 1 步：查漏（3 分钟）

- 「凭证查询」→ 筛本月 → 看有没有**草稿**没记账
- 首页 → 待办事项 → 有没有红字

### 第 2 步：记账（1 分钟）

凭证查询里勾全选 → 「记账」。

### 第 3 步：结转损益（2 分钟）

导航 → 「期末处理」→ 标签「结转损益」。

页面上会列出本期要结转的科目。看清楚：

- **收入类**：主营业务收入等
- **费用类**：管理费用、销售费用、财务费用
- **成本类**：5001 生产成本、5101 制造费用（房租水电煤气外发加工费都在这里）

点「生成结转损益凭证」→ 再点「记账」。

**结转完，这些科目余额应该归零。** 如果 5101 制造费用结转后还有余额，说明有问题，回头查。

生成的那张凭证长这样（实测数据）：

```
借：主营业务收入 600101        18,230.08
  贷：制造费用—水电费 510103     1,500.00
  贷：制造费用—办公费 510104       800.00
  贷：本年利润 4103             15,930.08
```

制造费用是**贷方**（把它冲平），收入是**借方**（也冲平），差额 15,930.08 落进「本年利润」。

> 「5001 生产成本」是**在制品**，不算在结转里——它还在仓库里，是存货不是成本。

### 第 4 步：结账（2 分钟）

「期末处理」→ 标签「期末结账」→ 点「结账」。

系统会先检查（凭证都记账了吗、损益结转了吗）。有问题会拦住并告诉你缺什么。

**结完账这个月就锁定了**，改不了。要改得先「反结账」。

### 第 5 步：出表看一眼（3 分钟）

导航 → 「会计报表」：

| 表 | 看什么 |
|---|---|
| **利润表** | 这个月赚了多少。跟首页的数字应该一致 |
| **资产负债表** | 资产 = 负债 + 所有者权益，两边必须相等 |

### 第 6 步：备份（1 分钟）

「备份恢复」→「一键备份」。

## 四点五、结错了怎么改：反结账

### 什么时候用

结完账才发现上个月的数记错了。**不用重来，反结账就行。**

### 怎么做

1. 期末处理 → 标签「**反结账**」
2. 选期间 → 点「反结账」
3. 回去改凭证
4. 重新「结转损益」→ 重新「结账」

### 三条规矩（系统会拦）

| 规矩 | 为什么 |
|---|---|
| **只能从最后一个已结账的月份开始反** | 结到 12 月了，想反 11 月，先把 12 月反了 |
| 反结账后，那个月又能录凭证了 | —— |
| 没有已结账月份时，反结账会被拒 | 「当前没有任何期间处于结账状态」 |

### 反结账之后一定要重新结转

补记的凭证如果是费用或收入，会**再次**出现待结转科目。**必须重新点一次结转损益**，否则结账会被拦住（提示「损益类科目尚未结转」）。

实测：11 月已结转、已结账 → 反结账 → 补记办公费 800 → 重新结转 → 重新结账，月净利从 15,000 变成 14,200，正确。

> 反结账是敏感操作，系统会记录是谁做的。别养成习惯，能不改就不改。

## 四点六、12 月：年末要做两件额外的事

12 月结账 = 年末结账，比平时多一步。

### 顺序

```
12 月凭证记完 → 记账 → 结转损益 → 记账 → 年末结转 → 记账 → 结账
```

### 年末结转是什么

平时结转损益，把收入费用转进「**本年利润 4103**」。这笔钱一年里一直挂在那儿。

年末要再转一次，把「本年利润」整个倒进「**利润分配—未分配利润 410401**」：

```
借：本年利润 4103            44,200
  贷：利润分配—未分配利润 410401   44,200
```

导航 →「期末处理」→「结转损益」页，**往下拉到最底下**有个「年末结转」区块。

上面会显示「4103 本年利润」当前余额，右边是按钮「**结转至 410401 未分配利润**」，点它就行。

（这块一直在，不是只在 12 月出现。不是 12 月点它，底下会有行灰字提醒「当前期间不是 12 期，通常次年再做年末结转」——别在月中乱点。）

转完这一笔，「本年利润 4103」应该**归零**，钱全部落在 410401 里，明年重新开始累计。

### 亏了怎么办

亏损时方向反过来，系统自动判断：

```
借：利润分配—未分配利润 410401    5,000
  贷：本年利润 4103                5,000
```

不用你操心正负，填好余额点按钮就行。

### 会拦你吗

会。这两种情况会提示：

- 「本年利润余额为零，无需结转」——本来就没赚没亏，正常，直接去结账
- 「缺少科目 410401，无法年末结转」——科目表被改过，补回来

### 年末做完检查一遍

| 检查 | 应该是 |
|---|---|
| 4103 本年利润 | **0** |
| 410401 未分配利润 | 累积的盈亏总额 |
| 资产负债表 | 两边相等 |
| 备份 | 做一份，标上「2026年决算」 |

## 五、对账：具体怎么操作

（为什么对、什么时候对，见 2.6）

### 5.1 生成对账单

导航 → 「往来核销」→ 标签「对账单」：

1. 选「应收」还是「应付」
2. 选客户/供应商
3. 选期间范围（比如 2026-11 至 2026-11）
4. 点「生成」

**系统自己算**：期初余额、本期增加、本期减少、期末余额。不用你手算。

### 5.2 打印寄出去

生成后能导出打印。寄给客户，让他签字盖章。

### 5.3 状态管理

| 状态 | 意思 |
|---|---|
| 草稿 | 刚生成，还没发 |
| 已发出 | 寄出去了，等回签 |
| 已确认 | 客户签回来了 |

**别等客户确认才往下做账。** 对账单是给客户看的，你的账照常记。首页的「钱在哪」按账上余额算，不依赖客户签没签。

### 5.4 谁该先对

59 个客户不可能一个个对。按这个顺序来：

| 优先级 | 谁 | 为什么 |
|---|---|---|
| 第一 | 首页「钱在哪」里账龄**超过 90 天**的 | 这些钱最可能变成坏账，早一天催早安心 |
| 第二 | 欠款**金额最大**的前 5 家 | 一家出问题就伤筋动骨 |
| 第三 | 三家双向的（宏源、勇唐、东蓬二厂） | 有付有收，最容易算错，两边轧一次最清楚 |
| 最后 | 其余零散客户 | 金额小，年底统一对一次 |

## 七、出问题了怎么办

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 试算不平 | 期初有错 | 期初建账页找差额 |
| 结转提示「净发生额为 0」 | 已经结过了 | 正常，直接去结账 |
| 首页净利润跟利润表不一致 | 有凭证没记账 | 首页黄字会提示 |
| 客户名改了首页没变 | —— | 系统是实时的，刷新一下 |
| 想改科目辅助核算 | 该科目已有分录 | 系统会拦。用「停用」代替删除 |
| 想删客户档案 | 已有凭证引用 | 系统会拦。改成「停用」 |
| 结账后发现记错 | 账已锁定 | 期末处理 → 反结账 → 改 → **重新结转** → 重新结账 |
| 反结账报「只能从最后结账的期间开始」 | 后面月份已结账 | 先按月倒着反，从最后一个月开始 |
| 补账后结账提示「损益类尚未结转」 | 补的凭证有费用/收入 | 再点一次结转损益即可 |
