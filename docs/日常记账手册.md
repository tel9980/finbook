# 小工厂日常记账手册

> 给老板娘 / 兼职会计看的。不讲会计原理，只讲「点哪里、填什么」。
> 从 2026 年 11 月开始用系统记账，按这份走就行。

---

## 〇、先记住三句话

1. **只记真实发生的业务**。有没有发票都照记，发票不是记账的前提。
2. **每月 15 分钟收尾**：把凭证记完 → 记账 → 结转 → 结账 → 备份。
3. **拿不准就记一笔「借：管理费用 贷：现金」，先记录再分类**。记了随时能改，不记就永远是个窟窿。

---

## 一、第一天：建账（只做一次，约 30 分钟）

### 1.1 新建账套

打开软件 → 「新建账套」，填四个格子：

| 格子 | 填什么 | 例子 |
|---|---|---|
| 文件路径 | 账存哪儿。建议放 D 盘专门的文件夹 | `D:\财务\2026.fbk` |
| 企业名称 | 工厂全名 | 恒亮氧化加工厂 |
| 纳税识别号 | 营业执照上的号（选填） | 91330... |
| **启用期间** | **填 `2026-11`** | 你从哪个月开始记账 |

文件路径这一栏：整个厂的账就是这一个 `.fbk` 文件。丢了这个文件，账就没了。

底下有个「预置常用档案（推荐）」的勾，**保持勾上**。它会先把「部门」和「银行账户」建好，不然你录第一张凭证就会被拦住问「必须填写银行账户」，而你不知道去哪填。

### 1.2 录期初余额

建账后进「**期初建账**」页。这里填的是**10 月 31 日晚上关账时的家底**。

**不用一行行敲。** 工具栏有个「**批量粘贴**」按钮，从你现有的 Excel 余额表（或者别人给的）复制两列——科目编码、金额——粘进去就行。

实在要手填，规则只有一条：

> 年初余额填**正数**，然后选方向（借/贷）。
> 「累计借方 / 累计贷方」填**启用期之前**已经发生的金额。
> 系统自己算：启用期期初 = 年初余额 + 累计借方 − 累计贷方。

**必须做的检查：** 页面下方有个试算平衡，借贷两边要相等。不等就说明有数填错了，回头找。

常见几笔：

| 家底 | 科目编码 | 填在哪边 |
|---|---|---|
| 现金 | 1001 | 借 |
| 银行存款 | 100201 | 借 |
| 客户还欠我的钱 | 112201 | 借 |
| 库存材料 | 140301 | 借 |
| 库存产品 | 140501 | 借 |
| 我欠供应商的钱 | 220201 | 贷 |
| 老板投的钱 | 4001 | 贷 |
| 之前赚的没分 | 410401 | 贷 |

> ⚠️ 期初**一定录在末级科目**上（编码 7 位数那种，如 112201，不是 1122）。
> 录在上级科目上，试算表不会统计这笔钱，账会显示不平却查不出原因——系统现在会拦住你。

### 1.3 建客户和供应商档案

导航「基础资料」下有「客户档案」「供应商档案」。

这里**顺便把税点填上**。每个客户税点可能不一样，填过一次，以后开票时系统自动按这个算：

- 客户档案里打开一个客户 → 「税点 %」填数字（13、9、6、3 都行，空着=不自动算）
- 「开票情况」选一下：正常开票 / 部分开票 / 不开票

**同一家厂既是客户又是供应商**（比如宏源既给你外发加工，又拿你的货走）：两个档案分别建一次，名字要**一字不差**。首页会按净额显示成一行，不用你自己心算。

### 1.4 备份

导航 → 「备份恢复」→ 「一键备份」。

**现在就把第一次备份做了。** 以后每月结完账做一次。

## 二、日常：每来一笔业务就记一张凭证

导航 → 「**填制凭证**」。

### 2.1 最常见五种业务，照抄分录

#### ① 卖货收钱

```
借：银行存款 100201       10300
  贷：主营业务收入 600101      9115.04
  贷：应交税费—销项税额 22210102   1184.96
```

嫌算税麻烦：填好含税金额，点工具栏「**按客商税点算税**」，自动拆。

#### ② 卖货没收到钱（挂应收）

```
借：应收账款 112201  （必须选客户！）   10300
  贷：主营业务收入 600101                 9115.04
  贷：应交税费—销项税额 22210102              1184.96
```

> 「应收账款」这个科目挂了辅助核算，**必须选客户**。不选系统不让存——这是故意的，不选就不知道谁欠你钱。

#### ③ 客户还钱了

```
借：银行存款 100201    10300
  贷：应收账款 112201  （选同一个客户）  10300
```

#### ④ 付供应商货款

```
借：应付账款 220201  （选供应商）  5000
  贷：银行存款 100201              5000
```

#### ⑤ 付房租、水电、煤气

```
借：制造费用—水电费 510103    1500
  贷：库存现金 1001            1500
```

> **这些记在「制造费用」里没问题。** 月底点结转时，它会自动一起转进成本，不用你另外做分录。

### 2.2 有四个「必填」，不填不让存

新手最容易卡这里。**不是系统找茬，是这几处必须知道钱是谁的：**

| 行里有这个科目 | 必须补 | 在哪补 |
|---|---|---|
| 100201 银行存款 | **银行账户**（B01 基本户） | 分录行的「银行账户」格子，下拉选 |
| 112201 应收账款 | **客户** | 分录行的「客户」格子 |
| 220201 应付账款 | **供应商** | 分录行的「供应商」格子 |
| 1403xx 原材料 / 1405xx 库存商品 | **存货** + **数量** | 「存货」下拉 + 「数量」填数字 |

银行账户和部门，新建账套时勾了「预置常用档案」会自动建好 `B01 基本户`、`B02 一般户`、`D01 销售部`、`D02 管理部`、`D03 财务部`。

**没勾的话这几个格子全是空的，一张银行存款凭证都存不了。** 补救：导航「基础资料」→「银行账户」→「新增」，编码填 `B01`，名字填你实际的开户行名。

### 2.3 几个实际操作技巧

| 情况 | 怎么做 |
|---|---|
| 借贷不平 | 系统会拦住你，右上角显示差额，对着找 |
| 金额差几毛 | 系统只提醒不拦，继续保存就行 |
| 忘了记账 | 凭证存下来先是**草稿**，点「记账」才算数 |
| 记错了 | 凭证查询 → 找到那张 → 作废 → 重新记一张 |
| 每月都一样的（房租） | 导航「凭证模板」，存一次，以后一键生成 |
| 老板垫钱买的 | 借：费用科目 / 贷：其他应付款 2241（别记成现金，现金没动） |

### 2.4 没发票的怎么办

**照记。** 系统不管发票。

- 有发票、有专票已认证的，进项税单独拆出来
- 没票的，**全额进成本**，不拆进项税

举同一个例子，含税 10300：

| 情况 | 分录 |
|---|---|
| 有专票（已认证） | 借 原材料 140301 9115.04 + 借 进项税额 22210101  1184.96 / 贷 银行 10300 |
| 没票 或 普票 | 借 原材料 140301 10300 / 贷 银行 10300 |

## 三、月中：看一眼首页

导航 → 「首页」。三块内容，30 秒看完。

### 3.1 本期经营结果

最大那个数字是**净利润**（绿赚红亏）。

- 下面一行小字是利润率
- 有「▲ 较上月」就是环比
- 营业成本下面摊着成本构成前三名——能一眼看出钱主要花在哪

**看到黄色警告「N 张凭证还没记账」，说明上面的数没算全**，先回去记账。

### 3.2 钱在哪

四列数字：

| 列 | 意思 |
|---|---|
| 别人欠我 | 应收账款总额 |
| 我欠别人 | 应付账款总额 |
| 手头现金 | 现金 + 银行 |
| 净头寸 | 别人欠我 − 我欠别人 + 预付 − 预收 |

下面两列明细：**欠我最多的客户**、**我欠最多的供应商**，后面跟着账龄（多少天了）。

- 数字后面标黄 = 超过 60 天
- 标红 = 超过 90 天

红色那条下面会出现一行提示：「⚠ N 家客户的钱超过 90 天没收回，共 X，该催了」

### 3.3 待办事项

有「本期损益尚未结转」「凭证断号」这类提示，照着做就行。

## 四、月底：15 分钟收尾

按这个顺序，别跳步。

### 第 1 步：查漏（3 分钟）

- 「凭证查询」→ 筛本月 → 看有没有**草稿**没记账
- 首页 → 待办事项 → 有没有红字

### 第 2 步：记账（1 分钟）

凭证查询里勾全选 → 「记账」。

### 第 3 步：结转损益（2 分钟）

导航 → 「期末处理」→ 标签「结转损益」。

页面上会列出本期要结转的科目。看清楚：

- **收入类**：主营业务收入等
- **费用类**：管理费用、销售费用、财务费用
- **成本类**：5001 生产成本、5101 制造费用（房租水电煤气外发加工费都在这里）

点「生成结转损益凭证」→ 再点「记账」。

**结转完，这些科目余额应该归零。** 如果 5101 制造费用结转后还有余额，说明有问题，回头查。

生成的那张凭证长这样（实测数据）：

```
借：主营业务收入 600101        18,230.08
  贷：制造费用—水电费 510103     1,500.00
  贷：制造费用—办公费 510104       800.00
  贷：本年利润 4103             15,930.08
```

制造费用是**贷方**（把它冲平），收入是**借方**（也冲平），差额 15,930.08 落进「本年利润」。

> 「5001 生产成本」是**在制品**，不算在结转里——它还在仓库里，是存货不是成本。

### 第 4 步：结账（2 分钟）

「期末处理」→ 标签「期末结账」→ 点「结账」。

系统会先检查（凭证都记账了吗、损益结转了吗）。有问题会拦住并告诉你缺什么。

**结完账这个月就锁定了**，改不了。要改得先「反结账」。

### 第 5 步：出表看一眼（3 分钟）

导航 → 「会计报表」：

| 表 | 看什么 |
|---|---|
| **利润表** | 这个月赚了多少。跟首页的数字应该一致 |
| **资产负债表** | 资产 = 负债 + 所有者权益，两边必须相等 |

### 第 6 步：备份（1 分钟）

「备份恢复」→「一键备份」。

## 五、对账：客户不确认怎么办

小工厂的老问题：发了对账单，客户几个月不回。

### 5.1 生成对账单

导航 → 「往来核销」→ 标签「对账单」：

1. 选「应收」还是「应付」
2. 选客户/供应商
3. 选期间范围（比如 2026-11 至 2026-11）
4. 点「生成」

**系统自己算**：期初余额、本期增加、本期减少、期末余额。不用你手算。

### 5.2 打印寄出去

生成后能导出打印。寄给客户，让他签字盖章。

### 5.3 状态管理

| 状态 | 意思 |
|---|---|
| 草稿 | 刚生成，还没发 |
| 已发出 | 寄出去了，等回签 |
| 已确认 | 客户签回来了 |

**别等客户确认才往下做账。** 对账单是给客户看的，你的账照常记。首页的「钱在哪」按账上余额算，不依赖客户签没签。

## 六、每月固定动作清单

打印出来贴墙上：

```
每月 1-5 号：
  □ 上月的凭证全部记完
  □ 勾选全部 → 记账
  □ 期末处理 → 结转损益 → 记账
  □ 期末处理 → 结账
  □ 会计报表 → 看利润表、资产负债表是否合理
  □ 备份恢复 → 一键备份

每周五下午（5 分钟）：
  □ 看首页「钱在哪」
  □ 红色超 90 天的客户，打电话催
  □ 手头现金够不够下月发工资

每季度：
  □ 打一份客户对账单寄出去
  □ 看「科目余额表」，5101 制造费用有没有异常余额
```

## 七、出问题了怎么办

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 试算不平 | 期初有错 | 期初建账页找差额 |
| 结转提示「净发生额为 0」 | 已经结过了 | 正常，直接去结账 |
| 首页净利润跟利润表不一致 | 有凭证没记账 | 首页黄字会提示 |
| 客户名改了首页没变 | —— | 系统是实时的，刷新一下 |
| 想改科目辅助核算 | 该科目已有分录 | 系统会拦。用「停用」代替删除 |
| 想删客户档案 | 已有凭证引用 | 系统会拦。改成「停用」 |
| 结账后发现记错 | 账已锁定 | 期末处理 → 反结账 → 改 → 重新结账 |

## 八、这个系统不管的事

你用不上的，别去找：

- **生产线设备折旧**（固定资产模块）——现阶段不做
- **MRP / 工艺路线 / 工序报工**——不涉及
- **多维度利润分析、预算管理**——小厂用不上

导航栏默认是「精简模式」，只显示日常要用的 17 个菜单。想全看，去「账套参数」取消勾选。
