## 一、问题：最难的不是记账，是「借方」两个字

一个开氧化加工厂的人，第一次打开「填制凭证」看到的是：

```
行 | 科目 | 摘要 | 借方 | 贷方 | 辅助
```

「借方」和「贷方」他一个都不认识。这句话没人解释，而后面每一张凭证、
每一张报表都要用到它 —— 于是要么退回去用手写账本，要么照别人说的死记硬背。

前几版把**首页**的专业词换成了老板看得懂的结论（v1.8.82）。这一版沿同一条路
往下走，处理日常真正会打开的三个页面。

## 二、改法：列名不动，上面加一行灰字

| 页面 | 现在表格上方多了一行 |
|---|---|
| **填制凭证** | 一笔业务拆两行：钱花到哪去（或谁欠你）写一行，钱从哪来（或你还欠谁）写另一行；两边钱数必须一样，差额 0.00 才能保存。科目按下拉里的业务词找（电费、房租、收款、原材料、工资） |
| **科目余额表** | 借方贷方是方向，不用背 —— 想知道月底还剩多少看「期末」这一列；想知道年初到现在看「本年累计」两列 |
| **账簿查询** | 明细账＝每一笔都列出来（对账用）；总账＝一个月一行合计数（看走势）；日记账＝按日期排的流水（银行、现金对账用） |

**为什么没把「借方」改成「付出」**：会计、代账会计、税务局看的都是借贷。
真改了，你的凭证跟外部单据就对不上，换人或请代账时要重新翻译一遍。
所以做法是「原词保留 + 灰字解释」——两全。

桌面版（exe）这三处一并加了同样的灰字，跟网页版说法完全一致。

## 三、教程也补了一节

`docs/小白日常操作教程.md` 新增 **「1.2·补、『借』和『贷』到底怎么分（30 秒看懂）」**：

> **借方 = 钱花到哪去了**（买了什么、变成了什么、该谁欠你）
> **贷方 = 钱从哪来的**（哪个卡付的、欠了谁、挣的什么钱）

并写明「软件里也写了这句话，就在分录表格下面那行灰字」。
