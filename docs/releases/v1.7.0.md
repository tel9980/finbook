# FinBook v1.7.0

这一版把**往来账**补齐了两件事——都是氧化加工厂天天碰到的实际场景：

1. **差异核销（抹零 / 尾差）**：应收 10000、客户实付 9980，差 20 抹零，以前会永远挂在账上；现在填个差异金额，系统自动记账、一次结清。
2. **往来对冲单**：同一家公司既买我们的货（应收）、我们又买它的（应付），月末两家约定「轧差只结净额」；现在录一张对冲单，出凭证、两边往来同时变清。

另外，**多笔对多笔的核销**（一笔收款冲多张单、一张单分多次收款）本来就支持，这次在报告里写清楚了。

## 这一版的变化

### 1. 差异核销（抹零 / 尾差 / 现金折扣）

**在哪里**：往来核销 → 「手工核销」页签，挑好一借一贷后，工具栏多了一个「**差异(抹零)**」框和「**差异科目**」。

**实际场景**：应收 10000，客户实付 9980，差 20 客户说「抹了」。

**怎么用**（三步）：

1. 上面挑贷方那一笔**收款 9980**、下面挑**原单 10000**；
2. 「本次核销金额」填 `9980`，**「差异(抹零)」填 `20`**；
3. 点「核销」——系统自动生成一张差异凭证：**借 财务费用-其他 20 / 贷 应收账款 20**，并把这条差异分录也跟原单核销掉。

结果：这张应收**一次结清**（9980 实收 + 20 抹零 = 10000），零头进了损益，账龄不再留个尾巴。

**几分钱也照做**：尾差 0.01、0.5 都行，系统会自己出凭证，不用手工补分录。

**差异科目**：

- 默认 `660305` **财务费用-其他**（抹零、现金折扣最常用）；
- 也可填 `6711` **营业外支出**（金额小、性质更像损失时）。

收款抹零出「借 差异科目 / 贷 应收」，付款抹零出「借 应付 / 贷 差异科目」，方向系统自动判断。

### 2. 往来对冲单（应收 ↔ 应付相互抵销）

**在哪里**：往来核销 → 「往来对冲」页签（桌面版和网页版）。

**实际场景**：A 公司既向我们买货，我们又向它买料。月末对账：它欠我们 10000，我们欠它 6000，两家约定「对冲 6000，只结剩下 4000」。

**怎么用**（四步）：

1. 填**日期**、**客户(应收)**（如 `C01`）、**供应商(应付)**（如 `S01`）、**对冲金额**（如 `6000`）；
2. 点「**新增对冲单**」——此时只是一张**待审核**的草稿单；
3. 点「**审核**」——系统自动生成凭证：**借 应付账款-供应商 6000 / 贷 应收账款-客户 6000**；
4. 同时对**两端各自按日期先进先出**核销：应收那 10000 被冲掉 6000，剩 4000；应付那 6000 清 0。

**几条规则**（都会在审核时拦下来，不会悄悄记错）：

- 对冲金额**不能超过任一端未核销合计**（应付只有 6000，就不能对冲 8000）；
- 客户、供应商两个往来单位**都要填**；
- **撤销审核**会删掉那张**未记账**的凭证、把两边的核销一起退回，单据回草稿；
- 凭证**已经记账**的，要先反记账，才能撤审；单据要删，得先作废/删除它生成的凭证。

### 3. 多笔对多笔的核销（本来就支持，这次写清楚）

FinBook 的核销是**分录对分录**的，不是「整客户结清」：

- 一笔收款**可以**冲掉多张应收单（收款单审核时按日期自动分摊）；
- 一张应收单**可以**分多次收款核销（部分核销，次数不限）；
- 金额可以不相等，剩下多少挂多少，账龄照实反映。

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 差异核销产生的差异凭证是**草稿**，需会计记账后才进余额（与收付款单一个规矩）
- 往来对冲的客户与供应商需要是**同一家关联方**的档案；系统不会自动判断两家是不是同一家
- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
