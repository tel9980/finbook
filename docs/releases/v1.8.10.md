# FinBook v1.8.10

桌面版补上了**往来对账单**——发给客户对账、回签确认的功能。

## 为什么改

`findb::statement` 这个模块（对标金蝶「客户对账单」）在 Web 服务端一直有接口，但**桌面端没有任何入口**。用 Windows 版的人完全用不上它。

而这恰恰是小厂最难受的一环：**客户对账不及时，有些要几个月才确认**。没有对账单，只能自己翻凭证手工算，算完发微信，对方不回就没下文，跟谁对上、跟谁没对上全靠记忆。

## 新增：桌面版「往来对账单」

在「往来 → 对账单」标签页：

- **生成**：选应收/应付、填客商编码、选期间范围，一键生成
- **内容**：期初余额 + 逐笔流水（日期、凭证号、摘要、增加、减少、滚动余额）+ 期末合计
- **快照**：生成时算好落库，之后改凭证、再核销都不影响已发出的对账单——已经发给客户的单据不能被后台操作改掉
- **状态流转**：草稿 → 已发出 → 已回签确认；已回签确认的不能作废（客户已认可）
- **明细弹窗**：点「明细」看完整流水，就是打印给客户签字的那张

界面上「已发出」用警示色标出，**一眼能看出跟谁还没对上**。

### 与「催款单」的区别

两个东西容易混，但用途完全不同：

|  | 催款单 | 对账单 |
|---|---|---|
| 目的 | 催收欠款 | 定期发客户对账 |
| 口径 | 某一时点的**未核销**欠款快照 | 某期间的**完整流水**（含已核销） |
| 金额 | 一个欠款总额 | 期初 + 本期发生 + 期末，带滚动余额 |
| 闭环 | 无 | 客户**回签确认** |

## 实测

```
对账单号 DB202611001
期初 0.00  增加 10,500.50  减少 3,000.00  期末 7,500.50
流水 3 笔：
  2026-11-05  记-0001  11月加工费   增 8,000.00            余 8,000.00
  2026-11-20  记-0002  加急单      增 2,500.50            余 10,500.50
  2026-11-25  记-0004  收张三货款             减 3,000.00  余 7,500.50
回签后状态 → 已回签确认（张三）
```

## 其他

- 精简模式（`simple_nav`）明确不含固定资产（`Assets`），小工厂现阶段只做应收应付与日常收支，生产线设备不进固定资产管理。取消勾选精简模式即可恢复。
- 无 SCHEMA 变更，仍为 **v38**。

## 兼容性

旧账套直接打开即可，无需迁移。
