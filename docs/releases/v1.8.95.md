# v1.8.95 报价单「对价校验」

## 问题

报价单上只有一个单价，价目表可能按 ㎡、按米、按 kg 记 —— 两个数摆在一起没法比。
业务员手工填价时（1.5 写成 15、0.28 写成 0.15）没有任何东西会拦一下，
往往到对账或客户投诉才发现。

## 改法

`check_quote_price`：取当前该用的价（数量档也参与），把价目表那格**换算成
「每库存单位」的价**再比 —— 12 元/㎡、1 件 = 0.0234 ㎡ → 每件 0.28。
口径不同又没录系数时直接说「对不上（缺系数）」，不拿两个不同单位的数硬减差额。

结论四种：一致 / 不一致 / 没价 / 口径对不上。

## 只提示，不拦单

手工价有时是对的（老客户、一次性让价、打包价）。系统替业务员拍板比不提示更糟，
所以保存报价单照常成功，只在响应里多一句 `price_warn`，页面上在表单下方显示一行：

- 黄字：价目表 12.00 元/㎡（折合每件 0.28 元），这单填 0.15 元，差 -0.13
- 绿字：✔ 和价目表一致
- 没有价目表：什么都不显示

## 接口

- `POST /api/sales/quote` 响应只增不改：多了 `price_warn` 与 `price_check`
- 新增 `GET /api/sales/quote/:id/price-check`
