# FinBook v1.8.12

**利润表漏算制造费用——这是会让人亏钱而不自知的 bug。**

## 问题

成本类科目（`5001 生产成本`、`5101 制造费用`）在系统里是 `AcctCategory::Cost`，不属于损益类。这是对的：它们应当先归集，再结转到 `6401 主营业务成本`。

但小厂往往不做成本核算——不核算单位成本、不算产成品成本，房租、水电、煤气、外发加工费就直接挂在 `5101` 各明细科目上。

而 `financial_totals` 的净利润只认 `6401 + 6402`：

```rust
let cost = exp("6401") + exp("6402");
let net_profit = revenue - cost - exp("6403") - ...;
```

**结果：记在 5101 上的真实支出，从利润里整体消失。**

实测：

```
收入       = 100,000.00
成本(6401) =       0.00
净利润     = 100,000.00   ← 房租 15,000 没算
```

账是平的，试算平衡，没有任何报错或警告。**只有老板觉得"怎么利润这么高"时才会发现。**

## 修复

把成本类科目的**当前余额**计入当期成本：

```rust
let unrecovered_cost = /* 所有末级 Cost 类科目的借方余额 */;
let cost = exp("6401") + exp("6402") + unrecovered_cost;
```

修复后：

```
收入   = 100,000.00
成本   =  15,000.00
净利润 =  85,000.00   ✓
```

### 为什么不会重复计算

成本类科目的余额 = "已发生但还没转到主营业务成本"的部分。真做了结转的账套，这些余额会被结转凭证冲成 0，所以不重复。实测验证：

```
① 房租记 510105，未结转  → 成本 15,000，净利润 85,000 ✓
② 房租记 510105，再结转到 6401 → 成本 15,000，净利润 85,000 ✓（不是 30,000）
```

只取末级科目（父科目余额是子科目之和，重复相加会翻倍）。

## 新增：首页显示经营结果

首页原来四个卡片全是"账记对没有"（试算平不平、几张没记账），**不回答老板最关心的"这个月赚没赚钱"**。

新增三个卡片：

| 卡片 | 内容 |
|---|---|
| 营业收入 | 本月收入合计 |
| 营业成本 | 材料 + 人工 + 外发 + 折旧等 |
| **净利润** | 本月利润，副标题带年初至今累计 |

净利润为负显示红色，为正显示绿色。数据源与「报表 → 利润表」完全一致（同一个 `financial_totals`），不另算一套。

放在试算平衡**之前**——账平不平是会计的事，赚没赚钱是老板的事。
