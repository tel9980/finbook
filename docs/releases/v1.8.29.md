# v1.8.29 —— 期初收集表一次导完；账龄表能导出了

这一版补两件「纸上都做过、系统里没做过」的事。

## 一、《期初收集表》填完能直接导回系统

以前拿到工厂填回来的表，得照着敲三遍：往来期初敲一遍、科目期初敲一遍、
实收资本再敲一遍。敲错一个数，试算平衡就不平，然后花半小时找那个数。

现在「期初建账 → **导入期初收集表**」，选一个 `.xlsx`，四张纸一次导完：

| 纸 | 落到哪里 |
|----|----------|
| ① 客户应收 | 往来台账（`arap_opening`）+ `112201` 科目期初合计 |
| ② 供应商应付 | 往来台账 + `220201` 科目期初合计 |
| ③ 账户余额 | 各科目（含银行/现金/备用金/存货/固定资产）的期初余额 |
| ④ 基本资料 | 实收资本 `4001`，本年利润 `4103` |

### 为什么要同时写台账和科目

`arap_opening` 是**台账**，用来算账龄、出对账单；资产负债表上的应收数是
`112201` 的**科目余额**。两者不会互相推导：

- 只导台账 → 「账龄表上明摆着欠 7 万，资产负债表应收是 0」。
- 只导科目 → 报表对了，但查不出是哪家欠的、欠了几天。

### 不平就整批拒绝，不写半个账套

期初借贷不平，试算平衡开账就是不平的，之后每个月每张报表都跟着歪，而且很难
倒推是哪一步错的。所以这里**先算平再落库**：

```
借方 = 应收合计 + 资产类账户
贷方 = 应付合计 + 负债类账户 + 实收资本 + 本年利润
```

不等就一条不写，并告诉你三个数：

> 借方合计 90,000.00（应收 70,000.00 + 资产账户），贷方合计 30,000.00，
> 差额 60,000.00。常见原因：漏填某个银行账户余额、应收/应付填了合计但明细没填全……

只填实收资本、没填本年利润时，按差额自动补 `4103` 并在结果里提示「请核对这个数
是前期赚的还是亏的」；但如果 4103 你**明确填了**，就绝不再动它 —— 让不平当场暴露。

### 认表名也认列名

表名被改成「客户应收」还是「① 客户应收」都认；名字被改得看不懂就退回按顺序取。
列头按**名字**认（欠款金额/金额/余额 都行），所以工厂把「单据号」和「备注」调了
顺序也不会串 —— 按位置取的话，备注会被当成单据号写进台账。

单据号空着会自动补 `QC-客户编码`：台账里两笔没单号的欠款无法区分，账龄也算不出先后。
期初日期取**启用期间的前一天**（11 月建账 → 2026-10-31）。

## 二、往来账龄表能导出 Excel

以前账龄表只能截图 —— 老板要发给客户、或者存档给会计，截图既不能改也不能算。

「往来核销 → **账龄导出**」出一份 xlsx：往来对象、六档账龄、借方合计、贷方合计、
净额、最久天数，末行合计加粗。

关键是它和界面上的账龄走**同一个** `findb::settle::aging`：不是另写一套取数，
所以文件里的数字与屏幕上的数字不可能不一样。文件名带科目
（`往来账龄_2202_20261027.xlsx`），导出应收和应付两个文件时不会混。

## 怎么用

1. 工厂把《期初收集表》填回来（表由 `cargo run -p findb --example opening_sheet -- 期初收集表.xlsx 账套.fbk` 生成，客户/供应商编码已预填）。
2. 网页：`期初建账` → `导入期初收集表` → 选文件。
3. 看到「已导入：应收 N 笔、应付 M 笔、科目期初 K 条（借 90000.00 = 贷 90000.00）」，再去「试算平衡」确认一把。
4. 有警告（比如自动补了本年利润）会单独弹一次让你过目。
