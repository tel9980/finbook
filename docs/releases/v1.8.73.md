# v1.8.73 —— 客供料交货单挂销售订单：这张单的活交完了没有

## 一、问题

受托加工这边，客户来料记了数量、加工完交货也记了数量，但「这张订单还差多少没交回来」
谁也说不清：车间问销售，销售翻微信记录。销售订单与客供料台账各自记各自的。

## 二、这一版做了什么

- **交货单可以挂销售订单**（可选）：填了就在单据上留订单号快照，列表里直接看得见。
- **挂单校验两条**：订单必须存在；订单客户必须与本单客户一致。
  客户编码是手输的，串一个字母就会把 A 客户的交货量记到 B 客户头上，而进度表看起来还挺正常。
- **交货进度表**（`GET /api/consign/so-progress`，桌面端与网页端都有）：
  按订单行列出 订购 / 已交 / 未交。
  - 已交**只算交货单**：退料是客户没用完的料回去、损耗是加工中没了，都不是成品交付；
    把退料也算进去，进度会虚高。
  - 未交 = 订购 − 已交，不低于 0（超交在库存那侧单独拦，不在进度表里显示负数）。

## 四、没动

- 交货单不自动回写销售订单的「已发货数量」：客供料交货是「把成品送回客户」，
  与销售发货（我方出库开票）是两套账，混在一起会让销售收入与库存都变样。
  真要合并，得先定清楚受托加工的收入确认口径（现在客供料台账仍不出凭证，v1.8.70 定案）。
- 进度只按物料比，不按批次：客户来料分批次，但订单行不记批次，硬对会有一半对不上。
