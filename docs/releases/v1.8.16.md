# FinBook v1.8.16

堵上两个**会让钱在账上"消失"而又不报错**的口子：

1. 有分录的科目，不能再改辅助核算
2. 被凭证引用过的档案，不能再删除

## 为什么必须堵

### 问题一：改了辅助核算，钱就从名单里消失了

辅助核算不是"显示开关"，它决定**这笔钱挂在谁身上**。

假设你把「112201 应收账款」的辅助从「客户」改成「不核算」，之后新录的应收就不带客户名。账上于是并存两种：

| 分录 | 带客户吗 | 后果 |
|---|---|---|
| 老分录 15,000 | 带（C001） | 能按客户查到 |
| 新分录 5,000 | 不带 | **查不到是谁欠的** |

实测结果：

```
应收科目余额：20,000
首页「别人欠我」：15,000   ← 少了 5,000
```

那 5,000 还在科目里，试算也平，**但从「欠我最多的客户」名单里彻底消失了**。你按客户催款，永远找不到这笔钱。

这类错最难查——不报错、不平账、合计是对的，只是钱不对到人头上。

### 问题二：删掉档案，往来名字变成编码

凭证里存的是 `customer=C001` 这样的编码。档案一删，编码指向空：

- 界面上名称退化成 `C001`
- 账龄算不出来（按编码反查名称失败就整条跳过）
- 首页「钱在哪」里这家单位直接不显示

## 现在的行为

**改辅助核算**（科目表 → 双击 → 勾掉/勾上某个辅助维度 → 保存）：

```
科目 112201 已有 1 条分录，不能改辅助核算。辅助核算决定这笔钱挂在谁身上，
改掉后旧分录仍带原辅助、新分录不带，同一科目会出现两种口径，
按客户或供应商查账时不带辅助的钱会查不到。
要改请先清理该科目的分录，或改用新科目。
```

编辑窗口里也会提前标黄提示，不用等到点保存才发现。

**删档案**（客户/供应商 → 删除）：

```
「宏源」（客户）已有 1 条分录引用，不能删除。
删掉后那些凭证的往来名字会变成编码，账龄和首页「钱在哪」都查不到这家。
请改用「停用」：停用后新凭证选不到，历史账不受影响。
```

## 什么还能改

这些**照常改，不受任何限制**：

| 改什么 | 效果 |
|---|---|
| 客户/供应商改名 | 所有界面立刻显示新名（凭证存编码，名称实时查） |
| 客户税点 | 「按客商税点算税」用新税点 |
| 停用档案 | 新凭证选不到，历史账照旧 |
| 科目名称、备注、现金流量项目、资产负债表项目 | 随便改 |

## 「停用」才是删档案的正确做法

「基础资料 → 客户档案」→ 双击 → 勾选「停用」→ 保存。

停用之后：录新凭证时下拉框选不到它，历史账一张不受影响，随时能改回来。

## 兼容性

- 无 SCHEMA 变更，仍 **v38**
- 只增加拦截，不修改任何已有数据
- 老账套打开后行为一致
