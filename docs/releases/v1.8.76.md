# v1.8.76 —— 自动挂科目：账不用重记，先看再定

## 一、为什么做这个

上一版把「利润分析表」的行做成了数据，但有个现实问题：厂里的费用早就记在某些科目上了，
难道为了这张表把账重记一遍？不能。这一版加「自动挂科目」：按**现有科目的名字**去对这张表的行，
对上就挂，不用动账。

## 二、怎么做的

- **先预览、再落地**：`auto_map(db, apply=false)` 只算不写，界面把「哪行挂哪几个科目」摆出来，
  人看过再点应用。猜错了不会报错——只会让某行金额偏大、另一行偏小，合计还是对的，
  这种错最难发现，所以不能直接落地。
- **一个科目只能挂一行**：电费、水费两行都像「510103 水电费」，先到先得；后来那行不是「没找到」，
  而是明确告诉你是被占了——「510103 水电费已经挂在别的行上了：要分开看就得拆科目」。
  默认科目表里水电费是一个科目，你那张表却分电费、水费两行，这就是该拆科目的信号。
- **只认末级、只认同类**：挂上级科目等于把下级一起算进来；支出行只认成本/费用类，
  不然「应付职工薪酬」会被「薪酬」两个字捞进来。
- 关键字比行名宽一点（「货车运输费」对「运输/运费/加油/油费/车辆」），但不用单字——
  「电」会把电话费、电焊机都捞进来。一行最多挂 3 个。

## 三、你实际会看到什么

点「自动挂科目」→ 弹出一张预览表：每行显示将挂的科目和一句说明。

- 挂上了：「挂上 2 个科目」
- 本来就有：「已经有科目，没动」
- 被占了：「510103 水电费已经挂在别的行上了…」
- 真没有：「现有科目里没有像它的名字：点「按这张表生成科目」新建，或手工填」

标准科目表里对得上的（工资 → 510101/660101/660201 三个工资、电费 → 510103 水电费、
税金 → 6403 税金及附加、社保费 → 660207 社会保险费、办公用品费 → 三个办公费、
业务费 → 两个业务招待费、厂租 → 两个租赁费、货车运输费 → 660106 运输费）会自动挂上；
化工、染料封闭剂、包装材料、外发加工费、维修费、挂具费这六个标准表里没有，会留空，
用「按这张表生成科目」新建。

## 五、没动

- 不做「按凭证摘要猜科目」：摘要写「电费」就归到电费行听着聪明，猜错没人发现。
- 不自动拆科目：电费/水费要分开看，得你自己在「科目」里拆成两个，系统不替你改账。
