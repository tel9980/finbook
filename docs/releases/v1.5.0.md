# FinBook v1.5.0

这一版补齐了**客户管理**：点开一个客户，除了原来的「往来明细 / 账龄」，现在还能看「交易历史」和「催款」两个页签 —— 从这个客户买过什么、到打过几次电话催，都在一屏里。

---

## 下载

| 平台 | 文件 | 大小 |
|------|------|------|
| **Windows 10/11** | `finbook-1.5.0-windows-x86_64.zip` | ~7 MB |
| Linux x64 | `finbook-1.5.0-linux-x86_64.tar.gz` | ~10 MB |

解压后得到三个文件：

```
finbook(.exe)          主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

账套就是一个 `.fbk` 文件（标准 SQLite），**备份只需复制这个文件**。

附件里还有服务器版（`finweb-1.5.0-linux-x86_64.tar.gz`，自部署 Web 端用）与校验和（`SHA256SUMS`）。

示例账套登录：`admin` / `admin123`

## 这一版的变化

### 1. 客户详情的「交易历史」页签

点开客户 → 交易历史，把这个客户的四类单据按日期倒序排在一起：

- **报价**（报过什么价）
- **销售订单**（定过什么）
- **发货**（发过多少）
- **收款**（收过多少钱）

默认看**本年**（从年初到当前期间），看某一笔什么时候发的、什么时候收的，不用再翻三个模块。发货行显示数量、收款行显示金额，各司其职。

> 「收款」取的是**收付款单**（会计口径），不是订单上的收款记录 —— 同一笔钱系统里两张表各记一份，客户维度只认一个，否则数字会翻倍。

### 2. 客户详情的「催款」页签

把对这个客户开过的**催款单**和发过的**往来对账单**列在一起，带日期、单号、金额、笔数和状态（草稿 / 已发出 / 已结清 / 已确认）：

- 之前打过几次电话催、每次催多少，一目了然；
- 发过对账单没、客户有没有回签，也能看到。

两个页签都是**只读展示**：改客户档案仍只有「辅助档案」一个入口，催款单/对账单仍到各自模块去开。

### 3. 工程卫生

- 客户管理的两个新视图延续老规矩：余额只有一处算法，页签只做展示、不重算；新增的取数都复用已有模块（账龄桶、催款单、对账单），不另起一套。
- 设计文档的代码行号引用（锚点）随本次改动同步更新，CI 里的「文档不许漂移」检查继续有效。

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 导出 Excel/CSV 仅管理员与财务主管可用，普通账号仅能打印
- 附件哈希为 SHA-256 完整性校验（防误删损坏），不防篡改
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
