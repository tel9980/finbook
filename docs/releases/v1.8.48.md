# v1.8.48 —— 账期：一个能填两年却没人读的字段

客户档案里有个「账期（天）」，从一客一税点那一版就在，桌面端网页端都能填。但全仓
`grep pay_days` 除常量定义外**零命中**——填 30 天和填 300 天，系统行为完全一样。

这一版让它真的被读：账龄表现在会告诉你「逾期多少天」。

## 「账龄」和「逾期」不是一回事

| 概念 | 算法 | 能回答什么 |
|------|------|-----------|
| 账龄 | 今天 − 单据日期 | 这笔挂了多久 |
| 逾期 | 账龄 − 账期（不足 0 记 0） | 超过约定多少天，该不该催 |

账龄 54 天是不是要催，取决于约定了多少天。同一个 54 天：

- 账期 30 天 → **逾期 24 天，该打电话了**
- 账期 90 天 → 还没到期，催了反而得罪人

所以两列都要有，只给一个都会误导。

## 逾期按「最老一笔未核销单据」算

一个客户有十笔未核销单据时，逐笔算逾期会得出十个数字，而催款只需要一个：**最保守的
那个**。取最老那笔的日期算，正好就是「最早超期多少天」——十笔里最老的最急。

## 不知道就写「未设账期」，不能写 0

档案里没填账期时，界面上写「未设账期」、Excel 那一格**留空**。理由：

- `0` 是「现款现货、当天到期」，是一个真实的约定
- 「没填」是不知道，两者混成一个 0，导出的表会让二十年没谈过账期的老客户看起来像现款客户

## 改了哪些地方

| 位置 | 变化 |
|------|------|
| `系统设置 / 客户·供应商档案` | 不变（账期一直能填，只是以前没人用） |
| 往来核销 → 账龄分析 | 新增「逾期」列：`逾期 24 天` / `未到期` / `未设账期` |
| 账龄导出 Excel | 新增「账期」「逾期天数」两列 |
| 桌面端账龄表 | 同上，逾期用黄字、未到期用绿字 |

## 没做的：催款单正文

原计划让催款单也带「已逾期 N 天」，但催款单正文是一整段文本，逐单加逾期要改模板结构；
而且明细行里已经写着每笔单据日期，看得出先后。**先把数字放进账龄表**——那是做「催不催」
决定的地方，催款单只是把这个决定写下来。正文那条留到后面单独做。

## 怎么用

1. 先把账期填上：`客户档案` → 编辑 → 账期（天）。老客户按实际谈的填，没谈过就留空。
2. 打开 `往来核销 → 账龄分析`，「逾期」列里黄字的先去催。
3. 要发函就把账龄导出成 Excel，两列账期/逾期都在里面。
