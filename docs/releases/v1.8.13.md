# FinBook v1.8.13

首页从「三个并列卡片」改成**以净利润为唯一主角**，并补齐了老板真正需要的判断依据。

## 改了什么

### 1. 净利润成为视觉焦点

原来营业收入、营业成本、净利润三个卡片同样大小、同样字号。老板打开首页，眼睛不知道该落在哪。

现在净利润独占一行：**38px 大字**，绿色（赚）/ 红色（亏），收入成本退为 20px 陪衬。

### 2. 加了利润率

只有绝对金额不够。同样是赚 8.5 万：

- 收入 10 万 → 利润率 85%（好生意）
- 收入 100 万 → 利润率 8.5%（薄利）

副标题直接显示 `利润率 60.0%`。

### 3. 加了环比

「本月赚 7.2 万」这个数字本身没有意义，老板真正想知道的是**比上个月好还是差**。

净利润旁边直接显示 `▲ 较上月 22,000.00`（涨绿降红），不用自己去翻上月报表。

### 4. 成本构成 Top 3 摊在成本下面

老板一定会问「钱都花哪了」。直接在营业成本下方列出最大的几项：

```
营业成本  48,000.00
办公费 40,000.00 · 水电费 8,000.00
```

不用点进报表翻科目。

### 5. 未记账凭证的警告

**这是最要紧的一条。** 有凭证还是草稿状态时，利润一定是偏小的，但界面上看不出来——老板拿着这个数做决定就会错。

现在直接标黄：

```
⚠ 3 张凭证还没记账，未计入上面的数字
```

## 同时修复：成本构成口径与净利润不一致

上一版把成本类科目（`5101 制造费用` 等）计入了净利润，但「成本构成」明细仍只统计 `6401/6402`。

后果：老板点开成本构成，明细加起来对不上合计——这是最容易被质疑的一类不一致。

现在两处用同一套口径（含未结转成本类科目余额，只取末级科目避免翻倍），并加了断言验证：

```
成本构成合计 = 48,000.00 = 营业成本 48,000.00  ✓
```

## 实测

10 月：收入 80,000，房租 10,000，工资 20,000 → 净利 50,000
11 月：收入 120,000，外发 40,000，电费 8,000 → 净利 72,000

首页显示：

```
本月净利润   72,000.00    ▲ 较上月 22,000.00
             利润率 60.0% · 年初至今 122,000.00
营业收入    120,000.00
营业成本     48,000.00
             办公费 40,000.00 · 水电费 8,000.00
```
