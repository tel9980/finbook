# v1.8.108 工作台补「待确认采购订单」待办（便捷）

## 问题

工作台「本月该干的事」里，销售侧有「待审批报价单」和「待确认销售订单」两条，采购侧只有「待审批请购单」一条——待确认的采购订单（草稿采购订单）漏掉了。老板习惯只看工作台，草稿采购订单没人点开「采购单据」页就看不见，供应商那边就压着没下单。

## 改法

在 `workbench::collect` 和 `workbench::collect_todos` 的采购块里，对称地补一条 `po_todo`：数本期采购订单里 `PoStatus::Draft` 的数量，文案「待确认采购订单」、跳转「采购单据」页（`po-doc`）。与销售侧「待确认销售订单」完全对称。

## 三条规矩

1. 只数草稿：`PoStatus::Draft` 才计入，已确认/已收货/已取消的不算。
2. 和销售侧对称：销售有「待确认销售订单」，采购就该有「待确认采购订单」。
3. 两个入口都补：`collect`（/api/workbench）和 `collect_todos`（get_notices）用同一份逻辑，避免一边有一边没有。

## 测试与门禁

- 变异 131（待确认采购订单把已确认的也算进来）实跑拦下。
- clippy 0 error、preflight 六步全绿。
