# FinBook v1.4.2

这一版是"日常顺手"专版：银行对账单有模板了，报税有人按时提醒了，旧账凭证能批量倒进来了，基础资料处处少点两下鼠标。另外修了往来核销里三个真 bug。

## 下载

| 平台 | 文件 | 大小 |
|------|------|------|
| **Windows 10/11** | `finbook-1.4.2-windows-x86_64.zip` | ~7 MB |
| Linux x64 | `finbook-1.4.2-linux-x86_64.tar.gz` | ~10 MB |

解压后得到三个文件：

```
finbook(.exe)          主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

账套就是一个 `.fbk` 文件（标准 SQLite），**备份只需复制这个文件**。

附件里还有服务器版（`finweb-1.4.2-linux-x86_64.tar.gz`，自部署 Web 端用）与校验和（`SHA256SUMS`）。

示例账套登录：`admin` / `admin123`

## 这一版的变化

### 1. 银行对账单模板：下载 → 填表 → 载入

银行对账页「导入 CSV」里多了「下载 Excel 模板」和「从 Excel 文件载入」，
和期初建账同一套用法。模板第二页写了一条新手最容易栽的：
**银行导出的对账单借贷是反的**（银行视角借＝支出），从网银复制过来先把借贷两列对调，否则自动勾对不上。

### 2. 报税日历提醒：到日子自动出现在待办里

工作台和通知铃铛、桌面首页都会在申报期内提醒：

- 增值税及附加（一般纳税人按月、小规模按季，看账套税务设置，不会报错税期）
- 个人所得税（工资薪金，每月 15 日前）
- 企业所得税预缴（1/4/7/10 月）、汇算清缴（5 月 31 日前）、工商年报（6 月 30 日前）

每条都写了"数从哪来"（比如小规模查 222102、个税去工资表看），照着填就行。

### 3. 桌面端凭证批量导入：换账套不用一笔笔敲了

凭证查询页「导入凭证」：通用 / 金蝶 / 用友三套列、粘贴或载入 Excel、
先预检（缺失科目、借贷不平、金额问题逐行列出，有阻断的不让执行）再导入。
缺失科目整行跳过（先去会计科目建好再导），导进来全是草稿，检查后记账。

### 4. 基础资料三处顺手优化

- 凭证辅助核算下拉可按编码/名称关键字过滤（客户存货多了翻不动的终结）
- 期初页辅助核算可点选：1122 这类科目的期初行能挂上往来单位，进账龄表
- Web 端 Ctrl+K 能搜档案，点结果直达辅助档案对应页签
- 凭证页缺档案可「＋新建」当场建（只填名称，编码自动编）；档案页单个新增编码留空也自动编号

### 5. 修了往来核销里的三个真 bug

都是"不一一对应收付款"的场景测出来的：

- 自动核销在"先收款、后开票"时会重复配平同一笔（参数错位），已修
- 账龄里部分核销过的收款越配越多（预收栏虚增），已修
- 预收账款（2203）的账龄整页空白，已修（维度按科目真实辅助核算取）

### 6. 修了结转后利润表空白 + 结账检查恒报未结转

- 结转损益后，损益科目借贷相抵，利润表归零：现在取数自动剔除结转凭证，结转前后都能看
- 结账检查"损益已结转"因查错来源字面量恒报未完成：已修正，结转后检查翻绿

### 7. 工程卫生：锁定工具链 + 全仓零警告

- 新增 `rust-toolchain.toml`，CI 不再随 stable 漂移
- `cargo fmt` 全仓重排，clippy 按 CI 口径零警告

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 导出 Excel/CSV 仅管理员与财务主管可用，普通账号仅能打印
- 附件哈希为 SHA-256 完整性校验（防误删损坏），不防篡改
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
