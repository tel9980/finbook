# v1.8.47 —— 月结向导：把「月末要做哪几件事」摊成一张打勾清单

月末结账以前是这样的：点「结账」，弹一串错误文字——

```
本期还有 3 张凭证未记账
有 4 个损益类科目尚未结转（如 600101 主营业务收入、6403 税金及附加…）
```

看完还是不知道**先做什么、做完了没**。小厂会计往往就是老板娘，她要的不是错误列表，
是一张清单：哪几项已经好了、哪一项还差、差的那项点哪里去补。

## 六个步骤

| 步骤 | 通过条件 | 不通过时说什么 |
|------|---------|--------------|
| 1. 期间顺序 | 上一期间已结账（首次结账则等于启用期间） | 「2026-02 还没结账，不能跳过中间期间直接结 2026-03」 |
| 2. 凭证全部记账 | 本期无草稿、无已审核未记账 | 「还有 3 张未记账（草稿 1 张 / 已审核未记账 2 张）」 |
| 3. 试算平衡 | 期初、本期发生、期末借贷均相等 | 直接列出 `problems()` 的三项 |
| 4. 损益已结转 | 损益类科目本期发生额结平 | 「还没结转：600101 主营业务收入、6403 税金及附加」 |
| 5. 成本类已转出 | 5101 制造费用 / 5201 劳务成本 无余额 | 「还挂在账上：5101 制造费用」 |
| 6. 现金不为负 | 现金与银行存款期末 ≥ 0 | 「100201 银行存款 期末 −1,200.00」 |

每步都有 `ok` / `blocking` / `detail` / `hint` 四样：界面画颜色，用户知道下一步点哪。

## 第 5 步是这次补的

成本类科目（5101 制造费用）既不在损益类里，也不一定进资产负债表存货项——它会**永久挂在
账上**，而利润表看得见支出、余额表看不出它没被结转。v1.8.45 修过一次「利润表漏算成本类」，
但结账这条路上一直没检查它。现在它是一步。

## 第 6 步故意不拦

现金/银行余额为负说明记错了方向，但**拦住结账并不能让人更好地改正**——只会逼人去反结账
绕开校验。所以它是「提醒」不是「阻断」：`blocking: false`，界面画黄色 ⚠。

这是有意的分级，不是漏写：

- **阻断**（红 ✖）：做完才能结账，且做完确实更对
- **提醒**（黄 ⚠）：真实发生了，但拦住它只会催生绕路

## 与预检是同一批判断

`periods::precheck` 已经能说「不能结账，因为 X」。向导不能变成第二套口径——「向导说可以
结了，点下去结账却报错」是这类功能最典型的腐烂方式。

所以 `findb::month_close` 有测试 `blockers_matches_precheck`：**向导的阻断项为空 ⟺ precheck
为空**，多一条少一条都会红。

## 两端同一份清单

- 桌面：`期末处理` 页顶部常驻「月结向导」面板（六个步骤 + 颜色 + 提示）
- 网页：`期末处理` 页把原来的「待处理问题」列表换成同一张清单

判定全在 `findb::month_close::report`，两端只负责画。

## 测试与验证

| 项 | 结果 |
|----|------|
| `cargo test --workspace` | 全绿（`findb` 月结向导 4 条 + `finweb` 向导接口 3 条） |
| 新增断言 | 步骤清单与顺序固定；空账套第一期可结；有草稿凭证即拦；已结账期间只报状态 |
| 变异验证 | 3 条全部拦下（向导把未记账当完成 / 未记账不再阻止结账 / 已结账期间仍说可以结），下限 90→**93** |
| 自检 | check-ci / check-js / check-portable / check-design-doc / check-simple-nav 全过 |

## 怎么用

月末打开「期末处理」，从上往下看六个步骤：

1. 有红 ✖ 的，按它下面那行灰字去做（多半是「去记账」或「点结转损益」）
2. 全绿了再点「结账」
3. 黄色 ⚠ 是提醒，可以先结账，但值得回看一下
