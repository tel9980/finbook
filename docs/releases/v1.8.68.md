# v1.8.68 —— 下单要记「按哪一版工艺排产」

## 一、问题

上一版让计件单价跟着工艺版本走，但**生产订单没记版本**。下单选了 V2，工序按 V2 建、
报工也带 V2；可订单上没这一列，事后「重新生成工序」只能退回默认版本 —— 同一张订单
混着两版工序，报工按哪版算钱全看运气，界面上看不出任何异常。

## 二、这一版做了什么

- `production_order` 新增 `routing_version`（空 = 默认版本），建单时记下；
  生成工序吃订单上的版本，不再自己猜。桌面端「加载工序」同样改为读订单版本。
- 兜底行为固定下来：订单没指定、工艺也没有默认版本时，退到该物料的第一个版本
  （只有 V2 版工艺的小厂不该被判「没有工艺路线」）。
- 网页端「工序报工」页新增「新建生产订单」：填产品编码自动带出工艺版本下拉
  （`GET /api/routing/:item/versions`），选哪一版就按哪一版生成工序；
  订单下拉与计件明细都显示 `@版本`。
- `GET /api/routing/:item?version=` 可看指定版本的工序，响应同时给出该产品的版本列表。
- 迁移 `SCHEMA_VERSION` 41 → 42（`MIGRATE_V42`），缺列旧账套升级用例覆盖新列。
