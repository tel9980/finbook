# v1.8.102 销售订单回款看板

## 问题
老板问「谁还欠我钱、欠多少」，以前只能自己拿订单和收款单去对：订单执行跟踪只有数量维度（发了多少），按客户汇总又看不出是哪几张单、每张欠多少。

## 改法
「销售单据」页新增 **谁还欠我钱** 面板（`report` 权限）：

- 每行一张订单：单号 / 客户 / 日期 / 订单金额 / 已收 / 未收（加粗）/ 状态；
- 顶部「共 N 笔、未收合计 X」；
- 数据跨期间，按未收金额从大到小排。

## 三条规矩
1. **只算已承诺的单**：作废（Cancelled）、草稿（Draft）不计。
2. **未收 = 订单金额 − 已收**：`balance = (total - collected).round2()`，`collected` 是 `so_payment_sum` 求和。
3. **已结清不列**：`balance == 0` 直接跳过。

## 接口
| 接口 | 说明 |
|---|---|
| `GET /api/sales/so/receivable` | `report`；`{rows, outstanding, count}` |

无 `price_view` 时金额字段服务端置零。
