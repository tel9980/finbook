# v1.8.36 —— 应收应付：先把数字弄对，再谈好不好用

这一版起因是一份只读审计：把「应收应付」从路由、界面到底层函数全过了一遍，逐条问
「这条路径上，用户会不会拿到一个**看起来正常、其实错**的数字」。

找到三处。它们都不是崩溃、不是报错，是**页面能开、文件能下、数字是错的**。

---

## 一、催款单把客户预存的钱算成欠款

`OpenEntry::open()` 是 `abs(signed) - settled` —— **没有方向**的绝对值。它回答「这笔
单据还剩多少没核销」，不回答「对方欠我多少」。催款单直接把它累加成催收金额。

实测：客户先打 30,000 预存，后来又提了 50,000 货。

- 账龄页：应收 50,000，其中预收 30,000（对）
- 催款单：「应向我方支付 **80,000.00**」（错，多算了客户自己的 30,000）

客户收到会直接翻脸，而这笔钱本来就是他自己先给的。最要命的是**两张表在同一个软件里，
没有一处报错**。

修法：

1. 用账龄那套方向归一 —— 贷方性质科目（2202 等）先翻号，让「正数 = 对方欠我方/我方
   欠对方」在全系统一个方向。不翻的话，供应商一张正常发票会被判成「预付」，对账函上
   一条应付都不显示。
2. 明细行带方向（应收 / 应付 / 预收 / 预付）。催收金额只累加「应收/应付」那一侧，
   预收/预付在下面单列一行 —— 客户看得懂「你给 5 万、我先收了 3 万、实际还欠 2 万」。
3. 一分钱不欠时**直接拒绝生成**。以前会出一张 **0.00 元**的催款单，比不发更糟。
4. 老账套已存的催款单没有 `direction` 字段（`serde(default)` 空串），**空串一律按
   应收/应付处理** —— 那些单据生成时还没有方向概念，改成预收等于篡改历史单据。

## 二、催款单导出只有一行汇总

`/api/export/dunning` 出的是 CSV，只有「单号/日期/单位/金额/状态/备注」，**没有明细**。
客户问「是哪几张单凑的 5 万」，会计只能回凭证里手工抄。

新增 `/api/export/dunning/xlsx`，两个 Sheet：

| Sheet | 内容 |
|-------|------|
| 催款单 | 每张单一行：单号、日期、类型、科目、客商、**应收金额**、**预收/预付**、笔数、状态、备注 |
| 明细 | 逐单：单号、客商、单据号、日期、摘要、金额、**方向** |

网页版「催款单」面板的导出按钮改指这份 xlsx。

## 三、查哪个月的账龄，由今天的日期决定

`/api/settle/aging` 的基准日缺省是「今天」，桌面端是「查询期间的最后一天」。

实测：查 2026-01 的账龄，一笔 1 月 5 日的单据在网页上算成 290 多天、全落最老那一档；
桌面端显示 26 天。导出的 Excel 跟网页一致、跟桌面不一致 —— 两个答案，谁也不敢拿给老板看。

修法：服务端缺省 `upto.last_day()`。基准日是**查询参数的一部分**，不该由今天决定；
真要按今天算，显式传 `as_of`。

## 顺手核过、判定不用改的地方

审计里还有几条听起来像缺口，实际是**有意设计**，写下来免得下次重做：

- **批量核销 / 多选**：`auto_settle` 已按往来 FIFO 批量配对，收款单审核也会自动核多张。
  手工再多选只提高误核概率。
- **账龄「按客户汇总」视图**：账龄本来就是一行一往来单位，再加汇总就是第二套算法。
- **预收/预付独立单据层**：收款单已经能承载（多余金额留往来腿），摊开成独立单据会打破
  「凭证即单据」的现有模型。
- **催款单「自动发送」**：仓库没有 SMTP/短信通道，小工厂实际是微信发 PDF 或打印盖章 ——
  该做的是导出（本次做了），不是发送通道。

## 还没做的（诚实清单）

| 缺口 | 为什么这版没做 |
|------|----------------|
| 账期与逾期天数 | 要改 `OpenEntry` 与账龄引擎的取数（客户档案里的 `pay_days` 目前全仓零引用），影响面比这次三处大 |
| 反核销不能部分撤销、不校验已结账期间 | 要动 `settle_record` 的表结构与期间锁，需要专门的迁移测试 |
| 账龄下钻到单据 | 要 `AgingLine` 带上 `entry_id` 列表，改动会波及账龄引擎与两端渲染 |
| 桌面端没有催款单界面 | 桌面端缺整个「催款单」页，属于新增界面而不是修口径 |

## 怎么用

- **催款单**：往来核销 → 催款单 → 新建。金额栏是「应收」，预收单列在下面；
  客户如果只预存没欠款，系统会直接告诉你「只有预收/预付 X，不需要催款」。
- **导出**：面板上的导出按钮现在出 Excel（汇总 + 明细），可以直接发给客户或打印。
- **账龄**：不填基准日时按「查询期间的最后一天」算，与桌面端一致；要按今天算就手填。
