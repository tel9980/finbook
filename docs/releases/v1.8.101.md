# v1.8.101 价目表/对账/报价单三件补强：导出带库存单位、对账导出、批量打印

## 问题

上两版加了「价目表导出」和「报价对账」，用下来还有三处不便：

1. 价目表导出只有计价口径（㎡/米/kg），客户看不出「300 只 = 7.02 ㎡」这个换算；
2. 对账表只能看，月底报账、发客户时没得导一份留档；
3. 报价单一张张打，一个客户一个月几十张，要点几十次。

## 改法一：价目表导出加两列（只读给人看）

`/api/price-rules/export` 的 xlsx 从 16 列扩到 **18 列**，末尾加「库存单位」和「折算系数」：

| 列 | 内容 | 规则 |
|---|---|---|
| 库存单位 | 这行的库存单位（读 `item_unit.base_unit`） | 没设时兜底「件」 |
| 折算系数 | 「1 库存单位 = 几 计价单位」 | 只填 `item_calc_unit` 里录了的口径；没录留空 |

- 这两列**不参与导入**（`import_rules` 只认前 16 列），客户填好发回来照常「批量导入」；
- 系数用满精度写（`fmt_exact`），不走 Money 列——后者两位小数会把 0.0234 压成 0.02。

## 改法二：对账表导出 Excel

新增 `GET /api/sales/quote/reconcile/export?period=`（`report`），把对账表导成
`报价对账-{期间}.xlsx`（带标题与副标题），列与屏幕对账表一致：

单号 / 客户 / 存货 / 数量 / 报价单价 / 实际单价 / 单价差 / 差额 / 订单状态

没转订单的：实际单价、单价差、差额三列**留空**，订单状态写「未转订单」——不假装有价。

## 改法三：报价单批量打印

「销售单据」页报价单列表加**复选列** + 「打印所选」按钮：

- 勾选若干 → 一次打一摞；一个都不勾 → 打**全部**；
- 复用打印页的 `runPrint`，字段集关掉税率/税额/行备注三列（报价单无税、折算说明在单据备注里）。

## 接口

| 接口 | 权限 | 说明 |
|---|---|---|
| `GET /api/price-rules/export?customer=` | `price_view` | 18 列 xlsx（前 16 列可回导） |
| `GET /api/sales/quote/reconcile/export?period=` | `report` | 对账表 xlsx |
| `GET /api/sales/quote/print-form?ids=…&fields=…` | `report` | 单张或批量（`ids` 逗号分隔） |
