# FinBook v1.8.2

这一版是**性能与运维增强版**：不动任何记账口径，在 v1.8.1 基础上补齐服务器端并发能力、大数据量下的查询/录入体验、账套备份可靠性，以及 CI 依赖治理。

---

## 下载

| 平台 | 文件 |
|------|------|
| **Windows 10/11** | `finbook-1.8.2-windows-x86_64.zip` |
| Linux x64 | `finbook-1.8.2-linux-x86_64.tar.gz` |
| 服务器端 | `finweb-1.8.2-linux-x86_64.tar.gz` |
| 校验和 | `SHA256SUMS` |

解压后得到三个文件：

```
finbook(.exe)          主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

附件里还有服务器版（`finweb-1.8.2-linux-x86_64.tar.gz`，自部署 Web 端用）与校验和（`SHA256SUMS`）。

示例账套登录：`admin` / `admin123`

**升级方式**：直接用新版程序打开原账套文件即可，数据库结构会自动升级（本次为 V36，与 v1.8.1 兼容，无需迁移），原文件不受影响——建议升级前先复制一份 `.fbk` 作为备份。

## 这一版的变化

### 1. 账套备份：一键打包下载（.fbk + 附件）

新增「系统管理 → 备份管理」页面和 `GET /api/backup/download` 接口：

- 把账套主文件 `.fbk` 与附件目录 `.attachments/` 打成一个 `.zip`，一次下载完整账套，再也不会只备份主库而漏掉发票扫描件、合同 PDF。
- 打包前自动 `WAL checkpoint(TRUNCATE)`，保证打包的 `.fbk` 是一致快照，文件级复制（`fs::copy`）拿到完整数据。
- 页面还支持列出历史备份、一键恢复（恢复前自动再备份一次当前库，可回退）。

### 2. 操作日志前端页面

新增「系统管理 → 操作日志」，调用已有的 `/api/logs` 接口：

- 按用户 / 模块 / 动作 / 详情关键字搜索，最近 200 条表格展示。
- 财务合规：谁什么时候做了什么，可追溯、可导出配合审计。

### 3. 大数据量下的查询与录入体验

- **明细账虚拟滚动**：单科目明细数万行时，只渲染可视区域行（＋1 行缓冲），DOM 节点从 N 降到可视行数，滚动流畅，不再卡顿。
- **侧栏搜索防抖（150ms）**：连续输入时只在停止 150ms 后重渲染导航，避免每次按键都遍历 69 项功能。
- **凭证列表键集分页后端（`list_page_keyset`）**：`WHERE id > ? ORDER BY id ASC LIMIT ?`，深度分页不再扫描 OFFSET 前的全部行，翻到后面的页也不再变慢。前端切换可在后续版本接入。

### 4. 服务器端并发与 WAL 优化

- `PRAGMA wal_autocheckpoint = 1000`：每 1000 个页面自动检查点，防止 WAL 文件长期运行无限膨胀。
- 新增 `Db::checkpoint_wal()`：备份前、账套注销前、服务器停止前调用，把 WAL 写回主文件并截断，备份体积更小、恢复更快。

### 5. 附件上传更快

- 附件 SHA-256 哈希计算从纯 Rust 手循环改为 `sha2` crate（硬件可加速），大附件（接近 10MB）上传时的哈希计算延迟明显降低。对外签名不变，现有账套兼容。

### 6. 性能回归测试（cargo bench）

新增 `crates/findb/benches/`：

- `vouchers.save`：2 / 20 / 100 行凭证的保存耗时
- `BalanceSnapshot.load` 与 `for_account`：余额快照加载与前缀预聚合查表

CI 可用 `cargo bench --workspace --locked` 量化，未来优化前后对比，防止性能悄悄退化。

### 7. CI 依赖治理

- 新增 `cargo-deny` job：license 白名单（MIT/Apache/BSD 等），禁止 GPL/LGPL/AGPL、未知来源、yanked 版本。
- 新增 `cargo-udeps --all-targets` job：检测未使用的 Cargo 依赖，保持依赖图精简。
- 附件上传已移除 `multipart = "0.18"`（该依赖会拖入 hyper 0.10 / iron / time 0.1 / idna 0.1.5，触发 4 个 RUSTSEC 漏洞），改用 axum 自带 `Multipart`（零新增依赖）。

### 8. CSV/Excel 导入向导补全

- 切换导入类型时自动重置已选文件、粘贴内容、科目映射，避免跨类型错用。
- 导入凭证成功后增加「查看导入的凭证」按钮，直达凭证列表（凭证落草稿，还需审核 → 记账）。
