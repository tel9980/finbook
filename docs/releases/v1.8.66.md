# v1.8.66 —— 桌面端也能按规则报价；挂具终于有台账

## 一、桌面端报价单：按加工费规则一键取价

v1.8.65 只给网页报价单接了「按规则报价」，桌面端开单仍在手敲单价——同一套加工费规则，
两个界面的算法不一样，报价就会对不上。这一版把桌面端补齐：报价单那行多了「加急」勾选和
「按规则报价」按钮，单价填的是「合计 ÷ 数量」（满精度、无千分位），报价单金额（数量 × 单价）
正好等于规则算出的合计；低于最低收费时这个单价会高于规则单价，那正是最低收费的意思。
计价口径仍然只在 `findb::processfee` 一处。

## 二、挂具台账：一套挂具的两本账

氧化厂的挂具自己有寿命、会坏、常常客户专用。以前只在演示数据里当存货挂着，实际上
既没有数量账也没有寿命账。这一版新增 `tool_item`（档案）与 `tool_move`（收发流水）：

- 四类单据：`buy` 购置、`issue` 领用、`back` 归还、`scrap` 报废。
- 结存分「在库 / 在车间 / 累计报废」，另计「使用次数」与「额定次数」，用满进「该换新」清单。
- **报废只从在库扣**：坏挂具先「归还」入库再报废，「在用」永远等于「领出去还没回来的」。
- 寿命只看归还（领了没用就还回来不记次数）；额定次数 0 = 不限。
- 只记数量与次数，不进存货、不出凭证（与客供料台账同一口径）。

桌面端（业务 → 挂具台账）与网页端（生产制造 → 挂具台账）都有：结存表、收发流水、
登记收发、新增档案、该换新清单。

## 四、没动

- 客供料仍不出凭证（数量口径备查台账），来料加工是否按受托加工物资入账、损耗是否
  计加工成本，属会计口径，等确认后再定。
- 计件单价仍不分工序版本（`piece_rate` 只有物料 + 工序名）。
- 挂具不做折旧、不做摊销：它是工装不是固定资产，坏了就报废换新，账上只看套数。
- 成本分摊（槽液、水电、返工件）仍靠人工设率。
