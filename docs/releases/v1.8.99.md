# v1.8.99 报价单打印：客户问「这 0.28 怎么来的」照着念就行

## 问题

报价单一直只有列表 + 编辑，**没有打印表单**——销售订单、采购订单、收付款单都能套打，
唯独报价单打不出来。客户来问「这个尺寸、300 件，单价怎么是 0.28」，只能口述。
而 v1.8.96 起报价单已经把规格 / 口径 / 工艺 / 折合数量 / 用的哪条价全锁进单子，
却一直没法把它亮出来。

## 改法

「销售单据」页的报价单列表，每一行加一个 **打印** 按钮，点开就是一张 A4 套打。
单据级「备注」里带上折算说明：

> 备注：规格 1250*250*3；折合 7.02 ㎡；工艺 硬质氧化；含送货

客户拿着这张单，对着「数量 300 × 单价 0.2808 = 金额 84.24」和那行折算说明，
自己就能验算出来，不用再打电话问。

## 三条规矩

1. **只打锁定快照，不重算。** 打印读的是报价单里存下来的 `unit_price` / `calc_qty` /
   `spec` / `process`，不回头查价目表——那张价后来可能调过，重算出来和客户手上那张
   对不上，反而惹麻烦。
2. **默认不打税率/税额列。** 报价单不含税，默认关掉「税率」「税额」「行备注」三列；
   没显式传 `fields` 才关，传了 `fields=rate,tax,...` 仍可强制显示。
3. **无「价格查看」权限者自动裁价格列。** 与销售订单套打一致，送货联不泄露价格。

## 接口

| 接口 | 权限 | 说明 |
|---|---|---|
| `GET /api/sales/quote/print-form?ids=1,2` 或 `?period=` | `report` | `ids` 空 = 当期全部；返回 `text/html` 套打 |
