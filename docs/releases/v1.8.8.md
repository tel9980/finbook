# FinBook v1.8.8

面向小工厂的记账体验改进：**现金不再只有一个"银行"**，**客户付款与付供应商可以不必一一对应**。

## 新功能

### 多银行 + 微信作为现金账户
- 资金账户不再硬编码单一 `B01`。收付款单、内部资金调拨单新增「银行/微信」字段，可填 `B01`、`B02`… 或 `WECHAT`。
- 银行承兑/商业承兑票据流转凭证、融资凭证同步取用实际账户编码，不再一律挂 B01。
- 桌面端收付款、调拨表单已加入对应输入框；Web API 的 `ReceiptCreateReq` / `TransferCreateReq` 同步支持 `bank` 字段。
- 账套数据库升级到 **SCHEMA v37**，`receipt_doc`、`fund_transfer` 新增 `bank` 列，旧账套打开时自动迁移，`bank` 为空时按原行为落到 `B01`，历史数据不受影响。

### 收付款跨方分配（不再强求一一对应）
- 收付款单新增「跨方单位」「跨方金额」两项。
- 审核时先按本方往来单位 FIFO 核销 `金额 - 跨方金额`，再按跨方单位 FIFO 核销 `跨方金额`：
  - 收款 → 冲抵应付（客户打来的钱用来付供应商的款）
  - 付款 → 冲抵应收
- 多余部分仍各自落入默认往来科目（预收/预付性质），不会丢账。
- 账套数据库升级到 **SCHEMA v38**，`receipt_doc` 新增 `cross_party`、`cross_amount` 列，默认空/零，等同于原有行为。

### 跨往来单位核销与对冲（沿用既有能力）
- 核销界面「跨单位/跨科目互抵」可对 A 单位的债权与 B 单位的债务直接相抵，自动生成过渡凭证。
- 往来对冲单支持客户 ≠ 供应商，生成「借应付 / 贷应收」凭证并在两端各自 FIFO 核销。

## 兼容性
- 旧 `.fbk` 账套直接打开即自动升级到 v38，无需手工操作。升级前建议先复制一份账套文件备份。
- 已有的收付款、调拨数据在新的 `bank` / `cross_party` / `cross_amount` 列为空/零，行为与升级前完全一致。
