# v1.8.103 回款看板补强：账龄预警 + 催款函

## 问题
上一版「谁还欠我钱」只有金额，看不出欠了多久。而催款函、账龄、收款核销在往来模块里早已做好，只是这张按订单的看板没接上——同一笔欠款，账龄页看得见超期，看板上却看不出来。

## 改法（三项一起做）
1. **超期应收预警（新代码）**：看板每行加「逾期」列，超期标红「逾期 N 天」；顶部摘要补「其中 M 笔已逾期、K 笔超 90 天」。
2. **催款函一键生成（薄接线）**：有 `voucher_new` 权限时每行给「催款函」按钮，复用往来模块已有的 `dunning_create`，生成后直接打开打印页。
3. **收款核销（确认已接通，不重写）**：收款动作早已写收款单 + 审核出凭证 + `auto_settle` 自动核销，预收走 `cross_settle`。本版只报告，不改。

## 三条规矩
1. **账期从订单日期起算（近似口径）**：`overdue_days = max(0, 今天 − 订单日期 − 账期)`。真正的到期日是「发货/开票日 + 账期」，订单日期是手里最接近的起点。
2. **账期只认客户档案的 `pay_days`**：新增 `customer_pay_days_map`，回款看板/账龄/催款函三处共用一个来源。
3. **未设账期按 0 天**：货到即付，到期那天起就算逾期。

## 接口
| 接口 | 说明 |
|---|---|
| `GET /api/sales/so/receivable` | 响应增 `pay_days`/`overdue_days` 与 `overdue_count`/`overdue_90_count` |
| `POST /api/settle/dunnings` | 复用：生成催款函 |
| `GET /api/settle/dunnings/:id/print` | 复用：催款函打印 |
