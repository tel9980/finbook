# FinBook v1.3.0

这一版只做一件事：**期初建账和档案录入不用再对着空白格子发愁**——点一下拿到 Excel 空表，在 Excel 里填好，再点一下读回来。

---

## 下载

| 平台 | 文件 | 大小 |
|------|------|------|
| **Windows 10/11** | `finbook-1.3.0-windows-x86_64.zip` | ~7 MB |
| Linux x64 | `finbook-1.3.0-linux-x86_64.tar.gz` | ~10 MB |

解压后得到三个文件：

```
finbook(.exe)          主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

账套就是一个 `.fbk` 文件（标准 SQLite），**备份只需复制这个文件**。

附件里还有服务器版（`finweb-1.3.0-linux-x86_64.tar.gz`，自部署 Web 端用）与校验和（`SHA256SUMS`）。

示例账套登录：`admin` / `admin123`

## 这一版的变化

### Excel 导入模板：下载 → 填表 → 载入

以前从旧账往新账搬数据只有"复制粘贴"一条路：Excel 里哪两列、什么顺序、要不要表头，全凭经验，贴错了才知道。

现在「期初建账」和各档案页（客户 / 供应商 / 部门 / 职员……）多了两个按钮：

1. 「**下载模板**」—— 存一个 `.xlsx` 空表。第一页是数据区（表头 + 两行示例，删掉填自己的），第二页是填表说明。
2. 「**从 Excel 文件载入**」—— 填完直接读进来，**自动进预览**：期初能立刻看到试算平不平（借方合计 / 贷方合计 / 差额），档案能看到多少条可导入、多少条因编码已存在被跳过。

方向不用填（资产自动记借、负债权益自动记贷），只写名称也行（编码自动编号）——原来批量粘贴的省心规则一个没变，只是换了个更顺手的填表方式。

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 导出 Excel/CSV 仅管理员与财务主管可用，普通账号仅能打印
- 附件哈希为 SHA-256 完整性校验（防误删损坏），不防篡改
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
