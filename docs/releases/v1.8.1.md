# FinBook v1.8.1

这一版是**纯优化版**：不动任何记账口径，把界面录入的手感、大数据量下的查询速度、
以及服务器端的并发能力整体提了一档；另外新增"账套级开关：启用生产管理"（账套选项，
默认关，按账套存储）。关闭后默认精简侧栏不铺开生产制造组，适合纯贸易/服务/财务
核算团队；其余全部功能入口仍可见，并始终可通过顶部搜索框直达（藏起来 ≠ 拿掉）。

1. **生产模块开关（账套级）**：小型财务团队用不到"生产/制造"这一组菜单时，
   在「系统设置 → 账套选项」里取消勾选 **启用生产管理**，侧栏的生产组立刻隐藏，
   界面清爽一大截。开关按账套存，每个账套自己决定，不影响别的账套。
2. **记凭证更快**：科目过滤不再"打字打着打着光标跳走"；分录行改成**增量渲染**
   （原来每次同步都整表重建，行多时明显卡）；借方填了数字自动把贷方清零并跳到下一行，
   连续录入一借一贷几乎不用碰鼠标。
3. **报表与余额更快**：余额快照加了**前缀预聚合**，取任一科目余额从"扫全表"变成"查表"；
   工作台 12 期趋势原来要完整渲染 26 次报表，现在一条聚合 SQL 搞定。
4. **大账套更抗压**：补齐 37 个缺失索引（凭证分录、采购/销售行、库存流水等），
   并上调 SQLite 缓存（32 MB）、启用 mmap（256 MB）、临时表进内存；
   密码策略改为进程内缓存，每个请求少一次"开库 + 读表 + 解析 JSON"。

## 下载

| 平台 | 文件 | 大小 |
|------|------|------|
| **Windows 10/11** | `finbook-1.8.1-windows-x86_64.zip` | ~7 MB |
| Linux x64 | `finbook-1.8.1-linux-x86_64.tar.gz` | ~10 MB |

解压后得到三个文件：

```
finbook(.exe)          主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

账套就是一个 `.fbk` 文件（标准 SQLite），**备份只需复制这个文件**。

附件里还有服务器版（`finweb-1.8.1-linux-x86_64.tar.gz`，自部署 Web 端用）与校验和（`SHA256SUMS`）。

示例账套登录：`admin` / `admin123`

**升级方式**：直接用新版程序打开原账套文件即可，数据库结构会自动升级（本次为 V36），
原文件不受影响——建议升级前先复制一份 `.fbk` 作为备份。

## 这一版的变化

### 1. 生产模块开关（账套级）

**在哪里**：系统设置 → 账套选项 → 「启用生产管理」（默认关，按账套存储，不影响别的账套）。

关掉后，默认精简侧栏不铺开「生产订单 / 领料 / 完工 / 在制品」等生产制造组；已有数据不删除，
打开搜索框仍可直达「MRP 运算 / 工艺路线」等功能，随时再铺开。适合只做贸易、服务、
纯财务核算的团队。

### 2. 记凭证的手感

- **过滤不抢焦点**：在科目栏里打字筛选时，不再因为筛选结果重绘把输入焦点顶掉。
- **分录行增量渲染**：新增行缓存，只在增行/删行时重建 DOM，同步数据仅刷新对应单元格。
- 借方与贷方互斥：借方填数自动清零贷方，焦点自动跳到下一行。

### 3. 余额与报表提速

- 余额快照**前缀预聚合**：按科目前缀先汇总，取任一科目（含下级）余额由线性扫描变为查表。
- 工作台 12 期趋势（资产负债 / 利润 / 权益）由 26 次完整报表渲染改为**单次聚合查询**。

### 4. 大账套与并发

- 补 37 个缺失索引，迁移版本升至 **V36**（打开自动迁移，无需手工操作）。
- 连接级 PRAGMA：`cache_size=32MB`、`mmap_size=256MB`、`temp_store=MEMORY`，
  配合已有的 WAL，读多写少的多人在线更稳。
- Web 端请求复用同一连接，密码策略进程内缓存（修改策略立即生效，有测试覆盖）。

### 5. 修复

- 凭证附件上传的 multipart 解析改为标准实现，附件上传/下载/删除全链路测试通过。
