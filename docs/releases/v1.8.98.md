# v1.8.98 价目表导出 Excel：客户要「发我一份」

## 问题

客户（或对方采购）常来一句「把你们的价发我看看」。以前只能截图：一格一格点下来，
截得又乱又不全，还截不出「这一格当前到底哪个价」。客户想在那张表上改几个数发回来，
也没法直接导 —— 又退回「批量导入」一格一格粘。

## 改法

「加工费规则」页工具栏加**导出 Excel**按钮。下载一个 `加工费价目表.xlsx`
（右上角填了客户就是 `加工费价目表-C01.xlsx`），列头与「批量导入」的模板**逐字一致**
（16 列），所以这张表导出去改完，**能原样导回来**。

只读账号（`price_view`）也能导，不要求能改价。

## 三条规矩

1. **每个「格」只导当前生效的那一条。** 格 = 物料 + 客户 + 口径 + 工艺档 + 规格区间 +
   数量区间。同一格里的历史老价、停用的都不进导出；没有已生效的价就导最近一版未来价，
   让客户能提前看到下月新价。
2. **生效日期原样保留，不置空。** 批量导入的身份里含生效日期，客户改价发回、日期不动，
   覆盖的正是当前这一版。若置空，而当前价来自未来生效的调价，导入会覆盖被阴影的旧
   「立即」版、而未来版仍赢 —— 新价反而不生效。
3. **金额满精度写、无千分位。** 单价 / 起步价 / 加急固定费落库恒两位小数，
   「加急率%」可能不是两位 —— 四舍五入再导回就静默丢尾数。

## 接口

| 接口 | 说明 |
|---|---|
| `GET /api/price-rules/export?customer=` | `price_view`；`customer` 空 = 全部客户（含通配价），非空 = 精确匹配该客户；返回 xlsx |
