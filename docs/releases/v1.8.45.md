# v1.8.45 —— 利润表和首页，不能是两个净利润

这一版源自一个具体的问题：**小工厂要不要做「成本结转凭证」，做完之后报表能不能对上。**

答案是：**不用做**——但原来的利润表是错的。

## 一、先说结论：这个记法不需要成本结转凭证

厂的日常是：房租、水电、煤气、外发加工费，发生时直接借 `510105 厂租房租` 这类
制造费用明细，月末点一次「结转损益」。**不需要**再做一张
「制造费用 → 生产成本 → 库存商品 → 主营业务成本」的成本结转凭证，
因为这套账不做存货成本核算，成本当月就该进利润。

v1.8.17 起「结转损益」已经把成本类科目一起转进本年利润，所以结转这一步本来就是对的。

## 二、真正错的是利润表

实测（收入 100,000、房租 15,000 记 510105）：

```
=== 结转前 ===
  利润表 四、净利润      100,000.00
  首页   收入 100,000 成本 15,000 净利 85,000.00
  对比   利润表 100,000 vs 首页 85,000  →  不一致 ❌

=== 结转后 ===
  利润表 四、净利润      100,000.00
  首页                   净利 85,000.00
  对比   不一致 ❌
```

原因就一行代码：利润表模板里「减：营业成本」取的是 `expense(&["6401", "6402"])`，
而 5101 制造费用**从来不属于这两个科目**。所以这笔房租在利润表里凭空消失了，无论
结没结转——结转凭证把 5101 转进本年利润，而本年利润不是利润表的取数科目。

**同一套账、同一个月、两个净利润**，老板问「这个月到底赚多少」，谁也答不上来。
而且方向很危险：利润表说赚 10 万，实际赚 8.5 万，是按「看起来更好看」的那边错。

## 三、改法：营业成本取净发生额，不取余额

```rust
// crates/fincore/src/report/income.rs
expense(&["6401", "6402", "5001", "5101", "5201"])
```

关键是取**净发生额**（借 − 贷）而不是余额，这样三种记法都对得上：

| 记法 | 利润表成本 | 为什么对 |
|------|-----------|---------|
| 只记 5101，没结转 | 15,000 | 借方发生额就是当月成本 |
| 做过「结转损益」 | 15,000 | 结转凭证被 `with_exclude_carry` 剔除，借贷不相互抵消 |
| 手工 5101 → 5001 生产成本 | 15,000 | 5101 相抵为 0，5001 净发生 15,000 顶上 |
| 完整链 5101→5001→1405→6401 | 15,000 | 每一环净发生额相抵，只有 6401 那 15,000 算一次 |

取余额会错在最后一行：成本先堆在 5001、再进 1405 库存商品，那时成本确实还没实现，
取余额会把存货成本提前扣成费用。

**为什么不在利润表加一行「在产品」**：小工厂不做在产品盘存，多一行就要多填一张表。
真做存货核算的厂走完整链，这张表也自动正确。

## 四、所以「要不要做成本结转凭证」

- **不做**（推荐，也是现在的手册口径）：成本类科目当月直接进利润，月末只点「结转损益」。
- **要做的唯一场合**：厂里确实要按产品核算成本、有在产品和产成品盘点。这时可以手工
  做 5101 → 5001 → 1405 → 6401 的凭证，本版之后利润表在每一种中间状态都对得上，
  不会重复扣、也不会提前扣。

## 验证

| 项 | 结果 |
|----|------|
| 新测试 `crates/findb/tests/income_vs_dashboard.rs` | 4 条全过：未结转 / 已结转 / 只做一道成本结转 / 完整成本链，每条都断言「利润表净利润 == 首页净利润 == 85,000」 |
| 变异 | `㉗ 营业成本退回只算 6401/6402` 被拦下（`1 failed`），下限 84→**85** |
| 全量 | `cargo test --workspace` 全绿 |

顺手修了变异脚本的一个坑：`cargo` 不在 PATH 时，58 条变异会集体报「测试根本没跑」，
看着像整套失效。现在直接报「找不到 cargo，先 export PATH」。
