# FinBook v1.6.0

这一版新增**资金调拨**：银行账户和现金之间互相转钱（提现备用、银行间划转、现金存回银行），录一张单、审核后自动生成凭证（**借 转入账户 / 贷 转出账户**），桌面版和网页版都能用。另外把两份对标报告里关于「成本预测 / 成本差异 / 增值税申报表」的过期结论改正了。

## 这一版的变化

### 1. 资金调拨（账户间转账）

**在哪里**：资金管理 → 「资金调拨」页签（桌面版和网页版同一位置）。

**怎么用**（四步）：

1. 选**转出账户**、**转入账户**（下拉里只列现金/银行科目，如 `100201` 工行基本户、`1001` 库存现金）；
2. 填**日期**、**金额**、**备注**（如「提现备用」「工行转建行」）；
3. 点「**新增调拨**」——此时只是一张**待审核**的草稿单，还没进账；
4. 有审核权的人点「**审核**」——系统自动生成一张凭证：**借 转入账户 / 贷 转出账户**，金额相等。

生成的是**凭证草稿**，会计再记账后才进余额（和收付款单一个规矩）。

**几条规则**（都会在保存时拦下来，不会悄悄记错）：

- 转出和转入**不能是同一个账户**（同户调拨是空动作）；
- 两端都必须是**现金 / 银行科目**，金额必须**大于 0**；
- **撤销审核**会删掉那张**未记账**的凭证，单据回到草稿，可以改名改钱再重来；
- 凭证**已经记账**的，要先反记账，才能撤审。

**和「收付款」的区别**：收付款是跟客户/供应商往来、会自动核销应收应付；调拨是**钱在自己两个账户之间挪**，不涉及往来、不核销。

### 2. 两份对标报告的过期结论已改正

`GAP_RESEARCH_REPORT.md`、`COMPREHENSIVE_COMPARISON.md` 里把**成本预测**、**成本差异分析**、**增值税申报表**标成了 ❌ / 🟡（写成「未实现」）。这三项其实早已实现（成本预测 `cost_forecast_report`、成本差异 `stdcost::variance_report`、增值税申报表 `findb::taxdecl`），本次按代码实际情况改正。

### 3. 工程卫生

- 资金腿的辅助核算（1002 系银行账户挂 `bank=B01`）抽成**一处**（`findb::funds::fund_account_aux`），收付款单与资金调拨共用 —— 避免「调拨忘了挂银行辅助」这类**不会报错、只会让银行对账对不平**的静默漏检。
- 新增的取数复用已有科目集合（资金日报同一套 `is_cash`/`is_bank`），不另起口径。
- 资金调拨单的表 `fund_transfer` 为**纯新增**表：老账套打开时按 DDL 自动补齐（`tables_complete` 机制），无需手工迁移。

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 导出 Excel/CSV 仅管理员与财务主管可用，普通账号仅能打印
- 附件哈希为 SHA-256 完整性校验（防误删损坏），不防篡改
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
