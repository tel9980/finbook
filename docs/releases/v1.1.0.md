# FinBook v1.1.0

面向**个人 / 小微企业的日常记账**。这一版把「下载 → 双击 → 用起来」这条链路上的坎拆掉了。

---

## 下载

| 平台 | 文件 | 大小 |
|------|------|------|
| **Windows 10/11** | `finbook-1.1.0-windows-x86_64.zip` | ~7 MB |
| Linux x64 | `finbook-1.1.0-linux-x86_64.tar.gz` | ~10 MB |

解压后得到三个文件：

```
finbook.exe            主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

账套就是一个 `.fbk` 文件（标准 SQLite），**备份只需复制这个文件**。

## 建议的第一步：先打开示例账套看看

包里附了一份示例账套——一家小商贸公司 2026 年 1 月的账，已经记好 9 笔业务（采购付货款 / 赊销开票 / 收货款 / 发工资 / 付房租 / 结转成本 / 缴税 / 付运费），**借贷平衡、全部已记账**。

建议按这个顺序点一遍，照着走就知道软件怎么用了：

1. 「工作台」—— 看这个月的大致情况
2. 「凭证查询」—— 看那 9 笔账长什么样
3. 「科目余额表」—— 看每个科目还剩多少余额
4. 「会计报表」—— 看资产负债表、利润表

看完之后建议：复制一份留着对照，再新建一个自己的空白账套开始记。

示例账套登录：`admin` / `admin123`

## 这一版的变化

### 1. 精简模式（桌面端）

完整侧栏有 **56 项**，其中生产制造、供应链、成本、预算等模块与日常记账无关，把菜单撑得很长。

侧栏底部勾选「**精简模式**」后，只剩 12 项：

> 工作台 / 填制凭证 / 凭证查询 / 账簿查询 / 科目余额表 / 会计报表 / 期末处理 / 银行对账 / 往来核销 / 会计科目 / 期初建账 / 备份恢复

- **不是删功能**：被折叠的模块一项没少，取消勾选立刻全部回到侧栏
- 勾上后底部有「临时看全部功能…」，需要时临时展开，不必改设置
- 开关记在这台电脑上（不进账套文件），所以把账套拷给别人不会把你的偏好带过去

### 2. 建账向导不再有术语墙

「科目级长 `4-2-2-2`」原来和「企业名称」并排摆着，是新手建账时的第一道坎——但系统已预置 199 个标准科目，级长保持默认就够用。

现在它被折进默认收起的「**进阶设置（一般不用改）**」，说明也改成了人话。「启用期间」旁补了「填你要开始记账的那个月」，「纳税识别号」旁补了「选填，打印报表时会用到」。

### 3. 发布包不再只有一个裸 exe

以前下载下来只有一个 `finbook.exe`，现在带上大白话说明和一份带数据的示例账套。新手打开一份空白账套是学不会东西的——得先看到「记完一个月账应该长什么样」才有参照。

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 导出 Excel/CSV 仅管理员与财务主管可用，普通账号仅能打印
- 附件哈希为 SHA-256 完整性校验（防误删损坏），不防篡改
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
