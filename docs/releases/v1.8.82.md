# v1.8.82 —— 首页说人话：一眼知道「该先办哪件事」

这一版**不改数据结构、不改任何记账规则**，`1.8.81` 的账套可以直接用。
改的全是「打开软件第一眼看到的东西」，因为原来那一眼看得很费劲。

---

## 一、问题：界面上全是会计话

上一版把首屏的四个自检数字收起来了，但留下的仍是会计语言：

```
试算平衡
  期初：借 0.00 / 贷 0.00
  本期：借 450,000.00 / 贷 450,000.00
  期末：借 1,235,000.00 / 贷 1,235,000.00
  ✔ 借贷平衡
```

小厂老板不是学不会「试算平衡」，是**不需要**。他要知道的只有一句：**账有没有记错。**

---

## 二、改法：先说结论，数字收起来

现在这一块是：

```
账有没有记错
  ✔ 账是平的，没有记错的凭证
  每一笔借方都有对应的贷方，可以放心出报表。
  ▸ 逐项数字（借方 / 贷方）        ← 会计对账时才展开
```

账不平的时候直接告诉他差多少、去哪查：

```
  ✖ 账不平，有凭证记错了
  差 1,000.00，去「凭证查询」逐张看。
```

**数字一个都没少**，只是分了两层：

| 原来天天摊在首页 | 现在 |
|---|---|
| 期初/本期/期末 借方贷方六个数 | 「逐项数字」折叠层，点了才展开 |
| 本期凭证 / 待处理 / 本期发生额 / 期末余额 四张卡 | 「账目概况（几张凭证、多少钱进出、余额）」折叠层 |
| 试算平衡 | 账有没有记错（结论提到最上面） |

## 三、连同其它几处一起换了说法

| 原来的词 | 现在的说法 |
|---|---|
| 试算平衡 | 账有没有记错 / 账对不对 |
| 本期发生额 | 本期借方合计 |
| 期末余额 | 期末借方合计 |
| 借贷不平衡 | 账不平，有凭证记错了（附差额） |
| 期末对账：检查试算平衡、余额方向、银行未达账项与未生成凭证的业务单据 | 结账前先体检：账平不平、余额方向对不对、银行有没有未达账项、有没有业务单据还没生成凭证 |

**有一处故意没改**：网页版期初建账里的「✓ 平衡 / ✗ 不平衡」。E2E 测试按这两个字
断言「随输入实时刷新」，改文案等于把这个闸门弄哑。代码注释里写明了原因，
防止以后有人当遗留术语顺手改掉。

## 四、教程补了一节：打开软件第一眼该看什么

`docs/小白日常操作教程.md` 第二节整节重写（教程随发版包一起发）：

- **那行带 ⚠ 的话** —— 五种情况对照表，每种都说「什么意思 + 怎么办」：

  | 看到的话 | 怎么办 |
  |---|---|
  | 还有 N 张凭证没记账 | 去「凭证查询」勾选 → 批量记账 |
  | N 家客户的钱超过 90 天没收回 | 先催这几笔，别的放后面 |
  | 净欠外面 X | 留意付款节奏，看手头现金够不够 |
  | 本月还没有收入凭证 | 去记第一笔加工费 |
  | 收支正常，暂无卡住的事 | 该干嘛干嘛 |

- **赚了多少 + 钱在哪** —— 附一句提醒：小厂出事多半不是不赚钱，是钱压在客户手里
- **账有没有记错在哪看** —— 看到 ✔ 就放心，看到 ✖ 去哪查
- **新加「二·补」** —— 原来那些词 vs 现在说法的对照表

速查卡同步成「月中：首页看三处 —— 那一行 ⚠ 说了什么？赚了多少？账是不是 ✔ 平的？」
