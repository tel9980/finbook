# v1.8.71 —— 返工件成本单：这批返工到底亏了多少

## 一、问题

氧化车间的返工件，以前只有一张「工序检验」记录（合格/返修/报废），返工花的材料和工时
既没地方记，也不好意思记回原单 —— 记回去原单单位成本就虚高了，标准成本差异与毛利全跟着错。
车间问「这批返工亏了多少」，只能靠估。

## 二、这一版做了什么

新增**返工成本单**（桌面端 + 网页端 + 接口）：

- 一张返工单**挂在来源生产订单上**，数量不能超过原单计划量；单号 `RG-202601-001`。
  来源订单的编号与物料由系统带出，界面填什么都不算。
- 成本分**材料 / 人工 / 制造费用**三类单独归集，随便追多少笔，随时看三段合计。
- **占比** = 返工成本 ÷ 原单已归集成本。原单还没归集成本时分母是 0，这时给空白而不是 0%
  ——0% 会被读成「这批返工不花钱」。
- **已结案**的返工单不许再追加/删除成本、不许删单：结案意味着这批返工的钱已经认下来了，
  再改会让上个月看过的报表变样（要改先把状态改回「进行中」）。
- **期间结账后**也不许改，与工资表那道闸同一个理由。
- 返工单**不生成凭证**：材料/人工的真实发生额在领料、报工、工资那边已经入过账，
  这里再出一次就是重复入账（与客供料台账同一个判断，见 v1.8.70）。

## 四、没动

- 不自动从领料单/报工流水抓成本进返工单：返工用的料和工时往往和正常生产混在一起，
  自动抓会抓错；这一版是手工归集，先把「有地方记」这件事解决。
- 不做返工的标准成本差异分析（要先把返工原因、责任部门这些字段用起来）。
- 客供料仍不出凭证（v1.8.70 定案）。
