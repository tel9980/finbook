# v1.8.75 —— 利润分析表：你们厂那张表，系统直接出

## 一、问题

你发的那张「氧化（老厂）月份利润分析表」有 16 行：收入，然后厂租、电费、水费、化工、
染料封闭剂、工资、包装材料、货车运输费、外发加工费、税金、社保费、业务费、办公用品费、
维修费、挂具费，最后是净利润。

这些名目在标准科目表里对不上——「化工」不是一个科目，「挂具费」也不是。按会计准则去套，
最后只能把化工、染料、维修费全塞进「制造费用-其他」，表上就是一行有数、九行空着。

## 二、这一版做了什么

新增「利润分析表」，版式照抄你那张：**序号 / 科目 / 行次 / 金额（元）/ 备注**，
行次按原表编（收入 1；支出 1~15），末行是「净利润（亏损以「-」号填写）」。
桌面端在「管理会计」，网页端在「账簿报表」。

关键是**把行做成数据**（`profit_sheet_row`）：每行挂若干科目编码，金额 = 这些科目
本期发生额之和。要改口径就改这一行，不用改代码。

- **默认只给收入行挂 `6001,6051`**（标准表里一定有），支出行一律空着并标黄「未挂科目」。
  不硬塞「最接近的科目」——那会把化工、染料、维修费算进同一行，而且不报错。
- **一键「按这张表生成科目」**：没挂科目的行，在 `5101 制造费用` 下各建一个同名末级科目
  （510106 化工、510107 染料封闭剂…）并回写。以后录凭证按它们记，这张表自动出数。
- **同一科目只能挂一行**：挂两行合计会翻倍，而每行数字都对、只有合计错，对账时才发现。
  保存时直接拦下来，错误里写清后果。
- 收入行额外显示「产量」（本月完工数量）——你那张表第一行写的就是「收入：月总产量」。

## 三、口径

损益取数一律排除结转损益凭证（结完账后损益科目借贷相抵，不排除整张表变 0）；
收入行取贷方发生额、支出行取借方发生额；净利润 = 收入合计 − 支出合计。

## 五、没动

- 不做「自动按凭证摘要猜科目」：摘要里写「电费」就归到电费行听着聪明，猜错没人发现。
  宁可让行空着标黄，让人一眼看出「这行还没挂」。
- 行次不跟着序号变：原表就是两套编号（序号 1、2、4、5…，行次 1~15），照抄。
