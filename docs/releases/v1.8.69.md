# v1.8.69 —— 制造费用按「报工工时」分摊

## 一、问题

槽液、水电这类制造费用跟着开机时长走，但分摊基准只有「按成本占比 / 按直接人工 /
按计划产量」，只能手工估一个比例；金额还得先去余额表抄一个数再手敲进来 ——
而制造费用期末要结转到生产成本，**结转完余额是 0**，抄成期末余额就得到
「分摊执行成功、一分钱没分出去」。

## 二、这一版做了什么

- 新增分摊基准 `按报工工时`：用 `prod_op_log.hours` 在本期各在制订单上的占比分摊，
  最贴近氧化车间「按开机时长走」的费用。
- 分摊金额可以留空：留空即取制造费用科目（5101，含下级）**本期借方发生额**
  （`overhead_pool_from_account`）。取借方不取余额，是因为期末结转是"贷 5101"，
  不影响借方发生额 —— 结转前后取到的都还是本期真实发生额。
- 没报工时不许"照分"：按工时且本期零工时时直接报错「先做工序报工，或改用其他基准」，
  而不是返回一批 0 元的分摊。
- 修掉一个真 bug：**报工流水的期间取的是"今天所在期间"**。账套期间是 202601、
  今天在 11 月时，订单坐在 202601、流水落在 202611，`wip_cost(202601)` 里工时全 0，
  按工时分摊永远分不到。现在流水期间跟着**订单**走（取不到才退回今天）。
- 桌面端「成本核算 → 分摊费用」加了「按报工工时」与「取本期发生额」按钮；
  网页端成本页的基准下拉加同一项，金额框留空即取科目发生额。

## 四、没动

- 槽液/水电仍按"分摊"处理，没有做按槽位、按面积、按批次的精细归集 ——
  那需要现场数据（每槽多少件、开多久），当前系统里没有这些字段。
- 返工件成本仍靠工单手工归集，没有单独设"返工成本单"。
- 客供料台账仍不出凭证（等确认会计口径：来料是否按"受托加工物资"入账、
  损耗是否计加工成本）。
