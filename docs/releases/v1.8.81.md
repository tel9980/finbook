# v1.8.81 —— 首页先告诉你「这个月怎么样」，没在用的模块不再占地方

这一版**没有改数据结构，也没有改任何记账规则**，`1.8.80` 的账套可以直接用。
改的是打开软件第一眼看到的东西 —— 因为它一直在说错重点。

---

## 一、问题：首屏四个数是给会计看的，不是给老板看的

原来首页最上面是这样的：

| 本期凭证 | 待处理 | 本期发生额 | 期末余额 |
|---|---|---|---|
| 48 | 3 | 450,000.00 | 1,235,000.00 |

这四个数回答的是「**账记得对不对**」：几张凭证、几张没记账、借贷各多少、平不平。
会计每天要，但小厂老板打开软件想知道的是另外三件事：

1. 这个月**赚了没有**；
2. 钱在**谁手上**（客户欠我多少、我欠谁多少）；
3. 今天**该先办哪件事**。

原来的首屏只回答第 1 个的一半，第 2 个在最下面，第 3 个完全没有。

---

## 二、改法：一句话结论 + 四个数折叠起来

首屏现在是：

```
本期经营结果（净利润、利润率、年初至今）
    收入 450,000.00        成本 424,150.82
    ⚠ 还有 3 张凭证没记账，下面的 25,849.18 是「已记账部分」的利润，可能偏小。
      去「凭证查询」勾选后批量记账，数字才是完整的。
钱在哪（客户欠我 / 我欠谁 / 手头现金 / 净头寸）
▸ 账目概况（凭证数、发生额、期末余额）   ← 折叠，点一下全都在
```

新增的 `verdict()` 只给**一条**建议，按这个优先级挑：

| 情况 | 说什么 |
|---|---|
| 有凭证没记账 | 先记账 —— 因为没记账的凭证不计入利润，此时「赚了多少」是偏小的，拿它做决定就会错 |
| 有人欠钱超 90 天 | 先去催 —— 小厂最常见的死法不是不赚钱，是赚的钱全压在客户手里 |
| 净欠外面（欠供应商 > 别人欠你） | 留意付款节奏，附手头现金 |
| 本月还没录收入 | 提示去记第一笔 |
| 都正常 | 报净利润 + 月底四步 |

**为什么只给一条**：给三条等于没给，他会一条都不看。

四个数一个都没少，只是挪进「账目概况」折叠块（默认收起）。试算平衡那张卡还在原位。

## 三、工作台：没在用的模块，不再挂着 0

同一批改动里还包括网页版工作台（`docs/功能参考.md` §4.124）。

小厂通常只有一个人、一个全权限账号，不做仓管、不开生产工单、没有报销审批。
可是工作台原来按岗位权限拼卡片，于是「生产在产 0 份」「临期批次 0 个」
「运行中审批流程 0 个」会**长期**挂在首屏，把「赚没赚 / 钱在哪」挤到下面去。

现在改成按「这个业务域有没有落过单据」决定显不显示：

| 域 | 判定表（任一有记录即算启用） |
|---|---|
| 销售 | 销售订单、报价单 |
| 采购 | 采购订单、采购申请 |
| 仓管 | 库存批次、出入库、盘点 |
| 生产 / 成本 | 生产订单、生产成本 |
| 报销 | 费用报销单 |
| 审批 | 审批流程实例 |

凭证、资金、报表**永远显示** —— 记账本身就是主线。

三处刻意的取舍：

- **口径是「历史累计有没有单据」，不是「本月有没有」。** 这个月没开销售单、上个月开过，
  卡片就该还在；按本月判定会让同一块区域时有时无，比一直显示更让人糊涂。
- **不按权限判定。** 小厂老板是全权限账号，按权限过滤等于什么都过滤不掉 ——
  这正是那堆空卡的来源。
- **藏掉的域要有一句话交代。** 网页版底部、桌面首页末尾都会写明「销售、仓管、生产……
  这一块本账套还没有用过，所以先不显示；照常去左侧菜单操作，录入第一张单据后这里就会出来」。
  小厂最怕「昨天还在的东西今天不见了」，以为软件坏了。

## 五、升级注意

- **无 schema 变更**：数据库还是 v48，不需要迁移。
- **无接口变更**：`/api/workbench` 多了一个 `active` 字段（只增不改，老客户端忽略即可）。
- **界面变更两处**，都只是「看得见的少了、看得懂的多了」：
  桌面首页四张指标卡折叠进「账目概况」；网页版工作台不再显示没用过的业务域。
- 账套、凭证、报表数字**一个都没变**。这一版不碰任何记账逻辑。
