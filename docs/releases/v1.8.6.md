# FinBook v1.8.6

这一版是**报表与工资的错账修复**：应付对账单期初不再变负数，结转损益后财务概况不再把收入/成本/利润冲成 0，净利润补上公允价值变动和投资收益，权益变动表与资产负债表同口径，跨年后“本年累计”从 0 重新起算，工资行编辑不再清空凭证链接、已结账月份不能改工资表。

**不改记账规则、不改凭证校验、不改数据库结构**（仍为 V36），直接覆盖升级即可。

## 这一版修了什么

### 1. 应付对账单期初不再显示为负数

应收对账单按“借方=欠款增加”看，应付对账单按“贷方=应付增加”看。旧版只有**本期发生额**用了应付方向，**期初余额**仍按借方为正计算，于是：

- 1 月形成 1000 元应付，2 月查对账单，期初显示 `-1000.00`；
- 期初行与本期增加方向相反，滚动余额看起来像“先冲掉一笔再重新欠”。

现在期初和本期统一按应付方向计算，期初 `1000.00`、本期增加 `500.00`、期末 `1500.00`，逐行滚动一致。

### 2. 结转损益后，财务概况不再变成 0

“账目总览 / 财务指标 / 财务分析”的营业收入、营业成本、净利润，原先直接取损益科目的发生额。月末做“结转损益”后，系统凭证会把收入、成本、费用全部转进本年利润，于是这些指标被冲成 0，看起来像这个月没做生意。

现在损益类指标单独按**排除结转损益凭证**的口径取数；资产负债表仍使用含结转的余额。结转前后收入、成本、净利润保持一致。

### 3. 净利润补上公允价值变动收益和投资收益

旧版净利润公式漏了 `6101 公允价值变动损益` 和 `6111 投资收益`，有这两类业务时利润会少算。现在利润表、财务指标、利润构成三处都包含它们。

### 4. 权益变动表与资产负债表同口径

旧版“未分配利润”只取 `410401` 一个明细科目，漏掉：

- `4103 本年利润`（年末结转前，本年利润还挂在这里）；
- `4104 利润分配` 下的其它明细；
- 尚未结转的当期损益。

结果年中查权益变动表时，“所有者权益合计”比资产负债表少一块。现在未分配利润 = `4103 + 4104 + 未结转损益`，与资产负债表“未分配利润”行完全同口径；网页上的“勾稽通过/不符”也能正确显示（之前接口没返回 `ties`，页面永远显示“不符”）。

### 5. 跨年后“本年累计”从 0 重新起算

如果账套是年中建账（例如 2025 年 7 月启用），并录入了“年初余额 + 本年累计借/贷”，旧版在 2026 年查询时仍会把 2025 年的累计发生额带进“本年累计”，导致 1 月的本年累计一开局就偏大。

现在只有报告期与建账期**同一年**时才把建账前的累计数计入；跨年后只统计当年 1 月起的发生额。期初余额和期末余额不受影响。

### 6. 工资行编辑不再清空凭证链接；结账后工资表锁定

旧版编辑工资行时，工资计算返回的 `voucher_id` 是空值，保存时覆盖掉已经回写的计提凭证链接。后果是：

- 工资行看起来“还没生成凭证”，但凭证其实已经存在；
- 删除工资行时“已生成凭证”的拦截失效，可能删掉工资行却把凭证留在账上。

现在保存时保留已有的计提/社保/发放三个凭证链接；删除时任意一个链接存在都会拦住。同时，已结账期间不能再新增、修改或删除工资行，避免工资表与已封账的凭证脱节。
