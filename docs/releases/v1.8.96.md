# v1.8.96 报价单「按规格和批量算价」

## 问题

客户问「1250*250*3 的件，300 件多少钱」，业务员得在纸上算：0.3125 ㎡ × 300 = 93.75 ㎡，
乘 80 元 = 7500，再反除成「每件 25 元」填进单子。算错一个数整张单都错，
事后也没人看得出这 25 是怎么来的。

## 改法

报价单加了三个格子：**规格 / 口径 / 工艺**。填了规格和数量，点「按价目表算」，
系统一条路算完：规格折成计价数量 → 按数量挑档 → 按工艺档挑档 → 乘单价 → 摊回每件价。

示例：

| 你填 | 系统算出 |
|---|---|
| MB01，规格 1250*250*3，300 件 | 折成 93.75 ㎡ × 80 元 = 7500 → **25.00 元/件** |
| MB04，300 件（有阶梯价） | 走「500 件以下」0.35 → **105.00** |
| MB04，800 件 | 走「500 件以上」0.25 → **200.00** |

保存时单价留空也会自动算。

## 单价锁进单子

报价单是当时的承诺。价目表下个月调价，不会改掉上个月已经发出去的报价单 ——
单子上存的是快照（`spec / calc_unit / process / calc_qty / rule_id`，schema v54）。
要按新价重算，编辑那张单子再点一次「按价目表算」。
