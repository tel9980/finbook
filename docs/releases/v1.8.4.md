# FinBook v1.8.4

这一版**只改桌面版的显示，不改任何算法**：报表里的 `0` 不再留空，而是明确写成 `0.00`；利润表整张表都是 0 时，直接告诉你为什么。取数公式、记账口径、数据库结构一行未动。

## 这一版的变化

### 1. 桌面版报表：零值统一显示 `0.00`

以前桌面版的报表按「财务惯例」把 0 打成空白，问题是：

- 一列全是 0 时整列空白，看起来像「金额列没取到数 / 这一列没渲染」；
- 更乱的是一张表里两套口径——例如所有者权益变动表，**前两列留空、最后一列却显示 `0.00`**，同一行对不上，用户只能截图来问。

现在桌面版与网页版、接口统一：**资产负债表、利润表、现金流量表、权益变动表、对比分析**里的零值一律显示 `0.00`，空白只保留给真正没有内容的行（表头行、空白分隔行）。

> **刻意的例外**：凭证分录、明细账等表格里的零值仍然留空。那里半张表本来就不该有数字（比如分录只有借方、贷方为空），全部写成 `0.00` 反而看不清真正的发生额。这是两类表格的分工，不是漏改。

### 2. 桌面版利润表全零时，给出原因

整张利润表都是 `0.00` 时，表格上方会出现与网页版同一套说明：

> 本期各项目均为 0.00：该期间没有已记账的损益发生额。利润表只统计已记账凭证（草稿 / 已审核未记账都不算），并剔除系统生成的结转损益凭证。请确认账套与期间，再到「凭证」检查本期 6xxx 损益科目是否已记账。

有任何一个非零金额时不会出现，不干扰正常看表。

### 3. 延续 v1.8.3 的修复

v1.8.3 修掉了明细账「点查询后整张表消失」的回归（虚拟滚动容器替换顺序写反导致），并统一了打印预览的零值口径。本版在这些基础上，把桌面端剩下的留白一起收干净。
