# FinBook v1.8.11

**税率不是账套参数，是客户属性。** 每个客户税点不同，现在能分别设了。

## 为什么改

小厂现实里，同一个老板的不同客户税点经常各不相同：有的要 13% 专票、有的只要普通发票、有的是小规模代开 3%、有的干脆不要票。账套层面统一一个税率，必然对不上。

之前的做法只能手工算税，或者干脆不拆税全额记收入——两种都不准确。

## 新增：一客一税点

### 客户/供应商档案新增两项

辅助档案 → 客户（或供应商）→ 编辑：

| 字段 | 说明 |
|---|---|
| **税点 %** | 这个往来单位开票时的税率：13 / 9 / 6 / 3 / 1 / 0 |
| **开票情况** | 每次都开票 / 有时开有时不开 / 从不开票 |

存在档案的 `props_json` 里（`tax_rate` / `tax_policy`），**无需 SCHEMA 变更**。

### 凭证录入新增「按客商税点算税」

工具栏加了一个按钮。做法：

1. 凭证里按**含税总额**录入，辅助核算挂上客户
2. 点「按客商税点算税」
3. 系统读出该客户的税点，自动拆成两行：原行改为不含税金额，新增一行 `22210102 销项税额`

实测（含税都填 10300）：

| 客户 | 档案税点 | 不含税收入 | 销项税额 |
|---|---|---|---|
| 张三氧化 | 13% | 9,115.04 | 1,184.96 |
| 李四五金 | 3% | 10,000.00 | 300.00 |
| 王五电镀 | 0（不开票） | 10,300.00 | 0 |

边界处理：

- 税点填 0 → 全额记收入，不提税（提示「税点为 0，无需拆税」）
- 档案没设税点 → 明确提示去补，而不是猜测一个默认值
- 金额太小算出的税为 0 → 提示并跳过，不生成零金额行

## 配套：无票业务

同版本一并明确了「发票不是记账前提」的处理口径：

- **有票**：按客户税点拆出不含税收入 + 销项税额
- **没票，以后补**：全额记收入，先不提税；补票时做转字凭证（借 600101 / 贷 22210102）补提
- **永远不开票**：全额记收入，税点填 0
- **补票不影响应收余额**——客户欠你多少钱始终是一个数

## 兼容性

- 无 SCHEMA 变更，仍为 **v38**，旧账套直接打开。
- 已有的客户/供应商档案税点为空，等于「未设置」，行为与升级前一致。
- 税率改动只影响之后的凭证，**历史凭证不受影响**。
