# FinBook v1.2.1

补丁版，只修一个问题：**打开软件看到的是完整菜单（47 项），而不是精简的 12 项**。

---

## 下载

| 平台 | 文件 | 大小 |
|------|------|------|
| **Windows 10/11** | `finbook-1.2.1-windows-x86_64.zip` | ~7 MB |
| Linux x64 | `finbook-1.2.1-linux-x86_64.tar.gz` | ~10 MB |

解压后得到三个文件：

```
finbook(.exe)          主程序，双击即用，无需安装
新手使用说明.txt        4 步走通的大白话说明
示例账套.fbk           一家小商贸公司的完整账，可先打开看效果
```

账套就是一个 `.fbk` 文件（标准 SQLite），**备份只需复制这个文件**。

附件里还有服务器版（`finweb-1.2.1-linux-x86_64.tar.gz`，自部署 Web 端用）与校验和（`SHA256SUMS`）。

## 这一版的变化

### 精简模式：没明确关掉就精简，不再分新老用户

v1.2.0 里精简模式看历史分流：没打开过账套的新用户默认精简，有历史的老用户默认完整菜单。结果是——**曾经打开过账套的人，升级后看到的还是 47 项**，生产制造、供应链这些用不上的模块全堆在眼前，而这恰是精简模式要解决的问题。

这一版改成：只要没明确取消过勾选，一律默认精简（12 项：工作台 / 填制凭证 / 凭证查询 / 账簿查询 / 科目余额表 / 会计报表 / 期末处理 / 银行对账 / 往来核销 / 会计科目 / 期初建账 / 备份恢复）。之前明确取消过的，不受影响，仍然是完整菜单。

功能一项没少：侧栏底部取消「精简模式」勾选，或点「临时看全部功能…」，立刻全部回来。

## 数据与隐私

**完全离线运行，数据不上传。** 账存在你自己电脑上的 `.fbk` 文件里，不联网、不收费。

## 已知限制

- 打印走系统默认浏览器预览（Ctrl/Cmd+P），未对接虚拟打印驱动
- 导出 Excel/CSV 仅管理员与财务主管可用，普通账号仅能打印
- 附件哈希为 SHA-256 完整性校验（防误删损坏），不防篡改
- 不要把同一个 `.fbk` 放在 NFS/SMB 网络盘被多台电脑并发直开（WAL 在网络文件系统上不稳定，可能损坏账套）
