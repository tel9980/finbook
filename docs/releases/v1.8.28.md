# v1.8.28 —— 套打与薄壳：把「第三种写法」收干净

v1.8.27 把报表打印和账套参数各收敛到一处。这一版收尾剩下的三种分叉，它们都是
同一类毛病：**同一件事有三个地方在写，改一个忘两个**。

## 一、套打也读账套里的纸张设置，并新增「套打偏移」

凭证套打、账簿套打、单据套打原来各有一句写死的 `@page`：

```css
@page{size:A4 landscape;margin:12mm 10mm;}   /* 凭证 */
@page{size:A4 landscape;margin:10mm 10mm;}   /* 账簿 */
@page{size:A5;margin:8mm;}                   /* 单据，按纸型算 */
```

于是账套里设了页码/横向/偏移，报表跟着变，**套打一点不动**——而套打恰恰是最需要
对位的地方：针式打印机走纸偏 2–3mm 是常态，以前只能改打印机驱动或者忍着，压线
压到金额上看不清。

现在纸张规则统一由 `PrintOptions::page_box_css(size, base_margin_mm)` 生成，四个
套打入口（凭证 / 账簿 / 订单 / 收付款单）都收同一个 `PrintOptions`。

新增两个字段：

| 设置 | 范围 | 用途 |
|------|------|------|
| 套打横向偏移 | −20 … +20 mm | 正数=向右 |
| 套打纵向偏移 | −20 … +20 mm | 正数=向下 |

实现上「偏移」等于把四边页边距改成 `左+N / 右−N / 上+M / 下−M`。两个坑：

- **负边距要夹到 0**。`margin:-8mm` 不是「负边距」，是**非法值**——浏览器会把整条
  `margin` 声明丢掉，纸张回到默认边距，比不设还乱。
- **套打不接正文字号**。套打纸的格子是按 px 固定的（`tr.l{height:21px}`），被
  `font-size:Npt` 一冲就溢格。所以纸张规则与字号规则拆成两个方法：
  `page_box_css`（只有 `@page`，套打用）与 `page_css`（报表用，两者都要）。

## 二、科目余额表打印不再自己写第四份 `<style>`

`trial_balance_html` 原来是一整套独立的 `<!doctype html>…<style>body{…} .pbar{…}`。
后果和上一版一模一样：账套里设了页码、横向、偏移，这张表全都不跟着变。

改法：`report_html::shell` 提升成公开的 `page_shell(title, company, subtitle, unit,
table_html, cols, po)`——**表体各不相同，壳只留一个**。科目余额表自己只拼 `<table>`。

## 三、桌面端补齐三个设置项

网页端早就有「预算控制 / 单据前缀 / 启用生产制造」，桌面端的账套参数页一直没有。
这不是「少个功能」，是**同一套账在两处看到不同的设置项**：在网页上把预算强控打开，
回到桌面端根本找不到开关，也不知道它开着。

补上之后两端字段一致。这一类的检查办法不是读代码，是**把两边的字段清单并排比一遍**。

## 四、结构校验补掉五类「填错不报错」

| 填错 | 原来会怎样 | 现在 |
|------|------------|------|
| `budget_control = "warning"` | 只有 `warn`/`strong` 生效，其余按关闭 → 超预算一路放行 | 报错并带出原值 |
| `doc_prefixes` 键写成 `purchase` | 只读 `po/so/req/quo/prod` → 永远用默认 CG | 报错并指出拼错的键 |
| 单据前缀填 `C G`（带空格） | 单据号里带空格，搜索/对账都难对 | 只允许字母数字，≤8 字符 |
| 凭证字重复（`记,记`） | 两张凭证同号，谁也说不清 | 报错 |
| 本位币填「人民币」 | 外币折算按 CNY 硬编码走，填什么都一样 | 必须三位字母代码 |

外加：企业名称留空会报错（报表抬头、套打单据全空），同时把 `BookOptions::default()`
的默认名称改成「未命名单位」，让默认值自己能过校验。

这类 bug 的特征是**没有任何报错**，只能靠人某天发现「怎么设置了没用」。

## 「试打一张」也能试偏移

设置页的「试打一张」现在支持 `?po_ox=&po_oy=`，覆盖**本次**渲染而不写库。没有这条，
用户只能「改 → 存 → 去报表 → 打印 → 发现偏 → 回来再改」——针式打印机对位往往要来回
三五趟。

## 怎么用

- **桌面版**：`系统设置 / 账套参数` → 「打印预览」里调套打偏移；「业务控制」下面多了
  预算控制和单据前缀。
- **网页版**：`系统设置` → 「打印预览」→ 套打偏移 → 点「试打一张」看着对位，满意了再保存。
- 对位技巧：先打一张，看内容整体偏左下还是偏右上，就填对应方向的正数；一次调 2mm。
