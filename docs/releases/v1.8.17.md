## 二、期初余额只许录在末级科目

### 原来的问题

可以把期初录在 `2202 应付账款` 这种一级科目上。而试算平衡表只遍历**末级**科目：

```
期初录 2202 贷方 5,000
→ 试算表不统计这 5,000
→ 显示「借贷不平」，但你翻遍科目都找不到差在哪
```

账套从一开始就是歪的，之后每个月点「结账」都被拒，且提示不出原因。

### 现在

录期初时如果填的是非末级科目（编码 4 位或 6 位的一级/二级科目），直接拒绝：

```
科目 2202 不是末级科目，期初余额只能录在末级科目上
```

Web 端同样生效。`finweb/tests/api.rs` 里有一个用例原来用 `2202` 录期初，同步改成了 `220201`。

## 三、结转损益纳入成本类科目

### 原来的问题

v1.8.12 修过一个 bug：首页净利润漏算制造费用。当时只改了**报表口径**，**结转路径没跟上**。

结果：

```
房租 15,000 记 510105 制造费用
→ 利润表算进去了（v1.8.12 修好了）
→ 但「结转损益」不转它
→ 5101 期末永远挂着 15,000，永不归零
→ 「本年利润」里也没有这笔
```

报表和结转两处口径不一致。小工厂房租、水电、煤气、外发加工费全记 5101，**每个月都中招**。

### 现在

`carry_forward_rows` 纳入 `AcctCategory::Cost` 的末级科目。

实测（11 月：收入 20,000、水电 5,000）：

```
借：600101 主营业务收入      20,000.00
  贷：510103 制造费用—水电费    5,000.00
  贷：4103 本年利润            15,000.00
```

5101 结转后归零，15,000 正确进入本年利润。

> 5001 生产成本（在制品）不在此列——它还在仓库里，是存货不是费用。

## 四、结账 / 反结账 / 年末结转 全流程验证

本次对整条期末链路做了 32 项实测，并固化成 4 个单元测试（`periods::close_cycle_tests`）。

### 实测结果

| 场景 | 结果 |
|---|---|
| 未结转就结账 | 被拒：「损益类科目尚未结转：600101 产品销售收入」 |
| 结转后损益净额 | 全部归零 ✓ |
| 结账 2026-11 | 成功，`closed_upto=2026-11` |
| 往已结账期间写凭证 | 被拒：「2026年11期 及以前期间已结账，不能再保存该期间的凭证」 |
| 跳过 12 月直接结 2027-01 | 被拒：「请先结账 2026年12期」 |
| 反结账 11 月 | 成功，期间重新开放 |
| 补记办公费 800 → 重新结转 → 重新结账 | 月净利 15,000 → 14,200 ✓ |
| 全年累计（11 月 14,200 + 12 月 30,000） | 44,200 ✓ |
| 年末结转 | 借 4103 44,200 / 贷 410401 44,200 ✓ |
| 年末结转后 4103 | **归零** ✓ |
| 亏损年份 | 方向自动反向：借 410401 / 贷 4103 ✓ |
| 本年利润为零时年末结转 | 被拒：「本年利润余额为零，无需结转」 |
| 缺 410401 科目 | 被拒，提示补科目 |
| 反结账非最后期间 | 被拒：「只能从最后结账的期间 2026年12期 开始反结账」 |
| 反结账 12 月后 `closed_upto` | 回退到 2026-11 ✓ |
| 跨年（2026-12 结完接 2027-01） | `closed_upto` 正确推进，1 月可录凭证 ✓ |

### 新增回归测试

`crates/findb/src/periods.rs` 的 `close_cycle_tests`：

- `结转结账反结账往返`
- `结账顺序约束`
- `年末结转四种情况`（盈利 / 亏损 / 零 / 缺科目）
- `跨年结账连续`

findb 单测从 391 增至 395。

## 升级提示

- 存量账套如果**期初录在非末级科目**上（编码 4 位的如 `2202`、`1122`），需要自行改录到末级（`220201`、`112201`）。改之前先看试算表是否平衡——不平衡基本就是这个原因。
- 新增的期初校验对已存在的旧数据不追溯，只拦新录入。
