# v1.8.70 —— 客供料口径定案：只记数量，不出凭证

## 一、问题

客供料台账（v1.8.63 上线）一直挂在「还没做」的清单里：来料加工厂把料拉来，
系统只记数量不生成凭证，看起来像是做了一半。

其实这是**口径问题不是功能问题**：受托加工的来料所有权属于客户，不属于本企业存货，
会计上本来就只作备查登记，本企业的收入是加工费。反复解释不如定案一次。

## 二、这一版做了什么

- 把口径写进代码：`crates/findb/src/consign.rs` 模块头新增「会计口径：这一块故意
  不生成凭证」，说明为什么只记数量、真要凭证化要改哪三处、以及唯一沾钱的
  「损耗赔偿」该怎么走（普通费用凭证，不给台账加金额字段）。
- `docs/功能参考.md` 新增 §4.113，把三条边界写成人话：
  不改（不入存货/不出凭证/不参与成本结转）、损耗赔偿例外、凭证化属于会计政策变更。
- 没有功能改动、没有表结构改动、没有行为变化。

## 四、没动

- 台账本身一行代码没改：单号、批次维度、超交拦截、对账单都保持原样。
- 槽液/水电仍按分摊处理，不做按槽位、按面积的精细归集（缺现场数据字段）。
- 返工件成本仍靠工单手工归集。
