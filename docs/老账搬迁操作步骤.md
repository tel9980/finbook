# 老账搬迁操作步骤（一次性，只做一遍）

> 什么时候用这份：**第一次用 FinBook，把以前手工账 / 别的软件里的余额搬到新账套里**。
> 只搬一次，之后每月照常记账、月底结账。
> 搬家搬完以后，每月和客户/供应商对账用另一套功能 —— 见本文最后一节。

一句话说明它和日常记账的区别：**期初不是"记一笔凭证"，它是"账本第一页的余额"**。
所以它走「期初建账」，不走「填制凭证」；搬进来的数**不会**出现在本月的收入/支出里，
只影响资产负债表和往来台账。

---

## 〇 动手之前：三件事

1. **备份 / 新建一个空账套。** 老账搬家一律搬进新账套，别在正在用的账套上试。
   （桌面：文件 → 新建账套；网页：首页 → 新建账套）
2. **先把客户和供应商档案建好。** 搬家的表里要填「客户编码」，编码不在档案里就对不上。
   长期合作的客户/供应商一批建进去，一次就够。
   （网页：基础资料 → 客户 / 供应商；桌面：左侧「会计科目」旁边的往来档案页）
3. **准备旧账的期末数**，通常三个来源：
   - 上个月的**资产负债表**（各科目余额）
   - **应收/应付明细表**（谁欠我多少、我欠谁多少，最好带单据号和日期）
   - **现金 / 银行对账单余额**、**固定资产清单**、**借款余额**

---

## 一 下载《期初收集表.xlsx》

网页版：**期初建账 → 导入期初收集表 → 下载空模板**。

模板里已经把这个账套的科目、客户、供应商的**编码和名称**都列好了，你只填金额。
四张纸，一张一张来：

### ① 客户应收
`客户编码 | 客户名称 | 欠款金额 | 单据号 | 备注`

- 只填**正数**：客户欠你的钱。
- 一个客户欠几笔、账期不同，就写几行（一行一笔，靠单据号区分）。
- 单据号随便起，能让你自己认出来就行（`2026-11-001`、`11月对账单-张老板`）。
- **客户先交的定金、预付款不是应收**，那是预收，见第③张纸。

### ② 供应商应付
`供应商编码 | 供应商名称 | 品类 | 欠款金额 | 单据号 | 备注`

- 同样只填正数：你欠供应商的钱。
- **先付给供应商的预付款不是应付**，那是预付，见第③张纸。

### ③ 账户余额
`科目编码 | 账户 | 余额`

填这些科目的账面数（编码不知道就点模板里下拉，或查「会计科目」）：

| 常见科目 | 填什么 |
|---|---|
| 1001 库存现金 | 出纳保险柜里实际有多少钱 |
| 1002 银行存款（各账户分开） | **银行对账单余额**，不是账面余额 |
| 1601 固定资产 / 1602 累计折旧 | 固定资产原值、已提折旧（折旧填贷方数就用负号或按模板提示） |
| 1123 预付账款 | 先付给供应商的钱 |
| 2203 预收账款 | 客户先交的钱 |
| 2001 短期借款 / 2501 长期借款 | 还欠银行多少 |
| 2221 应交税费 | 有欠税填正数，有留抵按模板提示填 |

### ④ 基本资料
- **实收资本**：照营业执照上的注册资本填。
- **本年利润**：不填。系统按借贷差额自动轧平 —— 这是搬家能不能对上账的关键一格。

## 二 先预检，再导入

点 **先预检（不落库）**，它会算一遍并告诉你：

```
预检通过，没有落库 —— 应收 23 笔、应付 15 笔、科目期初 12 条；借 1,286,400.00 = 贷 1,286,400.00
```

看到这行才是对的。然后点 **开始导入**。

### 借贷不平怎么办

期初**借贷必须相等**，不平会**整批拒绝**，一个数字都不写进账套，并告诉你差多少：

> 借 1,286,400.00 ≠ 贷 1,196,400.00，差 90,000.00

这是**故意的**：写进半个账套比直接报错难收拾得多。差 90,000 的典型原因是
「固定资产买了 90,000 忘了登」或「实收资本少填一笔」。

处理办法只有一条：**改表 → 重新导入**，不要在报表上补一笔调账凭证把差额凑平
——那样试算平衡看着平了，每一处余额都还是错的。

## 三 搬完必查三处（五分钟）

1. **往来期初明细**：应收合计、应付合计，和你的旧账明细表对不对得上。
   （网页：往来核销页下方「往来期初明细（按单据·迁移）」）
2. **科目余额表**：`112201 应收货款`、`220201 应付货款` 的期初数 = 上面两个合计。
3. **资产负债表**：应收/应付数 = 上面两个数；试算平衡表借贷相等。

三处都对上才算搬完。这三处只要有一处不对，多半是「只导了台账、没导科目期初」
——早期版本就出过这种「账龄表有欠款、报表里一分应收都没有」的故障，
所以现在这两件事一次做完。

---

## 四 搬完以后：每月对账走「应收应付对账」

期初只有**一次**。之后每个月和客户/供应商对账，用
**期末 → 应收应付对账**（网页版在左侧「期末」组里）：

1. 选「应收」或「应付」→ 期间 → 「新建这次对账」。
2. 名单会**按账面自动列出来**（有余额的户先摆好，金额先等于账面）。
3. 把对方报来的数**一格格改上去**（也可以整段粘贴：`客商编码,金额[,备注]`）。
   差额自己就冒出来了；对不上的户点「标争议」先放着。
4. 全对好了点「确认这一批」：**只有差额**会汇总成一张**草稿**凭证，
   去「凭证查询」看一眼，审核、记账 —— 要不要记账你说了算。
5. 发现哪户漏了：页面上会写「账面还有 N 户没录进来」，点「加进来」即可。
6. 确认后发现填错了：点「打回重对」（草稿凭证还在的话会自动删掉；已记账的要先反记账）。

**对账过程中账上一分钱都没动**，这是可以放心大胆试的原因。

## 五 常见问题

**Q：同一个文件导两次会不会翻倍？**
不会。同一「类型 + 客商 + 单据号」只认一次，第二次静默跳过。

**Q：单据日期填哪天？**
填这张单据原来的日期（`2026-11-05` 这种格式）。早于期初期间的都能进，晚于的会被跳过。

**Q：金额能填负数吗？**
应收/应付两张纸只认正数。负数是**预收/预付**，填第③张纸的 2203 / 1123，并写上客商编码。
（系统会明确提示这一点，不会让你蒙着改成正数糊过去。）

**Q：期初搬完，上个月还能改吗？**
不能。这里说的是**科目期初余额**，属于账套起点，要在同一期间内一次性定下来。
确实要改：清掉期初 → 改表 → 重新导入。

**Q：那往来期初明细填错一行呢？**
不用整张表重导。网页「往来核销」页下方的「往来期初明细」每一行都有「改」，
点开改客商、单据号、日期、金额、备注即可（v1.8.83 起）；原始录入人和录入时间保留不改。
改完记得回第三节把「三处」再对一遍 —— 明细合计仍要等于科目期初。

**Q：老账里有些应收已经收不回来了。**
搬家时照实填（还是应收），之后用「往来核销」或坏账处理去做，别在期初就抹掉
——抹掉以后永远查不到这笔钱是怎么没的。

**Q：搬家要不要连凭证一起搬？**
不需要，也不建议。期初只搬**余额和未结清单据**；历史凭证留在旧系统里备查，
真需要时导出 PDF 存档。
