FinBook 源码包

Rust 实现的会计 / 财务记账系统 —— 桌面端（egui）与 Web 端（Axum）双形态

项目说明

本包是 FinBook 的完整源代码。它采用 Rust workspace 组织，包含以下 crate：

模块职责
fincore纯计算核心：记账引擎、凭证、余额、报表、税务
findbSQLite 持久层：用户、账套、凭证、期次、权限
finuiegui 桌面 UI 公共组件
finbook桌面端二进制入口
finwebLinux 服务器 Web 服务（Axum + 浏览器访问）：首登即管理员、设备绑定、打印/导出管控

构建与运行（Web 端）

  • 构建：cargo build -p finweb
  • 运行：./target/debug/finweb（默认在服务器本机启动，浏览器访问）
  • 静态资源目录可用环境变量 FINWEB_STATIC_DIR 覆盖

Web 端特性：首次登录账号自动成为管理员（有状态提示是否已设定）；一人一机设备绑定（管理员可重置）；普通账户仅可打印、不可导出；服务端共用 SQLite（WAL 模式）。

目录结构

  • Cargo.toml / Cargo.lock —— workspace 清单与锁版本
  • crates/fincore/ · crates/findb/ · crates/finui/ · crates/finbook/ · crates/finweb/
  • 源码约 2.0 MB（已排除 target/ 构建产物与 *.fbk 运行时数据库）
